## 3. 三个会拦住你的坑

### 坑 1：报「不在以下 request 合法域名列表中」

因为我们 `urlCheck: true`，开发者工具会真校验。排查顺序：

1. 开发者工具右上角「**详情**」→「**本地设置**」→ 确认**没有**勾「不校验合法域名」（勾了反而测不出真机行为）
2. 确认 `app.js` 里 `apiBase = 'https://hergent.cn'`（别带 `/api` 路径后缀）
3. 浏览器直接开 <https://hergent.cn/api/health> 应返回 JSON

> 临时要连本地/内网调试时**才**勾"不校验"，测完立刻取消。

### 坑 2：登录一直失败

- 账号密码**区分大小写**：`mptest` / `Mptest@1`（密码 8 字符上限是后端 bcrypt 限制，别改长）
- 若报「登录已过期」反复弹 → 开发者工具「清缓存 → 清除数据缓存」再登录

### 坑 3：真机预览扫码后空白 / 网络失败

- 真机走**真实域名校验**，必须 https 且已备案（我们都满足）
- 手机和电脑无需同 WiFi，扫码即用
- 要看请求日志：手机上点小程序右上角「⋯」→「打开调试」，再进开发者工具「真机调试」
