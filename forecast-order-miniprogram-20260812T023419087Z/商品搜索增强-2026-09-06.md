# 商品搜索增强 · 条码与名称同框（2026-09-06）

## 一、需求对照：改前 vs 改后

| # | 要求 | 改前状态 | 改后 |
|---|---|---|---|
| 1 | 完整条码 / 任意片段（后 4 位）命中 | ❌ **条码字段根本没进搜索条件** | ✅ 已修 |
| 2 | 商品名任意连续片段（非仅首字符） | ✅ 已满足（`LIKE %q%`） | ✅ 保持 |
| 3 | 条码与名称自动识别，纯数字优先条码 | ❌ 无识别，`ORDER BY id` | ✅ 已加 |
| 4 | 相关度排序：精确 > 前缀 > 片段 | ❌ 无排序 | ✅ 已加 |
| 5 | 最小输入长度触发 + 查询性能 | ❌ 敲 1 个字符就发请求 | ✅ 已加（前端阈值 + 后端索引） |

### 改前的致命缺陷（根因）

`server/routers/data.py` 的 `fill-search` 原 WHERE 只搜 4 个字段：
**`name / spec / product_code / pinyin_first`**

- 库里 **332 个商品有 `barcode`**，条码完全搜不到；
- `pinyin_first` **全库 0 条非空**，占着一个搜索位却永不命中；
- `medium_barcode`(78) / `large_barcode`(41) / `mnemonic`(371) 也都没用上。

> 实测佐证：78 个商品**只有中包装条码、没有单品条码**（如「简爱树莓滑滑」medium=6970618570001），
> 不纳入 medium_barcode 就永远搜不到这批货。

## 二、改动位置

### 后端 `server/routers/data.py`

| 位置 | 改动 |
|---|---|
| 新增 `_ensure_search_indexes(conn)` | 惰性建索引（幂等，每进程每库一次）：`barcode` / `product_code` / `name`。列不存在或无写权限时静默跳过 |
| 新增 `_build_product_search(q, fields, cols, code_fields)` | 生成 WHERE 与相关度 ORDER BY，**全部参数化绑定**（防 SQL 注入） |
| `fill_search_products()` 内 | 调用上述两个函数；字段按 `PRAGMA table_info` **动态探测**（兼容不同租户库 schema 差异，老库可能无多单位条码列） |

**检索字段**

- 编码类：`barcode`、`medium_barcode`、`large_barcode`、`product_code`
- 文本类：`name`、`spec`、`mnemonic`（拼音首字母助记码）、`brand`
- 移除：`pinyin_first`（全库为空）

**相关度规则（`CASE WHEN … THEN 等级`，越小越靠前，同级按 id）**

纯数字输入（判定为条码/编码）：

```
0  完整条码/编码 精确相等
1  条码前缀 q%
2  条码任意片段 %q%   ← 后 4 位后缀匹配落在这里
3  名称前缀 q%
4  名称片段 %q%
5  规格片段 %q%
```

其它输入（判定为名称）：

```
0  名称精确相等
1  名称前缀
2  名称片段
3  规格 / 助记码 / 品牌 片段
4  条码片段
```

### 前端 `miniprogram/pages/fill/fill.js` / `.wxml`

| 位置 | 改动 |
|---|---|
| `onSearch()` | 最小触发长度：纯数字 **3 位**、其它 **2 字符**；未达阈值不发请求，只有从"有效搜索"退回时才恢复全量（避免每敲一键拉一次全表）；防抖 250ms（原 300ms） |
| `clearSearch()` | 同步重置 `_lastKw` |
| `fill.wxml` 搜索框 | placeholder 改为「搜商品名 / 条码（后 4 位也行）」 |

## 四、已知限制

1. **`LIKE '%q%'` 无法走 B-Tree 索引**（后缀匹配的固有代价）。当前 430 个商品下 <20ms；
   若单库商品过万，改用 SQLite **FTS5** 虚拟表（代码注释里已标注）。
2. **后 4 位可能撞号**：库里后 4 位 `8003` 有 5 个商品共同命中，属正常，靠相关度排序 + 名称前缀辅助定位。
3. 前端最小触发长度：数字 3 位 / 其它 2 字符。若觉得中文单字（如「甄」）搜不到别扭，把 `fill.js` 里 `minLen` 的三元改成固定 `1` 即可。
