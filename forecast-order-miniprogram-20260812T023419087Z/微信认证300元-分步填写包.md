# 微信认证 300 元 · 分步填写包

> **结论先说：现在还不能备案。** 微信官方 FAQ 原文 ——「小程序备案必须完成微信认证。无论是否涉及支付环节，完成微信认证是进行小程序备案的必要条件。」
> 后台文案也是：「小程序备案：需先填写小程序信息和类目，**完成小程序认证**」。
> 所以顺序 = **微信认证（300）→ 填名称/头像/简介 → 小程序备案（免费）→ 提审**。
>
> ⚠️ 别混淆：**主体验证**（注册时法人扫码/对公打款，免费）≠ **微信认证**（300 元第三方审核）。前者只证明公司是真的，**不解锁备案**。

## 3. 发票

不知道税号/不想开票 → 直接勾 **「不开发票」**。不影响认证，也不影响以后补开。

## 4. 支付

扫码付 **300 元**（企业主体；个体工商户 30 元）。
- 审核**通过不退**，审核**失败全额退** → 所以资料务必填对。
- 认证有效期跟随营业执照，**每年年审还要再交 300**。

## 5. 提交后：最重要的一件事 = 接电话

第三方审核公司会**打电话核实**（通常工作日当天，快则半小时，慢则次日）。

| 官方指定审核公司 | 电话 |
|---|---|
| 上海信通企业信用征信有限公司 | 0411-84947888 |
| 重庆创宇后天信息技术有限公司 | 028-85182726 / 028-67686807 |

**纪律**：
1. 提交后 2 天内，**陌生固话一律接**（尤其 0411 / 028 开头）
2. 若 2 天没接到 → 扫码进后台看**站内信**，里面有审核员电话，回拨过去
3. 漏接 = 认证卡住，只能等重拨或重提

## 6. 常见驳回原因（一次过 checklist）

- [ ] 营业执照照片**模糊 / 缺角 / 公章看不清** → 驳回第一名，重新拍一张正光、四角齐全的
- [ ] 企业名称与工商数据**不一致**（多字/少字/繁体）
- [ ] 统一社会信用代码输错一位
- [ ] 联系人电话**打不通 / 停机 / 设了陌生号拦截**
- [ ] 经营范围与所选类目明显不符（我们「商业服务 → 企业管理」+ 经营范围含 AI 软件开发/软件销售，**吻合**）

若名称里「AI」被追问，回复口径：**「不涉及 AI 生成内容，仅为订货填报审批工具；AI 指向主体经营范围中的人工智能软件开发资质」**。
