# 厂家返利核算规则

返利 = 厂家按合同给经销商的奖励，常见按"目标达成 + 进货/销售基数"算。口径每家厂不同，先确认合同再算。

## 1. 目标达成率
- **达成率** = 期间实际完成 ÷ 期间目标 × 100%
- 期间：月度 / 季度 / 年度（按合同口径）
- 完成口径：按进货额还是销售额？按开票还是回款？——**先问清，别猜**

## 2. 返利金额
- 常见公式：返利 = 达标部分基数 × 返利比例
- 例：季度目标 50 万，达成 55 万，合同返利 3% → 返利 = 55 万 × 3% = 1.65 万
- 有些合同**超额阶梯**：100% 达成 3%，110% 达成 4%——超出的部分按更高档
- 有些合同**未达标扣返**：低于 90% 达成，返利减半或不给

## 3. 核算注意事项
- 返利基数要扣掉退货、折让（先确认合同是否含）
- 返利到账形式：货补（下次进货抵扣）还是现金返——影响记账科目
- 和客户对账时，返利单独列项，别混进货款
- 记录每个合同的关键口径（目标、周期、基数、比例、达标线），避免月底扯皮

## 4. 回答模板
用户问"这季度能拿多少返利"：
1. 先确认：按哪个合同、哪个期间、进货还是销售口径
2. 报达成率：实际 X / 目标 Y = Z%
3. 按比例算返利，给算式
4. 标注"返利口径以合同为准，建议和厂家业务核对"

## 5. 常见误区
- 没有合同参数时**绝不硬算**返利——先问口径或让用户填返利政策
- 达成率四舍五入到百分位（如 96.4%），返利金额保留两位小数
- 已过期/退货的商品不应计入返利基数（除非合同写明含）
