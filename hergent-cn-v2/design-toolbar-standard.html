Hergent 工具栏统一组件标准

面向「预报订货管理」等所有列表/表体工具栏。对齐 variables.css 设计令牌、AI 副驾 .cp-icon-btn 与苹果风视觉。下列即为可直接复用的参考实现。

① 标杆工具栏（推荐形态）

左组：筛选 + 视图切换 chip；右组：常规动作（幽灵）→ 图标按钮（列设置/全屏）→ 唯一主 CTA（实心青）。组间用 .tb-sep 分隔，组内间距 8px。

② 按钮变体 & 间距

高度：默认 36px / 紧凑 .btn-sm 32px / 图标按钮 30px。圆角统一 --radius-sm(8px)。过渡 .15s。禁用态 opacity:.4。

③ 统一线性图标库（16px · stroke=currentColor）

edit 编辑
refresh 刷新
copy 复制
download 导出
import 导入
sort 排序
fullscreen 全屏
settings 列设置
plus 新增
undo 撤销
redo 重做
close 关闭
audit 审核
payment 付款
template 模板
wizard 向导
search 筛选

全部采用线性图标（Lucide 风格），统一 16px、stroke-width 2、圆角端点、fill=none、颜色=currentColor。禁止 emoji（✏️ ⧉ ⬇ ↶ ↷）混入功能按钮。

④ 字体 / 字号 / 字重层级

T1 区块标题 14px / 600
T2 按钮文字 13px / 500
T3 辅助提示 12px / 400
字重仅用 400 / 500 / 600 三档（设计体系无 700）。工具栏文字统一 13px/500；提示与占位 12px/400；区块标题 14px/600。数字一律 tabular-nums 对齐。

⑤ 对照：统一前 vs 统一后

统一后（标准）

  • 主 CTA 唯一、实心品牌青；其余幽灵描边
  • 图标全线性 16px、currentColor、同源图标库
  • 图标按钮 30×30、圆角 8、hover 浅底
  • 组内间距 8px、组间 12px / .tb-sep
  • 圆角统一 8px；颜色全部走 CSS 变量
  • 字号 13/12 两档，字重 400/500/600

统一前（问题）

  • .btn-sm 未定义 → 高度/字号漂移
  • emoji（✏️⧉⬇）与 SVG 混用，风格割裂
  • .btn-copy 等各自彩色边框，背景杂乱
  • 间距 8/10/12 混用，.tb-toolbar/.edit-ops 不一致
  • 圆角 6/8/12 混用，硬编码阴影
  • 字号 11/12/13/14，字重无层级

应用建议：将本页 .tb / .btn-* / .chip / .fld / .ico 与图标库沉淀为全局组件（如 Toolbar.vue + Icon.vue），预报模块三处工具栏（顶部 .toolbar、交叉 .tb-toolbar、编辑 .edit-ops）直接复用，即可一次性消除现有错乱。
