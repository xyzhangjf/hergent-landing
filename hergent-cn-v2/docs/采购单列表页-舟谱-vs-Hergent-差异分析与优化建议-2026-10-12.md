# 采购订单列表页 — 舟谱 vs Hergent 差异分析与优化建议

> 分析日期：2026-10-12  
> 分析对象：Hergent 采购单列表页（`hergent.cn/#/inventory/purchase?kind=order`） vs 舟谱云管家采购订单列表页  
> 依据素材：双方页面截图、舟谱列设置/批量操作/详情/创建页截图、Hergent `InvPurchaseList.vue` 源码结构

## 摘要（先讲结论）

1. **Hergent 已具备舟谱 70% 以上的列表能力**：列设置（拖序/冻结/显示隐藏/自定义列）、服务端排序、服务端分页、多筛选、导出、打印、批量操作等核心能力代码里已经存在，只是默认截图没展开，视觉上显得比舟谱"单薄"。
2. **舟谱真正值得立即学的不是"更多列"，而是"业务闭环感"**：底部合计行、创建时间快捷按钮、行内"复制"、详情页多标签（货款/入库单）、"转单为"、创建页保存/审核快捷下拉、审计日志 —— 这些都是一线业务人每天省时间的点。
3. **本次建议 9 项，P0 3 项、P1 4 项、P2 2 项**。P0 建议可在 1 个迭代内落地；P1 需要后端补接口或改详情页；P2 属于体验增强，可排后。

## 一、信息架构对比

| 维度 | 舟谱 | Hergent | 差异判断 |
|---|---|---|---|
| 入口位置 | 顶部系统级 Tab 栏 + 左侧采销管理 | 左侧进销存折叠菜单 → 采购单 | 不同导航范式，无优劣 |
| 列表与退单关系 | 采购订单、采购退货订单**两个独立菜单/页面** | 同一路由 `/inventory/purchase`，用 `kind=return` 切换采购单/采购退单 | Hergent 用配置化拆页（v449），更轻；舟谱更传统 |
| 状态分组 | 全部 / 待审核 / 待入库 / 部分入库 / 已完成 / 已取消 | 全部 / 草稿 / 待审批 / 已确认 / 已入库 / 部分入库 / 已取消 | 舟谱状态更粗（无"草稿"，"已完成"=Hergent"已入库"），Hergent 状态更细 |
| 详情页结构 | **多标签页**：采购订单详情 / 货款 / 入库单 | 当前为单页明细（从代码看详情路由已存在，但截图中未展示多标签） | 舟谱把"钱、货、单"拆成标签，信息层次更清晰 |
| 创建页结构 | 表头信息 + 商品明细网格 + 底部保存/保存并审核下拉 | 类似结构 | 基本一致 |

**关键差异**：舟谱把"货款""入库单"从详情页底部或弹窗里抬成**一级标签**，减少了滚动和跳转成本。Hergent 当前详情页如果只有商品明细，业务人查付款、查入库需要离开列表或滚动到底部。

## 二、视觉布局对比

| 维度 | 舟谱 | Hergent | 差异判断 |
|---|---|---|---|
| 主题 | 浅色，高对比蓝白 | 深色，卡片化 | 品牌差异，不是缺陷 |
| 信息密度 | 高：单屏 15 行数据 + 汇总行 + 紧凑筛选 | 中：单屏约 7 行，筛选区占 1 行但展开控件少 | 舟谱更适合大屏批量审单；Hergent 更适合新手 |
| 筛选区 | **平铺式高级筛选**，展开后 2 行：时间快捷钮、供应商、商品、单号、来源、经办人、部门、仓库、创建人、审核人、备注、打印状态、标记状态 | 单行基础筛选：搜索框 + 供应商 + 日期 + 更多选项 | Hergent "更多选项"里实际已藏了很多筛选（代码里有），但截图未展开，**视觉上显得筛选能力弱** |
| 状态 Tab | 横向置顶，带数字徽标 | 横向置顶，带数字徽标 | 一致 |
| 表格工具栏 | 导出、批量操作、新建 | 全选/反选、导出、打印、批量操作、新建 | Hergent 多了"打印"按钮（全局打印），少了行内"复制" |
| 底部 | **汇总行**（订单金额/入库金额/已结款/未结款合计）+ 分页 | 仅分页（截图未显示汇总行） | Hergent 缺汇总行，业务人无法一眼看总进货额 |
| 列设置 | Modal：排序 / 显示隐藏 / 冻结列 / 调整顺序 | 已有齿轮面板（代码里含拖序、冻结、自定义列增删改名） | Hergent 实际能力**超过**舟谱 |

**最值得学的视觉点**：
1. **底部汇总行**：舟谱把合计放在表格最下方，与分页并列，符合"看完列表看合计"的眼动路径。Hergent 目前无此行。
2. **创建时间快捷按钮**：舟谱在日期筛选旁直接放"今 / 昨 / 近7天 / 近30天"，点一下即查，减少日期选择器操作。

## 三、交互设计对比

| 维度 | 舟谱 | Hergent | 差异判断 |
|---|---|---|---|
| 行内操作 | **打印 + 复制** 两个文字链接 | 只有"打印..."下拉 | Hergent 缺"复制"，新建相似单要重新录入 |
| 批量操作 | 批量导入、批量打印、批量审核、批量取消、批量删除、批量标记/取消标记 | 代码里已有 `batchOpen` / `lastBatch` / `psiApi.batchPurchases` | 能力已对齐，差别在入口文案 |
| 排序 | 表头点击三态排序（无→降→升），带排序提示 chip | 已对齐 v470 范式 | 一致 |
| 筛选提交 | 单独"查询"按钮 + "重置" | "查询" + "重置" + 部分输入框 `@change` 自动查 | 基本一致 |
| 创建页快捷操作 | **保存按钮下拉**：保存并新增、保存并复制；**保存并审核下拉**：审核并新增、审核并打印、审核并发单 | 截图中只有"新建采购单"入口，创建页快捷操作未展示 | Hergent 创建页如果无下拉快捷，录单效率明显低 |
| 详情页操作 | 复制、转单为、导出、打印、上传附件、查看日志、上/下一条 | 代码里详情页操作待确认 | 舟谱把"转单""日志""附件"做在详情页，形成完整单据生命周期 |
| 退货入口 | 列表页直接有"采购退货订单"独立菜单 | 在采购列表用 `kind=return` 切换 | Hergent 更紧凑，但业务人可能找不到退货入口 |

**最值钱的交互差异**：
- **"复制"单据**：舟谱每行都能复制，对低温奶"每周向同一供应商下相似订单"的场景极省时间。
- **"转单为"**：舟谱详情页可把采购订单转成销售/车销/自提/调拨/采购退货单，实现"以采定销/以采定调"的快捷流程。Hergent 当前缺少这个业务闭环入口。

## 七、优化建议（按优先级排列）

### P0 — 立即做（1 个迭代）

#### 1. 列表底部增加汇总行
- **原因**：业务人查看采购单最关心"今天/本周进了多少货、付了多少钱"。没有合计行需要导出 Excel 再算，打断工作流。
- **具体改动**：
  - 前端 `InvPurchaseList.vue` 表格 `<tbody>` 末尾增加 `<tr class="total-row">`。
  - 显示：订单金额合计、入库金额合计、已结款合计、未结款合计（与舟谱同口径）。
  - 当列表被服务端分页切分时，汇总行应基于**当前页数据**（API 若支持 `total_*` 则更好，否则前端对当前页 rows 求和）。
- **影响范围**：仅采购单列表 UI，不涉及后端接口（若只做当前页合计）。
- **验收**：列表最下方出现"总计"行，金额与当前页行内数值一致。

#### 2. 创建时间快捷筛选按钮
- **原因**："查今天/昨天/本周"是最高频查询，每次打开日期选择器选范围浪费时间。
- **具体改动**：
  - 在"单据日期从/到"输入框前增加按钮组：今 / 昨 / 近7天 / 近30天。
  - 点击后自动填充 `date_from` / `date_to` 并触发 `load()`。
  - 默认状态不选中任何按钮；选中后高亮，可手动改日期。
- **影响范围**：仅 `InvPurchaseList.vue` 筛选区。
- **验收**：点"近7天"，日期框自动填近 7 天，列表刷新。

#### 3. 行内操作增加"复制"
- **原因**：舟谱每行都有"复制"，用于快速创建相似采购单。Hergent 当前只有"打印"，缺少这个高频操作。
- **具体改动**：
  - 在 `InvPurchaseList.vue` 操作列，"打印"旁增加"复制"文字按钮。
  - 点击后跳转到 `/inventory/purchase/new?copy_from={order_no}`，由新建页读取原单数据并填充。
  - 若新建页暂不支持 `copy_from`，可先实现"复制到剪贴板/提示"的降级方案，但建议直接跳转复用已有 `?copy=` 参数能力（代码里采购单详情/新建页已有 copy 逻辑）。
- **影响范围**：列表页 + 新建页（需确认 copy 参数解析）。
- **验收**：列表行点击"复制"，进入新建采购单页并带出原单数据。

### P1 — 中期做（2-3 个迭代）

#### 4. 详情页改为多标签结构（商品明细 / 货款 / 入库单）
- **原因**：舟谱把"钱、货、单"分开，避免单页过长；Hergent 当前若只有商品明细，查付款/入库需要滚动或跳转。
- **具体改动**：
  - 新建或改造采购单详情页组件（`InvPurchaseDetail.vue` 或类似）。
  - 顶部 Tab：采购订单详情 / 货款 / 入库单。
  - "货款"标签调用资金/付款记录接口；"入库单"标签调用入库记录接口（可复用 v477 之前已对接的入库查询能力）。
- **影响范围**：详情页组件 + 后端新增/复用 2 个查询接口。
- **验收**：从列表点击单据编号，进入详情页，三个标签内容正确。

#### 5. 详情页增加"转单为"功能
- **原因**：采购订单是供应链起点，常需要转成销售单、调拨单、采购退货单。舟谱把入口放在详情页，形成业务闭环。
- **具体改动**：
  - 在详情页顶部操作区增加"转单为"下拉按钮。
  - 选项：转销售订单、转车销订单、转自提订单、转调拨单、转采购退货单。
  - 点击后跳转对应新建页并带入原单商品/供应商信息。
- **影响范围**：详情页 + 各类型新建页（需支持 `from_po` 或类似参数，采购退货已有 `?from_po=`）。
- **验收**：在采购详情页选择"转采购退货"，跳转到采购退货新建页并带出原单数据。

#### 6. 详情页增加"查看日志"
- **原因**：单据谁改了、谁审核了、谁入库了，是业务纠纷时最重要的依据。舟谱有完整的订单日志 + 物流日志。
- **具体改动**：
  - 详情页增加"查看日志"按钮，弹出 Modal。
  - Modal 内分 Tab：订单日志 / 物流日志（或先只做订单日志）。
  - 订单日志字段：操作人、时间、事件、详细信息。
  - 后端新增 `purchase_order_logs` 表或利用已有变更记录能力；若暂无日志表，可先记录"创建/审核/入库/修改"四个关键事件。
- **影响范围**：后端新增日志记录/查询 + 前端详情页。
- **验收**：详情页点击"查看日志"，弹出窗口显示该单历史操作。

#### 7. 创建采购单页增加保存/审核下拉快捷操作
- **原因**：录单员连续录入多笔订单时，"保存并新增""审核并打印"能减少 50% 的页面切换。
- **具体改动**：
  - 创建页底部"保存"按钮右侧增加下拉箭头。
  - 下拉项：保存并新增、保存并复制。
  - "保存并审核"按钮右侧增加下拉箭头。
  - 下拉项：审核并新增、审核并打印、审核并发单。
  - 点击后顺序执行保存/审核 + 对应动作。
- **影响范围**：`PurchaseOrderNew.vue`（或对应创建页组件）。
- **验收**：选择"保存并新增"，当前单保存成功后清空表单继续录下一单。

### P2 — 长期/可选

#### 8. 商品明细增加"参考成本价"
- **原因**：便于采购时判断本次采购价是否异常。
- **具体改动**：详情页/创建页商品明细表增加"参考成本价"列，取自商品档案。
- **影响范围**：商品档案需有参考成本价字段；创建/详情页 UI。

#### 9. 增加单据来源、最后操作/打印审计字段

1. **不要照搬舟谱所有字段**：舟谱部分字段（供应商编码、最后打印时间）对低温奶经销商不是高频字段，加进去只会增加列设置噪音。优先做 P0 的三项。

4. **详情页多标签涉及后端接口**："货款""入库单"两个标签需要后端有稳定查询接口。若接口暂无，可先只加"商品明细"标签占位，避免前端空标签。
