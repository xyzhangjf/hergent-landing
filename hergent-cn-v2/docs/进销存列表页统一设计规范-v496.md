# 进销存列表页统一设计规范（v496）

> **基准页 = 采购订单列表页（`InvPurchaseList.vue`）**。本文把基准页已经沉淀的形态
> codify 成规范，并据此改造其余列表页。**规范不发明新交互** —— 每一条都能在基准页
> （或后端能力）上找到出处；找不到出处的写进 §9「有意差异」或 §10「待统一项」，
> **不许**为了"看起来一致"造没有后端支撑的假控件。

---

## 0. 适用范围与页面映射

进销存对外是 **6 个列表入口**，代码里是 **3 个组件 + query 分派**。改组件即改多页，
所以"对齐 6 页"的正确做法是对齐这 3 个组件的各 query 变体：

| 入口（侧栏） | 路由 | 组件 | query 分派 |
|---|---|---|---|
| 采购订单 | `/inventory/purchase` | `InvPurchaseList.vue` | `kind` 缺省 |
| 采购退货单 | `/inventory/purchase?kind=return` | 同上 | `kind=return` |
| 自提订单 | `/inventory/sale?type=self_pickup&kind=order` | `InvSaleList.vue` | `type` + `kind` |
| 自提退单 | `/inventory/sale?type=self_pickup&kind=return` | 同上 | 同上 |
| 车销订单 | `/inventory/sale?type=vehicle_sale&kind=order` | 同上 | 同上 |
| 车销退单 | `/inventory/sale?type=vehicle_sale&kind=return` | 同上 | 同上 |
| 调拨单 | `/inventory/transfer` | `InvTransferList.vue` | 无 |

**不在本规范内**：建单页（见 `进销存建单页开发规范-v441.md` 与 v449 拆页方案）、
单据详情页（`?tab=` 派生 tab 契约见 UI-SPEC §2.5.1）、进销存工作台。

**入口切换铁律**（v473 踩坑沉淀）：五个销售入口是**同 path 不同 query** ⇒ 组件会被
vue-router 复用，`onMounted` 不再跑。类型/种类**必须** computed + `watch`，
在 setup 里读一次的症状是"点另一个入口页面纹丝不动、零报错"。

## 1. 页面布局骨架（八段，从上到下）

| # | 段 | 规范 |

## 2. 表格列系统

### 2.1 宽度权威：`<colgroup>`（唯一）

- 表格挂 `class="tbl psi-tbl"`：`psi-tbl` 给出 `table-layout:fixed` + 单元格
  nowrap/ellipsis（全局唯一定义在 `src/styles/psi-list.css`，v496 建立）。
- **所有列宽写在 `<colgroup>` 的 `<col :style="{width:…}">`**；⛔ 不准在 scoped CSS 里
  再给列写 `width`（第二个真相来源，改一处必然漂移；v408 基准页的教训）。
- fixed 布局下声明宽度即硬值 ⇒ 内容超宽只能 ellipsis 裁，**不允许任何一格把列撑宽**
  （会顶开冻结列的 sticky 偏移）。

### 2.2 序号列（全站既有约定，UI-SPEC §2.6.1）

- `<th class="seq-th">` 内包 `.th-in`，**列设置齿轮是该格唯一按钮**；⛔ 不放工具栏。
- 序号取值 `offset + i + 1`（服务端分页 ⇒ 必须跨页连续；写 `i+1` 第 2 页从 1 重来）。
- 序号列**不在列清单里**：不可隐藏、不可拖序、不可删除。

### 2.3 列清单：core + 可选，云端持久化

- `core: true` = 恒显，**不进**云端显隐配置（单号/客户/金额/状态这类定位列）。
- 可选列的 `key` 一旦定下就是**云端列配置主键，禁止改名**（改名 = 把用户已存配置
  静默丢一次）。列 key ≠ 后端排序列名时，用 `SORT_KEY` 显式映射（§7.1）。
- 销售/调拨用共享件 `useColSettings(key, COLS)` + `ColMenuPanel`（简版：勾选 + 固定
  tag + 恢复默认）；基准页用完整版 inline 面板（拖序 + 冻结列下拉 + 自定义字段
  改名/删除/新增）。**两档面板的差异登记在 §10-T1**，未统一前各自保持原状。

### 2.4 冻结列（v496 上提全局）

- 全局类 `.psi-frz` + `.psi-frz-1..4`（位置 1~4），`left` 偏移由页面在 `<table>` 上用
  CSS 变量给出：`--psi-frz-1..4`。因为偏移 = 左侧各列宽之和，**每页列宽不同**。
- 基准页恒冻三列：复选框（1）/ 序号（2）/ 单据编号（3，`FIXED_FROZEN`，不可隐藏），
  另有用户可选的第二冻结列（4，`FREEZE_OPTIONS`：供应商/供应商类别/单据来源/不冻结）。
- 销售/调拨恒冻两列：序号（1）/ 单号（2）。单号是 `core` 恒显 ⇒ 偏移稳定。
- 冻结格必须**有自己的底色**（`td` 透明 ⇒ 横滚内容从底下透出来）：常态 `--bg`、
  行 hover `--bg2`、行选中 `--p-bg`，全局 CSS 三态各自覆盖。
- 表头冻结格 z-index 高于表体（9 vs 6），tfoot 冻结格取 7。
- 打印时 `position: static`（sticky 在纸上只会把几列叠一起）。

### 2.5 合计行（tfoot）

- 仅基准页有（后端返回 summary）。**跟随列设置**：每个可见列出一格，金额列落值，
  ⛔ 不写死 colspan（列被隐藏/重排后必错位，原 `colspan="8"/"6"` 的教训）。
- 打印稿里略去 tfoot（复选框/操作列被隐藏后 colspan 会错位）。

## 3. 筛选器

### 3.1 结构

- **常用筛选一行**（label 在上、控件在下，`.xxx-f` flex column）；项多时收进
  **「更多选项」折叠行**（第二行 `.xxx-frow-sub`）。判据：一行放不下才折 ——
  🔴 不造"永远为空"的折叠（调拨页只有 4 个筛选项 ⇒ 无更多选项，§9-D2）。
- 行尾右侧：`查询`（primary）/ `重置`（ghost）/ `更多选项`（ghost + CSS 三角 caret）。
- 单选/日期类 `@change="load()"`，文本类 `@keyup.enter="load()"`（不边打边拉）。

### 3.2 铁律：全部服务端过滤

⛔ 禁止前端 `filter`：三页都是服务端分页（`limit/offset`），前端过滤只作用于当前页
⇒ "筛选后还有 50 条"的假结果（v473 实录：2.2 万张单的页面）。日期/状态/客户/商品
等每一项都必须在请求参数里发给后端。

### 3.3 快捷时间档（五枚 chips）

- 共享件：`QuickRangeChips.vue` + `useQuickRange(f, load)`（v496 建立）。
  档位：**今 / 昨 / 近7天 / 近30天 / 全部**。
- 芯片复用全局 `.chip`（32px / 8px 圆角 / 令牌化 / 选中青实底）—— v482 已修掉基准页
  私有的 `.ipl-qbtn`（偏蓝硬编码、不跟主题）。
- `quickRange` **只用于高亮**；真实值落在 `f.date_from/date_to`（与既有口径一致）。
- 手动改日期框 ⇒ **清掉芯片高亮**（`onDateManual`），否则"芯片亮着但区间不对"。
- 「全部」= 清空两个日期框并重拉；`重置` 一并清芯片高亮 + 排序。

### 3.4 hasFilter 必须列全

`hasFilter`（决定空态说"还没有单据"还是"没有符合条件的结果"）必须包含**每一个**
筛选项 —— 漏一个的症状是"明明筛了商品、页面说一张单都没有"（v408/P1-3 教训，
基准页注释里有完整名单）。

## 4. 状态标识

- 状态徽标唯一口径：`constants/psiLabels.js` 的 `PO_STATUS`（7 态）/ `SO_STATUS`（7 态）/
  `TRANSFER_STATUS`（3 态），渲染为 `.tag` + `tagOf()` 的 `info/warn/ok/bad`。
  ⛔ 不发明后端不支持的状态值；零值页签照显（"这档现在是空的"本身是信息）。
- 页签计数：仅基准页（后端 counts，忽略状态筛选保留其它筛选 ⇒ 切页签数字不漂移）。
- 未知枚举值回落中文（`textOf(…, '未标注')`），⛔ 不许把英文键名裸呈给用户。

## 5. 操作按钮

### 5.1 行内操作（按状态 + 权限显隐）

| 页 | 行内按钮 | 依据 |
|---|---|---|
| 采购（订单视图） | 编辑 / 审核 / 反审核 / 取消 / 打印 / 复制 | 各有后端端点；`isEditable/canApprove/canCancel` 按状态门 |
| 采购（退货视图） | 审核 / 反审核 / 取消 / 打印 / 复制 | 退货单无"编辑"落点 |
| 销售 | 打印 | **唯一**有后端支撑的动作 |
| 调拨 | 打印 / 过账 | 过账 = `POST /complete`（草稿→已过账，真移库，带 confirm） |

⛔ **假控件禁令**：没有后端接口的按钮一律不摆（销售单没有审核流/批量接口；调拨没有
退单/取消接口）。摆了就是"点了报错"或"点了没反应"。

### 5.2 工具栏

- 右：导出 / 打印 / 批量操作▾（**仅采购** —— 后端只有 `batchPurchases`；
  批量结果逐单回报，失败带原因）。
- 批量动作（采购 7 项）：审核 / 反审核 / 取消 / 打印 / 标记 / 备注 / 发单（v481）。
- 打印 = 纯前端 `window.print()`；**打印数列仅采购**（后端 `batchPurchases('print')`
  记数）。⛔ 不造前端自增的假计数（刷新即归零）。

## 6. 分页器

统一结构（v496 起三页逐字同款）：

```
共 {{ total }} 条记录，第 {{ pageFrom }}–{{ pageTo }} 条 | ‹ 页码窗(≤7,当前居中) › | [N 条/页] | 跳至 [ ] 页
```

- 服务端分页：`limit`（默认 50，`PAGE_SIZES` 可选）/ `offset`。
- 页码窗：总页数 ≤7 全显；否则当前页居中取 7 个。
- 改"条/页" ⇒ 回第 1 页；跳页输入回车生效，非法输入忽略。
- 🔴 `offset` 必须在**三层委派链**（router → service → queries）逐层显式声明 ——
  FastAPI 未声明的 query 参数被**静默忽略**（v443/v473 实录：分页按钮只改文案不动内容）。

## 7. 排序 / 导出 / 打印铁律

### 7.1 表头排序（服务端）

- 点击三态循环：**降 → 升 → 取消**（第一下给降序，与"新单在前"默认观感一致）。
- `SORTABLE`（前端）必须 ⊆ 后端排序白名单（`_PO_ORDER_SQL` / `_SO_ORDER_SQL` /
  `_TRANSFER_ORDER_SQL`）**逐键一致** —— 后端对未登记键**静默回落 `id DESC`**，
  症状是"这一列点了没反应、零报错"（v470/v473/v478 三次实录）。
- 列 key ≠ 后端列名 ⇒ `SORT_KEY` 显式映射（`otype→order_type` 等）。
- 排序**不进** `f`（筛选对象）：会被带进 `hasFilter`（空态文案答错）、被「重置」清掉。
- 排序提示常显（`按 X 升/降序` + 一键清除）：排序键对应的列一旦被列设置隐藏，
  表头指示器就消失 ⇒ 顺序的来历变成**看不见的状态**（v470 建立）。
- 排序指示器：未排 `sort`（中性 ⇅，常显提示"能点"）→ 升 `arrow-up` → 降 `arrow-down`。
- 入口切换（`watch(query)`）⇒ 筛选归零 + **排序归零**（同一排序键跨视图语义可能不同）。

### 7.2 导出

- **跟随列设置**（顺序 + 显隐）：表里看到什么就导出什么。
- 取值走 `colText`（表格与导出同一口径）；空值 `''` ⇒ 界面显示 `—`（⛔ 不显示 `0`）。
- 范围 = **当前页全部行**；无行选择的页没有"导出勾选"一支（按钮 `title` 说清范围）。
- 文件名 `${标题}-${localDateStamp()}.csv`（**本地时区**，不用 `toISOString()`：
  北京时间凌晨 0–8 点会标成前一天）。

### 7.3 打印（`@media print`）

- 纸上只留数据表：页头/筛选/工具栏/分页器/列菜单/批量条全隐藏。
- 隐藏一切交互件：齿轮、排序指示器、复选框、操作列、关联列、tfoot。
- 冻结列 `position: static`；表格回 `table-layout:auto; min-width:0; width:100%`
  （fixed + colgroup 硬宽会溢出纸面）。
- 单张打印：`.print-one tbody tr:not(.print-target){display:none}`。

## 8. 空 / 载 / 错态

| 态 | 形态 | 文案规则 |
|---|---|---|
| 加载中 | `.state-empty` 加载中… | — |
| 错误 | `.state-error` + [重试] 按钮 | 必须带原因（`e.message`），⛔ 不静默空白 |
| 空态 | `.state-empty` + 新建按钮 | `hasFilter` 为真 ⇒ "当前条件下没有 X"；为假 ⇒ "还没有 X"。退货空态附**两条路**说明（直接新建 / 从已入库单转） |
