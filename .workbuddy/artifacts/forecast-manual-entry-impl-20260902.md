## 一、按维度落点（Q1–Q30 全做）

### 交互设计
- **Q1** 两条填报路径（导入汇总网格 / 草稿填报）补场景说明，澄清各自用途
- **Q21** 方向键在 `<input>` 内放行，跳格不再 `select()` 整选 → 可在格内改一位数字（原最大手感 bug）
- **Q2** `exitEdit` 有未保存改动时二次确认（本地草稿仍可恢复）
- **Q4** 新增行自动定位：翻到对应页 + 滚动居中 + 聚焦
- **Q22** 补全导航快捷键（Ctrl+X 剪切 / Home·End 行列首尾 / PgUp·PgDn 翻页 / Ctrl+↑↓ 跳列首尾）

### UI 布局
- **Q7** 编辑态默认分页（50/页），`rowShown` 已含分页逻辑；退出编辑复位 `pagingOn=false`，read-only 表恢复全量
- **Q8** 编辑态全屏 / 列筛选 chip 复用既有能力
- **Q9** 新增行左侧品牌色竖条（`.new-row` + `r._new` 标识，保存后清除）
- **Q28** 快捷键说明面板（首次进入编辑自动展开一次）

### 操作反馈
- **Q12** 进入编辑加载骨架屏（`loadingEdit`）
- **Q5** 保存后保留撤销栈（不再清空，可回退）
- **Q13** 区块粘贴后立即反馈非法格数
- **Q26/Q27** 保存失败分流提示 + 部分成功告知（商品已存/数量未存）+ 重试入口

### 表单校验
- **Q16** 增强：商品名称必填、单格数量上限 `QTY_MAX`、列内重复值提示
- **Q18** 粘贴数值解析失败保留原值并标红，不再静默归 0
- **Q25** 非法格汇成错误清单弹窗，点击定位跳转

### 输入效率
- **Q6** Ctrl+D 无选区时默认向下填充整列
- **Q19** 粘贴跳行计数提示（被过滤的空行）
- **Q23** 粘贴支持「客户×数量」交叉表（HEADER 映射补 qty 维度）
- **Q24** 撤销栈改增量快照 `{r,c,oldVal}`，去掉每次聚焦的全表 `JSON.clone`（栈深 200 → 常量级）

### 错误提示 / 易用性
- **Q3** 删除行 / 新建/改名重名 显式确认与提示（原静默无反应）
- **Q10** 窄屏卡片式降级（既有响应式）
- **Q11** `clearDraft(silent)` 拆静默版，保存成功不再弹「已放弃草稿」矛盾文案
- **Q14** 草稿恢复补主档字段 + 本地新增行统计（`draftRestoreInfo`），横幅如实写恢复范围
- **Q15** 草稿「保存草稿」去无说明 disabled，改为点击引导先审核
- **Q17** 保存用商品与数量矩阵同一份过滤结果，前置提示被忽略行（数据一致性最高优先级）
- **Q20** 表头识别阈值收紧（`known>=2` 易误判）
- **Q29** 编辑态与只读态列配置统一收口
