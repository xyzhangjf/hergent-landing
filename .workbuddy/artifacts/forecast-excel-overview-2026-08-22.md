# 订单汇总页 Excel 式电子表格增强 — 交付概览

## 完成内容
在 `hergent-cn-v2/src/pages/Forecast.vue` 的「预报订单模块」编辑矩阵上，增强为 Excel 式电子表格（保留原有列配置、复制 TSV、审核/只读视图不变），未引入任何第三方库（零许可证风险）。

### 新增能力
- **单元格选中**：点单元格 / 聚焦即高亮（蓝色描边 + 行/列头联动高亮），状态 `selected{r,c}`，对应 `<td>` 加 `data-r/data-c` 坐标。
- **键盘导航**：`Enter` 下移 / `Shift+Enter` 上移 / `Tab` 右移（到行尾换下一行）/ `Shift+Tab` 左移 / `Esc` 取消选中；不干扰文本输入的左右方向键与数字框步进。
- **右键上下文菜单**：右键任意单元格 → 上方/下方插入行、删除行、清空单元格；客户数量列还可「左/右插入列」「删除此列」；主档列仅可隐藏（不可删的给出提示）。
- **填充柄**：选中单元格右下角小方块，拖拽到目标单元格批量复制填充（主档列与客户数量列均支持）。
- **视觉**：选中描边、行/列高亮、网格线、冻结列保持；数字列右对齐、千分位（`fmt`）保留；移动端 `.table-wrap` 横向滚动自适应。

### 关键决策
- 采用「增强现有自研表格」而非引入 Univer/Handsontable/x-data-spreadsheet：商业 SaaS 零许可证风险、与现有 `cross` 数据模型/后端零映射成本、移动端已响应式、保留全部既有能力。
- 单元格导航用 Enter/Tab（非方向键），避免在 text/number 输入中劫持光标与步进。

### 修复
- 填充柄原本只在主档列 `<td>` 渲染（`selected.c===ci` 仅覆盖 0–9），导致数量列（c≥10）选中时无手柄 → 已在数量列 `<td>` 补同样的手柄条件。

### 验证
无头 Chrome 真机 E2E（`forecast-spreadsheet-e2e.cjs`）**7/7 通过**：进入编辑、单元格高亮、Tab 导航、`右键菜单`、`插入行生效`、`填充柄填充`、`只读复制按钮仍在`。
- 构建产物：`Forecast-C12dEEn8.js`，已部署 `/opt/hergent-cn-v2`。
