# 舟谱表厂家编码/分销价 批量灌入商品主档 — 交付概览（2026-08-22）

## 做了什么
把 `最新26年8月下单表8.18.xlsx`（舟谱）里 8.14→8.18 周期表的 **厂家编码（永辉代码）+ 分销价** 批量写入 Hergent 商品主档（生产租户 `tenant_1.db`），使预报交叉表的「一键复制下单」能直接输出厂家系统可识别的 `编码<Tab>数量`。

## 关键数据
- 源表：多周期滚动表（69 个 sheet，4月→8月），客户列从 12→26 个动态演化。**取最新周期** `8月14报单-8月18到货`（文件名 8.18 对应到货日），避免历史分销价误灌。
- 解析后唯一商品 148 个：89 有厂家编码、148 有分销价。按「条码 → 名称」去重合并（同名拆分商品如红桶恒滋/福宝条码相同，合并取同一编码）。
- 匹配生产库 `tenant_1.db`（430 商品，你的真实数据）：**143 个匹配可更新**（142 按条码 + 1 按名称），287 个未匹配（友芝友/新希望/简爱等非蒙牛品牌——舟谱表本就只含蒙牛系，符合预期）。

## 执行方式（低风险）
- 先备份：`cp tenant_1.db /root/.hergent-env/tenant_1.db.bak-<时间戳>`
- **只填充空字段**：仅当商品 `product_code`/`dist_price` 为空时才写入，**不覆盖已有值、不修改/删除任何商品行**。
- 结果：填充厂家编码 **89** 个、分销价 **143** 个。

## 验证
- 后端 health=200。
- **真机 E2E 7/7 PASS**：登录 → 进预报交叉表 → 含「厂家编码/分销价」列 → 点客户列头「⧉」复制 → 捕获到 TSV 文本 `1040411<TAB>12`（厂家编码即本次迁移灌入值），格式 = `厂家编码\t数量`，可直接 Ctrl+V 粘进厂家系统下单。

预报模块 → 交叉表视图 → 点任意客户列头「⧉」复制该客户，或点「⧉ 复制全部下单」复制所有客户 → 打开厂家系统下单页 Ctrl+V 粘贴即完成录单。
