# 预报订单管理 · 手动填报功能审查报告

- **审查日期**：2026-09-02
- **审查对象**：`hergent-cn-v2/src/pages/Forecast.vue`（预报订货管理）中的手动填报能力
- **审查方法**：精读真实源码（非运行态），按 7 个维度逐项核对，**每项均标注代码行号作为证据**
- **审查范围**：两条填报路径
  - **路径 A · 编辑网格**（内联 Excel 式）：`enterEdit`(L1960) → `loadEditGrid`(L1967) → `saveEdits`(L2129) / `onPaste`(L2188) / `pasteRegion`(L3212)
  - **路径 B · 草稿填报**（搜索加购 + 智能审核）：`viewMode==='list'`(L1250) → 搜索加购(L1266) → 智能审核(L1253) → 保存草稿(L1254)

## 一、结论先行

**功能能力本身已相当完整**——区块粘贴、Excel 式选区、撤销/重做、Ctrl+D 向下填充、拖拽填充柄、本地草稿、AI 建议、安全库存预警都已落地。**问题不在"缺功能"，而集中在三类**：

1. **大表格下的性能**（编辑态强制全量渲染 428 行 + 每次聚焦深拷贝全表）
2. **违背 Excel 心智的键盘行为**（方向键被拦截 + 跳格即全选，导致格内无法移动光标）
3. **静默降级与数据误导**（粘贴非法值静默归 0、保存成功弹"已放弃草稿"、草稿只恢复数量却称"已恢复未完成数据"）

> **P0 共 5 项**，其中 Q1（方向键/全选）与 Q2（全量渲染）直接决定用户**能不能顺畅录完一单**，建议优先处理（合计约 1.5 人日）。
