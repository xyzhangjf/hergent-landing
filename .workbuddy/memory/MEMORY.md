## 本机坑 → `topics/local-machine-pitfalls.md`(§10–§44)
🔴 `grep "A\|B"` 静默失效⇒`-e`；`&&` 短路；`| head -N` 截命中；`grep -rl` 只搜顶层；zsh 通配无匹配 abort；探针别放 `/tmp`。⚠️ **跨机不一致（v509 付学费）**：macOS **BSD grep 的 BRE 不支持 `\|`**（GNU 扩展），服务器 Linux 支持 ⇒ 同条命令本机**静默空跑**、服务器正常 ⇒ 一律 `grep -E "(a|b)"` 或 `-e a -e b`。🔴 **工作区文件会被静默回退** ⇒ 改长文档前先 `wc -l` 与 HEAD 核数。🔴 **rebase/FF 前查未跟踪的 `YYYY-MM-DD.md`**（v516 付学费：并行会话往 memory 加当天日志，未跟踪的当天文件会被 origin 新增挡住 ⇒ 备份 `/tmp` → 删除 → 合入 → 比对补回）。🔴 **ssh 里嵌 python `-c` 多层引号会转义错乱**（v517 学费：远端 `find('\"/inventory\":{')` 恒为空，误以为改动没进产物，实际本地解析一切正常）⇒ 远端要做的字符串解析**改在本地产物上做**，或写成脚本 scp 过去跑。
