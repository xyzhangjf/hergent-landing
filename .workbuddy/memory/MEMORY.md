## 本机坑 → `topics/local-machine-pitfalls.md`(§10–§44)
🔴 `grep "A\|B"` 静默失效⇒`-e`；`&&` 短路；`| head -N` 截命中；`grep -rl` 只搜顶层；zsh 通配无匹配 abort；探针别放 `/tmp`。⚠️ **跨机不一致（v509 付学费）**：macOS **BSD grep 的 BRE 不支持 `\|`**（那是 GNU 扩展），服务器 Linux grep 支持 ⇒ 同一条命令在本机**静默空跑**、在服务器正常（差点据此误判「新类名没进 CSS」）⇒ 一律 `grep -E "(a|b)"` 或 `-e a -e b`。🔴 **工作区文件会被静默回退** ⇒ 改长文档前先 `wc -l` 与 HEAD 核数。
