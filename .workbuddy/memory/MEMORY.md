🔴 **间距归一「收大留小」，别反着来**（v734）：判据不是「离不离 4 栅格」，是**这 2px 差人眼看不出看不出**。小间距 2/4/6/8/10/12 在密集区反复出现（`--sp-h6` 637 处里 **gap 占 255**）⇒ 看得出，6→8 等于全站多列容器重排 = 改设计；大间距 14/16/18/20 隔着整块内容 ⇒ 看不出，硬证据是 `--sp-h14` 与 `--sp-4` **同一条规则块共现 31 处**（作者自己也分不出层次）。**方向一律往上取整**（变小挤压 ⇒ 换行/裁切/溢出；变大只是页面变长）。令牌改值会撞契约的「基线自证」（`.card` 18→20 挂掉 `toolbar-density`）—— 那是**好失败**，改 `CARD_BASE` 常量 + 坏样本换成新令牌，别去改断言条件。
🔴🔴 **「用行高当高度」≠ 行距**（`height:15px;line-height:15px` 是垂直居中）。改 flex 三坑：`text-align:center` 对**匿名 flex item 无效**必须换 `justify-content`｜同块有 `text-overflow:ellipsis` 的**不能改**（文本变匿名 flex item ⇒ 省略号消失）｜`<select>` 不吃 `align-items`，`line-height` 是它唯一手段。加 `display:flex` 前必查它原本是否 inline（靠父级 grid/flex 被 blockify 才让 width 生效，普通 inline span 变 flex 会从「按内容宽」变固定宽）｜🔴 **护栏要三态**：命中 / 新增报错 / **冻结数用不满也报错**（只写上限 = 空白支票）。
令牌化最大的阻力是**契约**不是习惯（尺寸契约 `parseFloat` 遇 `var()` 得 NaN ⇒ 换令牌当场挂测试）｜🔴🔴 批量迁移脚本必须与护栏**共用同一套判据**，否则「改错 + 放行」同时发生（徽标 `height:15px;line-height:15px` 被改成 1.4 倍）｜行高令牌必须用**倍数**不用 px，`0`/`normal` 不是「行高为 1」｜护栏必须**双向**，说不清与邻居区别的档位不该存在（`checkLineHeightRamp`）｜缺的不是令牌是「令牌被使用」⇒ **护栏驱动采纳**｜对比度必 **alpha 合成后**算、四种底色全算（含 `--bg4`）、从最外层往内倒序叠｜焦点环别用 `:where()`（基类后加载吃掉 315 处，叠到 (0,2,0)），判焦点必发真 Tab、认 outline｜深色必须单独验，实心强调底+白字一律 `-solid`、文字侧 `-ink`｜亮青 `--p` 只能装饰（2.43）｜AA 下限使三级灰实际只能两级（`--t2`=`--t3`）｜判对齐只量 `Range…getBoundingClientRect()`（盒子差 0 ≠ 对齐），「全 0」先过阳性对照｜表头 sticky 必须有「限高 + overflow-y:auto」父级，**`freeze-page` 本仓不成立**｜`.ico{width/height}` 会压掉 `:size`（SVG 属性优先级最低）｜`:active` 别用 `transform:scale()`（重锚 fixed 浮层）｜判可见性用 `getClientRects()`｜**加载中显示一个结论比空白严重**（初始 `loading=true`、每块独立标志）｜测加载态只延迟 `fetch('/api/…')`，全局限速会假阴性｜骨架载体全站六种，清单先读源码｜状态标签病根是「三套并行」｜端点冻结/加列等 → 见本文件末节与 `impl-and-deploy-criteria`。 🔴🔴 **「输入框多出一层品牌色细框」先分清是"框"还是"环"，再问护栏认不认这个写法**（v749）：组框已用 `:focus-within` 画了 border+光晕，框内控件还吃全局 `outline:2px` ⇒ 圆角套尖角两层。**文本控件鼠标点击也匹配 `:focus-visible`**（能接键盘输入即可），所以不是"只有 Tab 才看得见"。判据三条：① 选 `:is(画环容器):focus-within :where(input,select,textarea):focus-visible{outline:none}`，特异性 (0,4,0) 压过全局 (0,2,0)；🔴🔴 `:focus-within` **必须紧贴容器右括号**，写成 `:is(...) :focus-within` 会多要求一层后代 ⇒ `.ipn-f > select` 不生效（v749 首版就"改一个漏一个"，供应商框因中间有 `.ipn-sup-combo` 侥幸好了）；② 内层**不许含 button/a/[tabindex]**（组框里的按钮没外层环可依赖）；③ 判"有没有环"看 **`outline-style`**，别看宽度 —— `outline:none` 的 computed width 是 `medium`(3px)，只看宽度会把修好判成没修。护栏 `tests/focus-ring-takeover.contract.mjs`（runner ㉞，双向登记：画环容器必须都登记 / 登记的必须还在画环；并反向守住"不许为消双环删掉全局环"）。查来源用 `CSS.getMatchedStylesForNode` 直接点名规则。

## 🔴 探针身份（v729，最易伪造「0 缺陷」）
🔴🔴 **登录态已迁到 cookie（P0-4）—— 老探针写法会静默跳 `#/login`**（v745 踩过）：`client.js:56` 的 `get token()` **恒返回空串**，`localStorage.setItem('hergent_v2_token',…)` 完全无效。必须用 `routers/auth.py:284` 那三枚 cookie：`erp_token`(httpOnly 真凭证) + `hergent_auth='1'`(前端守卫标记) + `hergent_tenant`。puppeteer 顺序：先 `goto(BASE+'/')` 拿域 → `setCookie(...)` → 再 `goto('#/forecast')`。判据：落在 `#/login` 且有 `input[type=password]` = 凭证没进去（**不是 token 过期**）。
hash 路由 URL 必须 `https://hergent.cn/#`+path，切换等 **3200ms**。token 过期 ⇒ **全部**页静默回退 `#/workbench`、用户名变「我」；**权限不足 = 只有部分页回退**、用户名正常。`probe_token.py` 旧版硬编码 user 1 = admin，而 `REPORT_VIEWER_ROLES=['boss','supervisor']` ⇒ reports/funds 被静默送回工作台。**boss = user 2**；插入前 `SELECT role` 断言。判通过前必须核对节点数量级与用户名。🔴 **「探针归位」≠「sessions 数量回到 1」**：用户可能同时在别处登录 ⇒ 判据是 `WHERE token LIKE 'sbxui-%'` = 0。抓图报「节点数仅 3 / 全屏差异」先当假差异重抓（v734 两次：白屏 36.89%→12.89%、`allProducts` 未到致按钮按 `v-if` 隐藏 31.38%→16.23%）。
🔴🔴 **服务器上 `/root/probe_token.py` 是旧版、硬编码 user 1（admin），命令行传 uid 无效**（v747 又踩）：`insert <tok> 2` 后 sessions 仍是 `user_id=1` ⇒ 症状**不是 401**，而是**侧栏只渲染 7 个区**（`REPORT_VIEWER_ROLES=['boss','supervisor']` 把仓配/资金/市场营销/**数据报表**整区滤掉）⇒ 探针报「数据报表未找到」，极易误判成「区被删了/图标 bug」。正确做法：直接 SQL 插 `sessions`（`user_id=2` 张俊峰/boss，先 `SELECT id,username,display_name,role FROM users` 核对），三时间列一律 `datetime('now','localtime')`。**任何侧栏/权限类探针第一条断言必须是「侧栏区数 ≥ 11」**，否则结论作废。
🔴 **截图走封装 `p.screenshot(path,{clip})`，别直接 `p.raw.send('Page.captureScreenshot')`**（v747）：后者返回 `{result:{data}}`，取 `.data` 恒 undefined ⇒ `Buffer.from(undefined)` 抛 `ERR_INVALID_ARG_TYPE`；且 clip 字段是 `x/y/width/height`（`w/h` 会被静默忽略）。侧栏 DOM：`.sidebar > .sb-nav > .sb-area`，区名 = `innerText` 第一行，区图标 = 区内第一个 `svg`。
