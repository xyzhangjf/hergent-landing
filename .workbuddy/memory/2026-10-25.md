## v672 采购单列表「复选框右边三个小点」（勾选列盒模型缺陷）

老板截图：采购单列表**每一行**（连表头）复选框右侧都多出「…」。

### 根因（不是伪元素、不是图标字体、不是省略文本）
三条**各自合理**的规则叠出来的：
1. `styles/psi-list.css` 给 `.psi-tbl th, .psi-tbl td` 加了 `overflow:hidden; text-overflow:ellipsis`
   ⇒ 这一格**具备画省略号的能力**；
2. `table.tbl td` 默认 `padding:10px 14px`，勾选列只有 36px（`CHK_W`）⇒ 内容盒 **8px**；
3. 复选框 13px ⇒ 溢出内容盒 **5px** ⇒ Chrome 按 `text-overflow` 在右侧补画「…」。

紧凑密度 `padding:2px 8px` ⇒ 内容盒 20px 不溢出，**所以只有默认密度看得见** ⇒ 从 v532
上提共享类那天起潜伏至今。销售 / 调拨两页用的是同一个 `.psi-chk`，**同样中招**（一起修好）。

### 修法
- `psi-list.css` 勾选列**左右内边距归零**（纵向不动，行高不变）。内容盒回到 36px，
  13px 复选框居中 11.5px，零溢出。
- `InvPurchaseList.vue` 私有 `.ipl-c-chk` 退役（它只写了 `text-align:center`，正是漏掉内边距的
  第二真相源），改用共享 `.psi-chk`；打印隐藏规则同步（全局 `@media print` 已覆盖）。
- 拒绝的治症状方案：`text-overflow:clip`（溢出还在，复选框一变大就复现）、加宽列到 44px
  （36 是冻结列 sticky 偏移 0/36/82 的基准，改了整套错位）。

### 🔴 第一版修错了（真机注入实测抓出）
只写 `.psi-tbl td.psi-chk{padding-left:0}`（(0,2,1)）⇒ 被**同文件更靠后**的
`[data-density=compact] table.tbl.psi-tbl td{padding:2px 8px}`（(0,3,2)）整块压掉 ⇒ 紧凑档
静默不生效（注入实测 compact 下 padding 仍是 8px）。正解：选择器写 `table.tbl.psi-tbl …`
且把 `[data-density="compact"]` 变体列进**同一组**（(0,4,2)）。
教训：**同文件内的密度档覆盖必须先算权重再下笔**，别默认「后写就赢」。

### 契约（run-all 第 ⑨ 组，19 条，扫全站）
`tests/chk-col-padding.contract.mjs`：唯一源归零规则 + 权重 ≥ 紧凑密度规则 + 含紧凑变体
+ 无 `xx-c-chk` 私有类 + 页面 scoped 不得覆盖 `.psi-chk` 盒模型 + 三页 `CHK_W=36` 且列宽
只由 `<colgroup>` 给 + **成因链自检**（从源码读列宽与基础 padding，复算「36−14×2=8 < 13」）。
判别力自证：删归零规则 ⇒ FAILED(1)；恢复 `.ipl-c-chk` ⇒ FAILED(2)；还原 ⇒ ALL PASS。

### 真机（生产 v672，两种密度同屏 A/B）
默认密度修复前 `overflowPx=+5px`、修复后 **−11.5px**（padL/padR=0）；紧凑密度 0px；
截图「…」消失。⚠️ **演示租户被能力闸门拦在进销存表体之外**（采购单 0 行 ⇒ 空态，`table:false`）
⇒ 真机测量用「真实页面 + 与模板逐字一致的表结构注入」，零写请求。
发布：`index-CPaTdoFs.js` / `index-C7nFBPeO.css`，index.html 与两者双侧 md5 全等。提交 `bdecfac`（未推）。
