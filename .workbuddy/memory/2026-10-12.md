#### 🔴 本轮踩到并修掉的一个**隐蔽探针缺陷**（值得单列）

生产探针初稿第一次跑出来是「20 条失败」，而且**每一条失败看起来都像产品坏了**（对照项不在、条目缺失）。
真因是注入脚本里的一行：

```js
// 错：在**模板字面量**里写单反斜杠
var path = url.replace(/^https?:\/\/[^/]+/, '').split('?')[0];   // 文件里是 \/ 两个字符
```

模板字面量会把 `\/` 折叠成 `//` ⇒ 展开成 `url.replace(/^https?://[^/]+/, ...)` ⇒
正则字面量在**第二个 `/`** 处提前闭合 ⇒ `SyntaxError: Unexpected token '^'`。
🔴 **杀伤力在于：语法错误发生在解析阶段 ⇒ 整段 `addInitScript` 被浏览器丢弃**
⇒ 连同一段里的 `localStorage.setItem(token)` 都没执行 ⇒ **页面根本没登录** ⇒ 没有侧栏
⇒ 探针输出十条莫名其妙的 ❌，而真凶躺在 `page.errors` 里没人看。

三条修法（都写进脚本注释了）：
1. **注入脚本内禁用任何反斜杠**：用 `indexOf('://')` + `indexOf('/')` 手撕 origin/query，不用正则。
2. **注入自检**：脚本末尾写 `window.__probeInit='ok'`，探针启动即断言 —— 让这类错误**当场炸**，绝不伪装成十条 ❌。
3. ⚠️ **`v472-prod-boss-gate-verify.mjs` 是好的**：字节级核实它写的是 `\\/`（**双反斜杠**，已为模板字面量
