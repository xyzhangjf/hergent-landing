## v668｜筛选面板只有「（空白）」＝ 列对象没有 type（2026-10-30 21:0x，用户截图报障）

**现象**：用户发来截图 —— 打开「厂家编码」列头漏斗，值清单只有一项「（空白）」，计数 `1 / 1`，勾什么都不动。

**根因（一处，波及全部主档列 + 全部计算列）**：
`colByKey` 用 `visibleCols` 建 Map，而 **`visibleCols` 的元素没有 `type` 字段**
（它的 map 只搬 key/label/cls/fixed/edit/fmt/options/custom，见 visibleCols 定义）；
`cellText()` 的分支是 `col.type === 'master'` ⇒ type 为 undefined 时一路漏到末尾 `return ''`
⇒ 该列**每行取值都是空串** ⇒ 值清单去重后只剩一个空值＝「（空白）」。
只有 `colOrderList`（查看态渲染用）才带 `type: 'master'|'qty'|'calc'|'seq'`，且**计算列只在那里**。
⇒ 客户列（`type:'qty'` 走 qtyByUnit 分支）与计算列（走 cellValOf 兜底）没被波及，故一直没被发现。

**修法**（Forecast.vue）：
- `colByKey`：`visibleCols` 逐个补 `type:'master'`（`c.type ? c : {...c, type:'master'}`），
  再把 `colOrderList` 里缺的（计算列）按 `type:'calc'` 补进 Map。仍然每帧只建一次，不退化。
- `cfRowVal`：主档列取值 `==='—'` 时归 ''。网格里"空"显示为 `—`（`masterVal`/`arrivalCycleText` 约定），
  筛选口径必须当空 ⇒ 否则同一列同时有「（空白）」与「—」两个桶，用户分不清哪个才是没填的行。
- 顺带：`全选` 复选框加 `:indeterminate.prop="fxChecked.length>0 && !fxAllOn()"`（部分勾选不再长得像"一个没勾"）。

🔴 **可复用判据**：`visibleCols` 与 `colOrderList` 是**两套列对象**，前者给改单网格（带 edit/options），
后者给查看态渲染（带 type）。**任何按 `col.type` 分支的取值都必须走 colOrderList 那一套**，
或自己补 type —— 否则静默返回空串，不报错。
