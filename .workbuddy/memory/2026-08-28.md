## 预报汇总表品牌选择器点击闪退（Bug 修复）
- 用户报障：预报订单汇总表里的品牌选择器点击后闪退（标签页崩溃/白屏）。
- 真机复现（agent-browser 无头 Chrome + demo 登录 hergent.cn/#/forecast）：编辑网格品牌列是 `<input list>`+`<datalist>`（Chrome 识别为 combobox）。单独点开/选值/展开在 demo（2 品牌、~12 行商品）均**不崩、无 JS 错误**；后端临时插 200 品牌压测仍不崩——说明 demo 行数少复现不了。
- **根因**：编辑网格**每一行都独立渲染一份含全部品牌选项的 `<datalist id="opt-brand">`（id 重复 + 海量 DOM）**。真实用户 ~430 商品 × 200 品牌 ≈ 8.6 万 `<option>` 节点，点击展开 datalist 时标签页崩溃（"闪退"）。单位列选项少不触发；品牌列选项多才暴露。这是 D2 给品牌列加 datalist 下拉候选时引入的副作用。
- **修复**（Forecast.vue 681-686 模板）：datalist 仅首行(`ri===0`)渲染一份共享实例，所有品牌 input 的 `:list="'opt-'+c.key"` 统一引用它；option 节点从「行数×选项数」降到「选项数」（430 行场景从 ~8.6 万降到 200），并消除重复 id 的 HTML 规范违例。单位等其它带 options 列一并受益（总 datalist 从 N 行份降到每列 1 份）。
- **验证**：build + rsync 至 /opt/hergent-cn-v2；无头浏览器真机确认 `datalist#opt-brand` 份数=1（修复前=行数）、总 option=210（品牌200+单位~10）、200 品牌下点开+展开**不崩、无 JS 报错**。已清理压测的 200 品牌恢复 demo 干净。
