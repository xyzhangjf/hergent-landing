### 追加修正：合计行吸底在 Mac 可能失效（border-collapse 坑）
用户追问「合计行吸底做了吗」。代码层面 P1-3 已做（tfoot + .col-total.sticky），本轮保留；但 sticky 原本写在 `<tr>` 上，而 `table.tbl{border-collapse:collapse}`（variables.css:165）会令 sticky 在 `<tr>/<tfoot>` 上于 Safari/部分 Chrome 失效 → Mac 用户很可能不吸底。表头 sticky 写在 `<th>` 单元格上（稳），表尾写在 `<tr>` 上（脆弱），不一致。
- 修复：`.col-total.sticky{...}` → `.col-total.sticky td{position:sticky;bottom:0;z-index:9;...}`（与表头一致，cell 级 sticky 不受 border-collapse 影响）。编辑模式表尾 `.foot-row td` 本就 cell 级，无需改。
- 重建 `npm run build` ✓ → Forecast-o5Z9bo7o.js + Forecast-PIBc2Jgp.css → rsync + chown → 生产 CSS 已含 `col-total.sticky td{position:sticky;bottom:0;z-index:9...}`。
- 结论：合计行吸底**原本就写了，但存在 Mac 不生效的真实风险，现已修正为稳健实现并部署**。仍待用户真机滚动确认视觉效果。
