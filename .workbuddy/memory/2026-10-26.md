## v687 建单页「占位文案整洁化」（老板口径）

**需求**：把建单页「先选供应商 / 先选客户 / 请选择原因」这类文案隐藏，保持页面整洁。

**做法：收文案，不收反馈。** 收掉三条常驻占位，但三条解释通道全留：

| 通道 | 落点 |
|---|---|
| 格内常驻文字 | ❌ 收掉（`ProductCombo` / `PurchaseOrderForm` 锁定态留空；零价原因空选项 → `—`） |
| `title` 悬停 | ✅ `disabledHint` / `title="零价出库必须选择出库原因"` |
| 点击 toast | ✅ `blocked` → 「请先选择客户，再选择商品」（v686 已有，未动） |
| `validate()` 兜底 | ✅ 「零价出库必须选择出库原因」（未动） |

- 已填过商品的行**照旧显示商品名**：锁的是「不能再改」，不是「不许看见」。
- 锁定态光标仍 `not-allowed`、仍可键盘聚焦 —— 无字的替代信号，没一起收。
- `InvSaleNew.vue`（死页）同步改，免得两处写法打架。
- **未收**：调拨页「请选择调出/调入仓库」、采购退货页部门「请选择」、原单下拉 —— 属「未选状态标识」，
  改了会让下拉首项空白（比有字更迷惑）。已列给老板，等他定。

**契约判据的坑（本轮新增经验）**：断言「格内不许有字」**不能扫整个标签** ——
`:title="disabled ? disabledHint : ''"` 挂在同一个 `<span>` 上，扫全标签会把 title 一起判死。
正确写法：只取 `>` 之后的插值 `(span.match(/>({{[\s\S]*?}})<\/span>/)||['',''])[1]`，
再断言插值里不含 `disabledHint`，另加一条「title 必须还在」。

**验证**：组 ㉑ 67 → **76 条** 全绿；run-all **21 组 ALL PASS**；真机 **77 PASS / 0 FAIL / 3 SKIP**。
**部署**：全量 assets + index.html，双侧 md5 逐字节一致（entry `index-D93ystn0.js` `ad5aaa32…`）。
**提交**：`809adfc`。

## v688 采购建单表 125% 缩放下不再横滚（老板选 A）

**背景**：v687 之前实测出采购建单表 `min-width:1372px` 是按 1920 视口算的，
1536（=1920×125%）下容器只有 1248 ⇒ 横滚 124px。老板选 A（从根上重分列宽）。

**关键技术发现**（比结论本身重要）：
`table-layout: auto`（全局 table.tbl 只有 width:100%，没 fixed）下**列宽是被内容撑开的**，
改 width/min-width 声明基本无效 —— 只降 min-width 时空行 1248、填上 16 字商品名立刻弹回 1304。
必须 `max-width` + 内部文本 ellipsis 同时给，才压得动。

**改动**：
- PurchaseOrderForm（13 列）：`@media (max-width:1680px)` 内 min-width 1372→1200、
  商品列 min+max-width 200 + `.ipn-v` 省略号、行备注 max-width 100。
- PurchaseReturnForm（7 列）：**独立组件**，自带一份 1372 ⇒ 单独降 1200
  （第一版漏了，真机复测发现退货页仍 1372/1248 才补）。
- 数字列（条码/价格/数量/金额/库存/批次）一个没压 —— 截断=读错金额。

**验证**：1536 下订货/退货均 1248/1248 ✅；最不利密度 13 列零截断、行高 30px 不变；
1920 对照各列逐项不变（商品 442 / 备注 150）；回归 77 PASS / 0 FAIL / 3 SKIP；run-all 21 组 ALL PASS。
**部署**：双侧 md5 一致（entry `index-C0wErDLq.js` `5eeae656…`）。**提交**：`f1cba77`。

**遗留**：1440/1280 视口仍横滚（13 列最不利需 1219px，数字列已到底，物理装不下）。老板设备 1536/1920 不受影响。
