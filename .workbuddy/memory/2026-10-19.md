## 07:30 v608/v609 撤掉多余的「品牌 ∈ N 个」筛选胶囊
用户原话：「我刚看仅显示有报单那一行下面又多了一个显示品牌个数的按钮，品牌筛选按钮自带已选品牌个数，这个不需要啊」

### 🔴 判据：工具栏控件已经表达过的状态，不要在下方的 filter-row 再复述一遍
- v607 我把 `filter-row` 的 `v-if` 补上了 `brandSel.length`，理由是「勾了品牌看不到筛选条」——
  **这个判断是错的**：工具栏「品牌」按钮本身有 `.btn-badge` 数量角标、面板内还有「全选 / 清空」，
  清除途径一样不缺。多出的一条 `品牌 ∈ N 个 ×` 只是把同一个数字说了第二遍。
- 同类风险：任何「状态胶囊 / 筛选标签」上线前先问一句——**这个状态在触发它的控件上是否已经显示？**
  已经显示就别加。用户是非技术老板视角：多一行字就是多一行噪音。
- 改动：查看态 + 编辑态两处 `v-if` 去掉 `brandSel.length`、并删掉品牌胶囊本体。`filter-row`
  现在只服务「列筛选 / 唯一值筛选」（这两类在表头没有任何角标提示，所以必须留）。

### 🔴 删掉控件必须同步清掉「指路它的文案」
v608 上线后探针 B2 打出的 toast 仍是「…或点**筛选条上的 × 清空品牌筛选**」——
指向刚被删掉的控件，用户照着点会找不到东西。v609 改为「点工具栏「品牌」→「清空」」。
判据：**删 UI 时 grep 它的中文引导词**（`筛选条` / `点 ×` / `按钮`），不要只删 DOM。
