## 报单映射新建抽屉输入框重叠修复（2026-08-26 晚）
- 现象：新建/编辑抽屉里输入框挤在一起、部分叠在一起。
- 根因：全局 `src/styles/variables.css:133` 已把 `.fld` 定义为输入框控件样式（`height:32px;padding:0 10px;border:...`）。ReportMapping.vue 的 `<style scoped>` 把 `.fld` 当字段容器只重写了 display/flex-direction/gap，未覆盖全局 `height:32px` → 容器被锁 32px 高，内部 label+input(36px)+hint 溢出重叠。
- 修复：组件内容器类 `.fld`→`.field`（全局无此类，彻底解耦），并补 `width:100%;box-sizing:border-box` 兜底。模板 7 处 `<div class="fld">`→`field`；scoped 样式 5 条 `.fld*`→`.field*`。
- 验证：组件内 grep `fld` 无残留；`npm run build` 成功（chunk ReportMapping-XHuBvLm9.js）；rsync+chown 部署生产 DEPLOY_OK。
- 教训：本仓库 `variables.css` 已有大量通用类（.fld/.btn/.card/.tag/.tbl...），新增页面写 scoped 样式时**严禁复用这些全局类名作容器/语义类**，必须自查 variables.css 是否同名，否则会静默继承全局控件样式。

## 报单映射 403 根因与修复（2026-08-26 晚，接上一节）
- 现象：新建映射点员工下拉，页面提示"请求失败403"（非上一节的"空下拉"，是另一种失败）。
- 真因：后端有**第二套 RBAC 中间件**（server.py:591 起），按 `_PATH_MODULE_MAP`（server.py:311）把每个 `/api/*` 前缀映射到模块，未登记的路径一律 403 `MODULE_NOT_CONFIGURED`。报单映射 8 个端点（`/api/report-mappings*`）**全部没登记进这张图** → 一访问就 403。上一节"空下拉"其实也是这同一个 403（请求被拦，下拉自然空），"演示库缺员工"只是叠加问题，真凶是 MODULE_NOT_CONFIGURED。
- 另查：`_TENANT_REQUIRED_PREFIXES`（server.py:54）在中间件里**根本没被引用**（仅定义），加它无效——之前文档记"已加白名单"是错记。真正的门禁是 `_PATH_MODULE_MAP` + `_check_perm`。
- 修复：在 `_PATH_MODULE_MAP` 末追加 `"/api/report-mappings": "data"`（档案类归 data 模块；boss/admin/staff 均持有 data 读+写权限，tenant_1 真实 boss 与 tenant_10 demo 管理员都通得过）。`python3 -m py_compile` 通过；`bash deploy.sh` 部署重启。
