## v708（2026-11-01）窄屏两个尾巴：顶栏用户名竖排 + 角色下拉半截截断

**诉求**：用户回「修」——指向上轮末尾如实标注的两处 375px 问题。

### ① 用户名「张/俊/峰」竖排
根因不是字号、不是 padding，而是**裸文本节点是匿名 flex item**：
`{{ store.user.name }}` 直接放在 `.tb-user`（flex）里，空间不足时被压到 1 个字宽 ⇒ 逐字换行。
- 名字包 `<span class="tb-user-name">`；`.tb-user` 加 `flex-shrink:0` + `max-width:180px`
- 🔴 `text-overflow:ellipsis` 要对 flex item 生效**必须**配 `min-width:0`（默认 `min-width:auto`
  会撑到内容宽，省略号永远不出现）
- `.tb-btn` 也加 `flex-shrink:0`：空间不够该从 `.tb-brand`（有 `flex:1`）让，不是压扁图标
- 顶栏加 `title`，过长时可见全名

### ② 窄屏腾空间（375px 实测各元素合计 ≈ 450px ⇒ 必然溢出）
- `.topbar` 窄屏 gap 16→8、padding 20→12；`.tb-user` 上限 96px
- 🔴🔴 **`@media` 不提高优先级 —— 这是本次最值钱的一条**：
  Shell.vue 里那条 `@media(max-width:768px){.wx{display:none}}`（隐藏天气）**从没生效过**。
  双重原因：① `@media` 不改变特异性；② scoped 把它编译成 `.wx[data-v-<Shell>]`，
  而天气元素带的是它自己的 scope 属性。**结论：跨组件的样式覆盖写在目标组件自己的文件里**，
  靠「同文件内后写者胜」才可靠。改完在产物里确认 `display:flex` 在前、`@media{display:none}` 在后。
- 新增 ≤360px 断点：让出品牌文字只留 logo，用户名上限 80px

### ③ 角色下拉（`appearance:none` 抹掉原生箭头却没补）

- 🔴 必须写 `background-color` 而不是 `background` 简写 —— 简写会把 `background-image` 一起重置掉

### 🔴🔴 一个新坑（值得单独记）：规则「存在 + 命中 + 不生效」
`.df-acc-row select[data-v-x]{flex:1 1 100%}` 在产物里、selector `matches:true`，
但 `getComputedStyle` 仍是 `1 1 0%` —— 因为 `.df-acc-row .input, .df-acc-row select` 与它
**同为 0,2,1**，压缩后前者反而在后 ⇒ 后写者胜。加 `.acc-role` 提到 0,3,1 才真生效。
⇒ **CSS 改完别只 grep「规则进产物了」，要量 computed 值**；同特异性时顺序决定一切，
而压缩后的顺序不一定等于源码顺序。

## v709：品牌筛选弹窗「全选」从裸复选框升级为带文字的控件

### 用户原话与真实原因
「请给本期预报—品牌筛选弹窗加一个全选按钮，现在只有清空按钮」——
**功能 v671 就有**（`SelectAllCheckbox.vue` 三态框早挂在同一个 `.bp-acts` 里），
但它是一颗 **13×13、无任何文字**的裸 checkbox，夹在 12px 灰字标题与橙色下划线「清空」之间
⇒ 用户认不出来「这是个能点的全选」= **等于没有**。
判据：**可识别性也是功能的一部分**；用户报「没有某功能」先核功能是否存在，
存在就查它是否**不可发现**（无文字 / 无边框 / 权重低于邻居 / 13px 贴边）。

### 改法（最小侵入，不动全站唯一源）
`Forecast.vue` 4 处（品牌×2 查看态+改单态、到货周期×2 同构）：
```html
<label class="bp-selall" :class="{ 'is-off': !brandCandidates.length }">
  <SelectAllCheckbox .../>
  <span>{{ brandAllOn ? '取消全选' : '全选' }}</span>
</label>
```
+ `.bp-selall` 7 行样式（inline-flex / 12px / `var(--t2)` / hover 变主色 pill / is-off 降透明）。
文字随三态切换（全选 ↔ 取消全选）；点文字靠 label 原生转发，**没写一行 JS**。
⛔ 不改 `components/SelectAllCheckbox.vue` —— 库存三单据 / 商品档案 / 调拨面板
横向空间本来就紧，加文字会把那些页的裸框全部改样。

### 验证（生产真机 22 项 ALL PASS）
- label 52×17、文字 12px == 清空 12px、顶边差 **0** / 垂直中心差 **0**、头部高仍 22
- 点文字 → 5/5 全勾、角标 5、文字变「取消全选」、全选框 checked 且非 indeterminate
- 再点 → 归零、角标消失、文字回「全选」；点 13×13 方框本身同样生效
- 面板 660×230 未越出视口；**宽度归因实验**：隐藏 label 文字后宽度 660 → 660
  ⇒ 撑宽源是底部 `.bp-tip` 长文案（`.brand-pop` 只有 min-width 没有 max-width），不是新控件
- 到货周期弹窗同构 3 项 PASS

### 🔴 两个新坑（都值得单独记）
1. **`cdp-lite` 的 `screenshot(path, {clip})` 不带 `scale` 会静默返回空串**
   —— CDP 侧报错被 `if (!data) return ''` 吞掉，文件根本不落盘，而脚本 exit 0。
   判据：截图函数**返回值必须打印并判空**，否则「截了但没落盘」看起来像成功。
   定式：`clip` 里补 `scale: 2`（顺便拿到 2x 图）。
2. **面板变宽要归因，不要拍数**：先量 `before`，把新控件临时 `display:none` 再量 `after`
   —— 相等即证明宽度不是它撑的。比「我觉得 660 太宽」靠谱。
