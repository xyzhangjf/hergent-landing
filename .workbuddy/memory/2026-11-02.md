🔴 **最该记住的一条：`position:sticky` 只写声明没用，必须有「有限高 + overflow-y:auto」的容器当舞台。** 全局 `.table-wrap` 只有 `overflow-x:auto`、**没有 max-height** ⇒ 容器高度＝内容高度 ⇒ 永不纵向滚 ⇒ sticky 无吸附空间 ⇒ 等于没写。`freeze-list` 之所以可靠，就因为它自己带 `max-height:calc(100vh-240px)`（v512 立的），不依赖任何页面的 flex 高度链。这与 v513 记过的「`.page` 高度 auto ⇒ flex 链解析不出确定高度」是同一个病根。
- 🔴 **第二种失效：写在 `overflow:hidden` 祖先里**。该祖先成为 sticky 的「最近滚动容器」但不滚 ⇒ 静默失效。`ProductTarget` `.pt-card{overflow:hidden}` + `.pt-wrap{overflow-x:auto}`（无限高）双重吃掉它的 `.pt-tbl th{sticky}` = **假冻结**。`InvPurchaseDetail.vue:542` 早有注释记过这个坑（把合计行移出 `.ipd-plain` 才修好）。
- 🔴 **`.tbl-wrap` 这个类在全站 CSS 里根本不存在**（`CronJobs.vue:53` 只在模板里写了一次）⇒ 等于裸 div，既不限高也不裁切。**「类名写了」≠「样式存在」，判样式缺失要 grep CSS 而不是 grep 模板。**

**真机读数（59 页 → 28 页有表 → 35 个表）：✅钉住 12、🔴滚走 4、不适用 19。** 滚走 4 组：告警历史 50 行（容器 2081/2081 完全没限高）、招标雷达 50 行（3181px 高）、员工档案业务员表 28 行（**同页另外两张都冻了，只有这张漏**）、定时任务。另有**建单/退货 9 个明细表**：默认 15 行不超视口测不出，用**行注入到 45 行**逼出——表高 1341 > 视口 900、`thPos=static`、表头位移 **400px**。对照组采购单列表同一实验下 `643/1612 + sticky + gap 恒 1px` 完美钉住。

🔴 **探针两坑（第一版都踩了，都导致假阳性）**：
1. **判「已冻结」不能只看 `getComputedStyle(th).position === 'sticky'`** —— 商品目标、定时任务就是这么被误判成「已冻」的。必须**内滚一段再测表头位置**（判据：容器内滚 400px 后表头相对容器顶的 gap 不变）。
2. **表格高但容器不滚时，要滚「实际的滚动者」，不能固定 `window.scrollTo`** —— 本项目滚动者常是 Shell 的 `.view-wrap`（`817/14904`），window 根本滚不动 ⇒ `y0===y1` ⇒ 被判成「钉住了」。告警历史第一版就是这么漏掉的。正解：向上找第一个 `overflow` 非 visible **且** `scrollHeight>clientHeight` 的祖先。
3. 附带：**页面无数据时表格 `v-if="rows.length"` 整块不渲染** ⇒ 真机扫出 0 个表是正常的，不是「这页没表格」（59 页里 28 页有表）。空数据页只能按结构判定，清单里已逐条标注证据等级。
