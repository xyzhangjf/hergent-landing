## 招投标雷达「看不到新增」UI 语义修复（21:20+，已部署）

- **背景**：上一轮已定位「看不到新增」= 非系统故障、非真实数据缺失，而是前端「按浏览器当天」指标白天恒为 0 的误导（cron 每日 07:10 抓取，白天公告次日才入库）。用户回「要」→ 落地三处 UI 修正。
- **改动**（`hergent-cn-v2/src/pages/BidRadar.vue`，纯前端、不动后端、不动金额/脱敏口径）：
  1. KPI「今日新增」→「近 3 日新增」（`date_from=RECENT_FROM`=TODAY-2 的独立轻量查询，sub 改「最近 3 天发布」）；
  2. 「新」角标逻辑 `it.date===TODAY` → 近 24h **或** 自上次打开后新增（`localStorage` 记 `br_last_visit` 时间戳，按 `created_at` 判）；

  4. 快速筛选「仅看今日新增」→「仅看近 3 日新增」（筛 `RECENT_FROM`）。
- ⚠️ **踩坑（重要）**：同一消息对**同一文件并行发多个 Edit** 会互相读旧内容、后写覆盖前写 → 只有其中 1 条生效、其余被回滚（表现为 grep 仍见旧引用）。**改同文件多处一律用整文件 `Write` 重写**，或串行单 Edit。已规避。
