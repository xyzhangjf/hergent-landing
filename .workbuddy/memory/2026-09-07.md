## 评估：NeoBrowser 与舟谱无 API 问题（用户发来公众号文章）
- 结论：NeoBrowser（Rust MCP server，驱动本机真实 Chrome、复用真实登录态、真指纹过 bot 检测）**只解决"进不去"，不解决"没有 API"**——数据仍靠 UI 抓取，无 schema，改版即断。
- 架构硬约束：MCP stdio 须与 agent 同机；Hermes 生产在 Linux 云服务器（无桌面 Chrome/登录态）→ NeoBrowser **只能跑终端用户本机**，成不了 Hergent 云端统一接入层。
- 定位：**自用可做**（老张自己的账号/数据/机器，把手工导出自动化，接入口径仍是 Excel 上传，Hergent 侧零改动）；**对客户只做"客户侧本地采集器 + 只上传 Excel"并书面授权，不托管客户账号**；**不做服务端爬虫**（ToS + 封号风险 + 红线③）。
- 风险：项目 2026-08-18 发布、HN 有质疑（vibe-coded、疑似泄露密码）、curl|sh 供应链；`NEOBROWSER_REAL_PROFILE` 会把整个 Chrome 登录态交给 agent → 若试必须用独立 profile `NEOBROWSER_PROFILE=zhouspu`，不开 REAL_PROFILE。
- 探针三问（动手前）：① 舟谱登录有无验证码/登录态保持几天 ② 报表页有无「导出 Excel」按钮（无则只能抄 DOM，成本翻倍）③ 每天 1 次是否触发风控。

## 公众号能否 API 直接发布（2026-09-07 查证，权威现状）
- 链路四步：`GET /cgi-bin/token`（AppID+AppSecret）→ `media/uploadimg`（正文图必须先传，换微信自家 URL，外链会被过滤）→ `draft/add` 建草稿 → `freepublish/submit` 发布。
- ⚠️ **2025-07 起微信回收个人主体、未认证企业主体、不支持认证账号的 `freepublish` 权限**（官方文档「适用范围」标注：仅企业主体已认证可调用）。→ **个人/未认证号最多只能自动进草稿箱，最后一步必须人在后台或公众号助手点发布。**
- ⚠️ `draft/add` 官方文档标"公众号/服务号都 ✔"，但开放社区大量实测：未认证/个人号返回 `48001 api unauthorized`，且个人号接口日调用额度可能是 0。**以实调返回码为准，别信文档表格。**
- ⚠️ **IP 白名单**：access_token 只认后台白名单里的出口 IP；家宽/办公网动态 IP → 每次换 IP 要重配，是"无人值守"最大障碍。
- 凭据风险：AppSecret = 公众号近乎完全控制权（32 位 hex，`^[a-f0-9]{32}$`）。若落地必须本机加密存放（Keychain 或 chmod 600 的 .env），绝不进 git。
- 备选零凭据方案：产出**内联样式 HTML 一键粘贴版**，用户手动粘进公众号编辑器（格式保真、零权限零风险）。
- 结论：能否"直连发布"取决于用户公众号主体与认证状态，需先问清（个人 / 企业未认证 / 企业已认证）。
