## 一、弹窗通用形态（9 张归纳）

- 一级项右侧弹**白底圆角卡片 + 投影**；面板内**分组横向并排成列**。
- 列标题粗体置顶 + 标题下细分隔线；列间纵向分隔线；**列宽随条目自适应**。
- 需要新建的条目右侧带蓝色文字小按钮「创建」（采销/仓配/资金/财务/档案皆然）。
- 空列不占位。列底部偶有流程示意小图标行（装饰性，不复刻）。

## 二、七个弹窗全量条目

### 采销管理（6 列）
- 综合管理：综合订单[创建]、单据中心
- 访销管理：访销订单[创建]、访销退单[创建]、返配订单
- 车销管理：车销订单[创建]、车销退单[创建]
- 自提管理：自提订单[创建]、自提退单[创建]
- 采购管理：采购订单[创建]、采购退货订单[创建]
- 调拨管理：调拨订单[创建]

### 仓配管理（4 列）
- 仓库作业：入库单、出库单、拣货单
- 配送作业：配送单、司机任务看板、线路设置
- 库存作业：盘点盈亏单、静态盘点单（整仓）、静态盘点单（部分）
- 库存查询：库存查询[创建]、车辆商品查询、临期预警表

### 资金管理（4 列，面板标题「我的操作」）
- 客户相关：收款单[创建]、客户费用单[创建]
- 供应商相关：付款单[创建]、供应商费用单[创建]
- 内控相关：核销单[创建]、内部费用单[创建]
- 库存成本：库存成本查询、库存成本汇总[明细]

### 财务管理（5 列）
- 日常业务：凭证管理[创建]｜固定资产：资产管理｜财簿管理：总账｜期末处理：期末结转｜财务报表：资产负债表

### 档案管理（7 列）
- 商品相关：商品档案、单位档案、品牌档案、价格方案、商品标签、上次售价、上次采购价、价格体系设置、销售类目、组合规则
- 往来相关：客户档案、客户标签、仓库档案、信用管控方案、供应商档案、业务类型
- 资金相关：账户管理、费用类别、收入类别、调账类型、往来标签、结算期限
- 财务相关：科目、资产类型、增减方式
- 员工相关：员工与部门、角色权限配置
- 自定义：自定义字段
- 期初录入：应收款/应付款/预收款/预付款/科目/库存成本/现金流量 期初（7 项）

### 数据报表（6 组，无列标题）
- 汇总表：采购待入库明细 / 调拨 / 盈亏 / 其他出入库
- 往来：新版应付款、客商一体对账、其他应收、其他应付、费用单、收入单、费用垫付核销
- 收付流水：线上收款流水、收款明细、付款明细
- 跟踪类：预订货单履约、预订货单占用、费用合同执行、商品兑付、促销执行、费用兑付、商品借还
- 外勤：拜访记录、拜访达成、外勤轨迹、外勤照片、库存上报分析
- 分析：客户利润、员工利润、商品铺市概览/分析、费用比、客户活跃、客户销售跟踪

### 设置（3 列）
- 打印设置：app 打印、电脑打印、模板设置、新模版设置、远程打印
- 其他设置：公司设置、采销设置、资金设置、对接设置、档案设置
- 运营设置：目标设置
