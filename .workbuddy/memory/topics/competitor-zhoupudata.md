## 一、弹窗通用形态（9 张归纳）

- 一级项右侧弹**白底圆角卡片 + 投影**；面板内**分组横向并排成列**。
- 列标题粗体置顶 + 标题下细分隔线；列间纵向分隔线；**列宽随条目自适应**。
- 需要新建的条目右侧带蓝色文字小按钮「创建」（采销/仓配/资金/财务/档案皆然）。
- 空列不占位。列底部偶有流程示意小图标行（装饰性，不复刻）。

### 6.1 铁证：标签是「点一个开一个」累积出来的

| 证据 | 读数 |
|---|---|
| 标签栏 4 个标签（OCR，y≈0.074） | `商品档案`(x0.124) / `单位档案`(0.190) / `品牌档案`(0.269) / `价格方案`(0.324) |
| 弹窗「商品相关」列的条目（OCR，x0.080） | 自上而下 = **商品档案 / 单位档案 / 品牌档案 / 价格方案** / 商品标签 / 上次售价 / … |
| **两者关系** | 标签栏 4 个 = 该列**前 4 个条目**且**顺序完全一致** ⇒ 老板依次点了这 4 条 |
| 10-06 老截图同位置（y≈0.142） | **空的** ⇒ 存在「**无标签状态**」；标签是点出来的，不是模块自带的 |

⇒ **结论：舟谱 = 点弹窗里一个条目 → 开出**一个**标签；再点别的 → 再开一个（累积）；每个标签可单独关。**

### 6.2 标签的构成与激活态（像素实测）

- **每个标签 = `[圆形小图标] + 名称 + [×]`**。OCR 稳定把左图标读成 `C`、把关闭读成 `X`；
  四个标签的**左图标完全相同** ⇒ 它**不像页面类型图标**（商品档案与价格方案不该同图标），
  更像**功能按钮或状态点** —— ⚠️ **它到底是不是「刷新」无法从截图断定**（见待确认问题）。
- 左图标轮廓（8× 放大 + 字符画）：**一个不闭合的圆环，缺口在右侧**，形似 ⟳ 刷新符；
  直径约 21px（原图 3834px 宽下）。
- **激活态**：沿标签栏那条带子逐列取背景亮度 —— 底色 **228**（灰），
  只有 x 1220–1460 一段是 **255（纯白）**，正好落在「价格方案」标签上
  ⇒ **激活标签白底、其余灰底**。深色模式下这条要反过来（激活更亮）。
- **位置**：顶栏之下、页内工具条之上。基准图里 顶栏 y≈0.019 / **标签栏 y≈0.074** / 页内工具条 y≈0.126 / 表头 y≈0.193。

### 6.3 我们与之的差距（诊断）

- 我们**没有标签栏**这个概念：`InventoryShell.vue` 用 `TABS` 表（工作台/采购单/销售单/库存查询）
  **无条件全渲染** ⇒ 点任何一个条目跳进来，都会看到**整组 4 个页签** —— 这正是老板说的
  「点击某个字段后，把整个模块的所有标签全部展示出来」。
- 同类还有 `Archive.vue`（7 个页签）/ `Rebate.vue` / `ProductCatalog` 页等，全是**模块内固定页签条**，
  与舟谱的「打开历史标签栏」是**两种不同语义**：我们的页签 = 「这个模块有哪些页」，
  舟谱的标签 = 「我打开过哪些页」。改造的核心就是把后者的语义立起来。

### 6.4 我们这边可复用的东西

- 路由已是 hash 模式 + query 承载状态（v395 刚做的 `navTo.q` / `isCur` 逐键比）⇒ 标签天然可由 URL 还原。
- 权限唯一源仍是 `canSee(path)`（`Shell.vue` 的 `resolveNavItem`）⇒ 标签栏必须**复用同一个判据**，
  绝不允许自己再判一次（否则又是一个"隐藏了入口但 URL 还能进"的洞）。
