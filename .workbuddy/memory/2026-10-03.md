## v372（2026-10-03 23:4x）：小程序「预报汇总总表」为空 —— 同一个接口两端入参不同

**老板报**：boss 账号 Web 端看得到报单，小程序「预报汇总总表」却是空的。

### 根因（不是权限，是取数口径错位）

报单落库 `order_date` 一律取**期次 `order_start`**（服务端推导，不信任客户端日期），
而 `order_start` 通常早于今天 ⇒ `forecast_submission_summary` 四参全空时的兜底
`s.order_date = 今天` **恒空**。

生产实测：期次 #23 `order_start=10-02`/`order_end=10-03`（closed），21 单**全记 10-02**，
`order_date=今天(10-03)` 报单数 = **0**，有量明细按日：10-02:16 / 09-28:3 / 09-26:18 / 09-22:10。

**为什么只有小程序中招**：
- Web `Forecast.vue` 6 处调用**全部显式传** `summary('', order_start, order_end, id)` ⇒ period_id 双口径 ⇒ 正常

period_id 双口径分支**（与 Web 端同源），不新写第二份选期次/拼 SQL 逻辑。取不到时
try/except 降级回原行为，不抛异常。

🔴 注释钉死：**本兜底只服务读路径**。`forecast_period_default()` 会选中已 closed 期次，
