## 修复 hermes_core.py datetime 局部导入 bug（18:12）
- **症状**（AI 主动发现）：「资金概况」「逾期查询」两个 Hermes 工具报错。
- **根因**：`execute_tool()` 函数内 `elif tool_name == "open_forecast_period":` 分支有一行 `from datetime import datetime`（局部导入），使 Python 把 `datetime` 当作 execute_tool 的**函数局部变量**，导致函数内更早分支（check_overdue 第327行、cash_overview 等）`datetime.now()` 报 `UnboundLocalError: referenced before assignment`。
- **修复**：删除 execute_tool 内那行多余局部导入；顺带清理 3 处同类反模式（_check_targets_summary/_generate_meeting_pack_summary/_check_expiry_summary 里的局部 `from datetime import`）。模块顶部第8行已 `from datetime import datetime, timedelta`，无需局部导入。

- **教训**：Python 函数内任何位置 `from X import Y` 都会让 Y 成为整个函数的局部变量，导致更早的引用报 UnboundLocalError。工具分发大函数里禁用局部 import。

## 修复生产 Hermes 403（浏览器 AI 对话报错，18:40）
