- 改动文件：`routers/sales.py`、`routers/data.py`（加 BaseModel 校验）、`core.py`（新增 `pydantic_error_detail` 助手，供 router 复用把 ValidationError 转中文提示）。
- 模型设计要点：
  - `extra="allow"` + `model_dump(exclude_unset=True)` → 精确保留透传语义（未发的字段不插 NULL 覆盖列默认值；前端多发的列/extra 全部保留，与旧 `**d` 行为一致）。
  - 必填：`name`（商品/客户，min_length=1,max_length=200）；订单 `items` 必填且每项 `quantity: float = Field(gt=0)`（**无 default**，缺/非法直接 422；旧代码 `it['quantity']` 缺字段会 KeyError→500）。

  - 空 items 保留旧友好 400「请选择商品」。
  - 非法 JSON（`request.json()` 异常）→ 400。
- 返回：校验失败 `raise HTTPException(422, detail=中文)` → 走 Phase L 的全局 http_exception_handler → 安全信封 `{success:False,error,trace_id}` + `X-Trace-Id` 头，**无内部泄露**。
