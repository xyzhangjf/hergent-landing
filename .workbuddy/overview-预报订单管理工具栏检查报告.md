## 二、UI 布局评估（间距 / 分组 / 对齐 / 视觉层级）

**现有结构（line 5147-5151）**：
- `.toolbar` 用 `justify-content:space-between` 把左右两组推开，两组内部 `gap:8px`，组间 `gap:12px`，整体 `flex-wrap:nowrap + overflow-x:auto`。
- 唯一视觉强调 = 「智能建议」(btn-primary)，层级正确。

**问题（3 类）：**
1. **右组无功能分隔，难扫读**：搜索框 / 仅显示有报单 / 导入 / 编辑·保存 / 智能建议 / 表格设置▾ / 高级▾ + 3 个状态徽标 全部平铺在同一行、统一 ghost 样式，**没有分隔条区分"筛选 / 数据 / 编辑 / AI / 设置"五个语义簇**，眼睛找不到分组边界。
2. **状态徽标挤占操作位**：`已确认/草稿/已隐藏` 三个 badge（line 81-83）是"状态"不是"动作"，却和操作按钮同排争抢横向空间；窄屏下与按钮一起被 `overflow-x` 隐藏，先看不全。
3. **模式切换导致入口漂移**：`表格设置▾`(只读) 与 `高级▾`(编辑) 互斥显隐——只读用户找不到高级工具、编辑用户找不到表格设置，两端可发现性不一致；且 `高级▾` 是"菜单里的菜单"（7 项里 4 项是再开子面板的开关），叠加「更多工具」30 按钮，导航深度过深。

## 四、具体优化建议（按优先级）

### P0 · 布局（低成本、立竿见影）
- **P0-1** 右工具栏插入 2-3 条分隔条（`|`），把 [搜索·筛选] · [导入] · [编辑·保存] · [智能建议] · [表格设置/高级] 显式分组，提升扫读性。
- **P0-2** 把 3 个状态徽标移出按钮行（如提到标题下方独立一行或右上角固定位），不与操作按钮争横向空间。
- **P0-3** 窄屏给工具栏一个明确换行断点（目前 `overflow-x` 滚动易把功能藏起来），或把"智能建议/高级"常驻、其余收纳。

### P1 · 语义去重（消歧义）
- **P1-1(R2)** 「销量预测」合并为单一入口：保留高级▾→销量预测，删掉更多工具→🤖销量预测（或反之二选一）。
- **P1-2(R1)** 「建议书」改名「下单说明文档」，或并入「智能建议」弹窗的"导出说明"按钮，避免与"智能建议"撞名。
- **P1-3(R3)** 「审批/推送审批/小程序审批」重命名：审批流 / 推送企微审批 / 小程序配置（把"小程序审批"移出审批语义）。
- **P1-4(R4)** 「返利冲刺」+「凑单达返利」合成一个「达返利助手」面板（提示+一键凑单一体）。
- **P1-5(R5)** 「体检」并入「数据质量」分组，删除独立"数据健康分"或并入同一面板。

### P2 · 降低导航深度
- **P2-1** 「高级▾」的 4 个分组开关改为在弹层内直接分 section 平铺（数据质量/预测/协同/更多），减少"菜单套菜单"。
- **P2-2** 「更多工具」30 按钮按主题折叠成 3-4 个二级分类（分析 / 采购协同 / 返利 / 系统），避免一长串。

## 五、检查结论
1. **功能触发**：主工具栏 23 项按钮（含模块页签、期次管理、数据/编辑/AI/设置、高级▾ 七项及其 4 个子面板）**全部绑定真实处理函数、无死按钮**；仅「智能建议」在无期次时灰掉无提示，体验可补（P0 级小问题）。
2. **布局**：结构可运行，但右组缺语义分隔、状态徽标挤占操作位、模式互斥导致入口漂移——**建议 P0 三项**。
3. **冗余**：发现 **5 处语义撞名/双入口**（R1-R5），其中 R2「销量预测」双入口是上次改名未彻底清理的遗留，**建议 P1 落地去重**。

> 本次为**检查与建议**，未改动代码。如认可，回「**做**」我按 P0→P1 顺序落地（P2 可另议）；也可指定只做某几项（如"只做 P1-1 和 P1-3"）。
