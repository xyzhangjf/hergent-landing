# Postmortem 模板（事故复盘）

> **用途**：任何事故 / 关键踩坑 / 用户反馈后必写。耗时 5-10 分钟。
> **配套**：`PRD-TEMPLATE.md`（事故前的需求）+ `RISK-CHECKLIST.md`（事故前的风险评估）。
> **AI 接到事故反馈时**：必须主动问「Postmortem 写了吗」，未写则立即按本模板走。

---

## 1. 元数据

| 字段 | 值 |
|---|---|
| **Postmortem ID** | PM-YYYYMMDD-<短名> |
| **作者** | 张俊峰 + AI |
| **事故日期** | YYYY-MM-DD HH:MM |
| **影响范围** | 单用户 / 多用户 / 全量 |
| **持续时间** | HH:MM ~ HH:MM |
| **严重度** | P0（生产不可用）/ P1（功能受损）/ P2（边缘场景） |

---

## 2. 5W 一句话

> 一行说清事故。

**什么 + 何时 + 何地 + 谁影响 + 怎么发现**

> 例：2026-09-05 22:31 boss 用户登录被反复踢回登录页，影响单用户，6 个 API 接口同时 401 由前端 console error 发现。
