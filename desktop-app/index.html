1. 我们如何收集和使用您的个人信息

在您使用本软件的过程中，我们会在以下场景收集您的相关个人信息：

1.1 账号注册与登录

当您注册Hergent账号时，我们需要收集您的手机号码用于身份验证和账号绑定。如您不提供上述信息，将无法完成账号注册并使用积分计费相关服务。您也可以通过"跳过登录"方式以游客身份体验本软件的部分功能。

1.2 积分与充值服务

当您使用积分充值功能时，我们会收集您的充值记录、消费记录和积分余额信息，以便为您提供积分管理服务及开具发票（如需要）。支付环节通过支付宝等第三方支付服务商完成，我们不会收集您的银行账户、支付密码等敏感支付信息。

1.3 AI对话服务

您在使用AI对话功能时输入的文本、上传的文件以及AI模型生成的回复内容，均默认存储于您的本地设备，不会上传至我们的服务器。对话数据完全由您自行控制，您可以随时在软件内查看、导出或删除。

当您使用需要联网的AI模型（如DeepSeek、通义千问等第三方模型API）时，您的对话内容会经由我们的代理服务器转发至相应模型服务商，我们不会存储或分析您的对话内容。

1.4 多平台消息连接

当您使用飞书、企业微信、钉钉、QQ等平台连接功能时，我们会收集您提供的对应平台的App ID、App Secret等连接凭据。上述凭据加密存储于您的本地设备，仅用于建立与对应平台的安全连接，不会离开您的设备。

1.5 设备信息

为区分不同设备上的积分账户、管理软件授权及提供版本更新服务，我们会收集您的设备标识符（由设备硬件信息经哈希算法生成的匿名标识）。该标识符不包含您的个人身份信息。

1.6 定时任务

当您创建定时任务时，任务配置信息（任务名称、执行时间、对话指令等）存储于您的本地设备。我们不获取或监控您的任务内容。

1.7 日志信息

在您使用本软件的过程中，为排查故障和优化性能，本软件会在本地生成运行日志。日志文件存储于您的设备，仅在您主动反馈问题时经您同意后提供给我们进行分析。

2. 个人信息的存储

2.1 存储地点

您的对话数据、技能配置、角色设定、本地文件等核心数据存储于您的个人设备。账号信息、积分余额、充值记录等必要的服务数据存储于阿里云计算有限公司的服务器（位于中华人民共和国北京市）。我们严格遵守中华人民共和国关于数据存储的法律法规。

2.2 存储期限

本地数据由您自行管理，卸载软件时将一并删除。服务器端数据将在您注销账号后60日内删除或匿名化处理，法律法规另有要求的除外。

2.3 安全措施

我们采用业界通行的安全保护措施保护您的个人信息：传输层使用HTTPS/TLS加密通信、服务器端部署访问控制与防火墙、本地敏感凭据加密存储。但请您理解，没有任何安全措施是绝对完美的，我们会持续改进安全防护能力。

3. 第三方服务

3.1 AI模型服务商

本软件支持调用DeepSeek、通义千问等第三方AI模型服务。当您选择使用特定模型时，对话内容会发送至对应的模型服务商以生成回复。各服务商对其处理数据的行为负责，我们建议您同时关注对应服务商的隐私政策。

3.2 支付服务商

积分充值通过支付宝等第三方支付平台完成。支付环节中您提供的信息受支付服务商的隐私政策约束。

3.3 平台连接服务

飞书、企业微信、钉钉、QQ等平台连接功能涉及与对应平台的数据交互。使用该等功能时，请同时遵守对应平台的隐私政策与服务条款。

4. 个人信息的共享、转让与公开披露

4.1 共享

我们不会向任何第三方出售您的个人信息。除本政策第1条、第3条所述的必要场景外，未经您的明确授权同意，我们不会与第三方共享您的个人信息。以下情形除外：(a) 与您协商并获得您的明确同意；(b) 根据法律法规、行政或司法机关的强制性要求；(c) 为保护我们或公众的人身、财产安全免遭损害所合理必需的。

4.2 转让

我们不会将您的个人信息转让给任何第三方。如因公司合并、收购或破产清算等原因确需转让，我们将提前告知您并取得您的同意，且要求受让方继续履行本政策。

4.3 公开披露

我们不会公开披露您的个人信息，法律法规另有规定的除外。

5. 您的权利

根据适用的个人信息保护法律法规，您享有以下权利：

5.1 查阅与更正 — 您可以在软件设置页面查看您的账号信息，并通过客服渠道申请更正不准确的信息。

5.2 删除 — 您可以在软件内删除对话记录；在设置页面清除所有本地数据；卸载软件将自动删除全部本地存储数据。
