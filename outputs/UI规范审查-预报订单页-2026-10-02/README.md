**误报根因（三条，都已定位）**：
1. **CSS 复合选择器只抽了第一个类** —— 提取器对 `.tag.st-draft{}` 只记 `tag`，`st-draft` 被丢弃 ⇒ 一条 `.tag.st-*` 全家判成「零定义」。**修正**：选择器内**抽全部** `.cls`。
2. **`\bclass=` 把 `:class=` 也匹配了** —— `:class="{ on: activeTab === 'summary' }"` 被当静态 class 拆词，`activeTab` 等**变量名**混入 ⇒ 差集虚涨到 60。**修正**：用 `(?<!:)class=`。
3. **基准缺全局 CSS** —— 只拿本页 `<style>` 当「已定义」，于是 `card`/`btn-sm`/`tbl` 等全局类全被误报。**修正**：基准 = 本页 scoped ∪ `src/styles/variables.css`。

## 五、审计器自身的两个坑（下轮别重犯）

1. **SFC 切段不能用第一个 `</template>`** —— Vue 有嵌套 `<template v-if>`，会切出只有 245 行的假 template ⇒ 我第一版据此得出「界面 emoji = 0」是**在错误片段上得出的**。
   正解：以 `<script` / `<style` 位置为锚点。
2. **`:class` 表达式不能直接提 `'…'` 字面量** —— `:class="{ on: activeTab === 'summary' }"` 里的变量名 `activeTab`、比较值 `'summary'` 都会被误当类名 ⇒ 差集从 18 虚涨到 60。
   正解：先删比较式（`===?\s*'…'`），再取对象**键名**与三元字面量。
3. **zsh 里 `grep "\.$k[a-z]+"` 会被当算术表达式**（`bad math expression`）⇒ 输出空但**exit 0**，看着像「没有匹配」。多模式一律用 `grep -e`。
