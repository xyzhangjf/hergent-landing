## 五、这张表怎么被读出来的（可复查）

| 步骤 | 做法 |
|---|---|
| 1 | 报名页是 SPA，字段走鉴权接口 ⇒ 直接抓 HTML 只拿到空壳 |
| 2 | 用 puppeteer-core + 本机 Google Chrome 无头打开 `apply.html`，进入 `bp.delincapital.com.cn` 那个 iframe |
| 3 | 遍历 `input/textarea/select` 取字段名、类型、placeholder、必填星号；逐组点开下拉**滚动抓全候选值** |
| 4 | 用**真实鼠标事件**（`evaluateHandle` + `element.click()`）逐项填值 —— 普通 `element.click()` 对 React 虚拟列表下拉无效 |
| 5 | 填完截整页图，**未点「提交」**（提交是不可逆动作，必须你亲自或明确授权） |

复现脚本：`08-报名表预填脚本.js`（手机号 / 邮箱走环境变量 `DELIN_PHONE` / `DELIN_EMAIL`，不入库）；
截图证据见同目录 `06-报名表已填截图.png`。

🔴 **本机跑无头 Chrome 必须加 `--no-sandbox --disable-gpu`**：本机沙箱里 Chrome 自身沙箱会
`sandbox initialization failed: Operation not permitted`，GPU 进程 `exit_code=6`，
表现为 `newPage()` 超时或 `setViewport` 报 `Session closed` —— **看着像代码 bug，其实是启动参数缺了**。
