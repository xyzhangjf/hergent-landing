## 三、实现期抓出的 3 个真缺陷（都是静默失效）

### 3.1 键对账会产出**一份看起来「完全一致」的空报告**

- **机制**：`reconcile_by_key` 的 `_index()` 把 **key 为空的行静默丢弃**（既有特性）。两侧单号列全空 / 两侧编号体系完全不同 ⇒ 两个索引都空 ⇒ 回 `only_in_a=0 / only_in_b=0 / mismatch_count=0`。
- 🔴 **这比「几乎全不匹配」更危险**：后者一眼看得见异常；前者会让人直接下结论**「账是对的」**。
- **修法**（只增键、不改不删旧键）：回 `rows_a_total/rows_b_total/skipped_no_key_a|b/keys_a/keys_b/common_keys/vacuous/warning`；`vacuous=True` 时 warning 明说「0 差异不代表一致」，并**区分三种成因**（两侧空表 / 单号列全空 / 无共同取值）。
- **判据**：**「0 差异」必须能分辨是"真的逐笔一致"还是"什么都没比出来"。**

### 3.2 配置改了但网关没重启 ⇒ 新能力**永不生效**

- **机制**：Hermes 工具索引是**进程内缓存**。`ensure_mcp_servers` 只写 `config.yaml`；`ensure_running` 原先见到进程在就 `return` ⇒ `needs_restart=True` 被丢掉、只剩一条日志。用户现象：**「我明明配了，手机上还是用不出来」**，零报错。
- **判据**：`config.yaml` 的 mtime **>** 进程启动墙钟 + 2s（两者都客观可得）。
  进程启动墙钟 = `/proc/<pid>/stat` 第 22 字段 + `/proc/uptime` 换算（⚠️ 不换算会差一个开机时长）。
- **修法**：`mcp_config_drift()` ＋ `ensure_running()` **自愈**（scheduler 每 60 秒一轮）＋ **600s 冷却闸门**（防网关自己回写 config ⇒ 重启风暴）。
- **三态 `judged`**：**判不了要如实说**（无 config.yaml / 网关未运行 / 本平台无 `/proc`），既不臆断成待重启（会成风暴），也不假装成「已生效」（那是静默洞）。

### 3.3 🔴🔴 import 即迁移：只测纯函数的脚本也在**写真库**

- **根因**：`server/erp_db.py` 在**模块顶层**就跑 `_safe_migrate(...)`（实测 `:451`/`:468`/`:718`/`:727` …），`DB_PATH` 取自 `db/connection.py:11` 的 `os.environ.get("ERP_DB_PATH", <server/erp.db>)` ⇒ **任何** import 链里有 `erp_db` 的脚本，不设该变量就**对真库跑那批 DDL**。
- **为什么看不见**：① **大小不变**（幂等 DDL 是 no-op）② 零输出零报错 ③ **唯一痕迹是 mtime**。
- **踩点**：`probe-experience-catalog.py` 自称"只测纯函数"，但 `from routers.loss_workflow import ...` 顺带拉起了 `erp_db` ⇒ 真库 mtime 从 `08:45` 走到 `09:16`，大小一路 `3829760` 不变。**逐个跑、盯 mtime** 才定位到。
- **修法**：隔离动作**在第一个 server 模块 import 之前**执行；四个探针全部改为**每轮从真库自我重置影子库**（含 `-wal`/`-shm`），并在结尾加**真库 mtime+size 双判据自证**。
- **顺带发现（未修，不属本轮范围）**：`server/tests/` 的 `test_period_prev_v273.py`、`test_rhythm_only_rule_v282.py`、`test_user_rename_v288.py` —— `ERP_DB_PATH` 出现 **0 次**，直接跑会写真库。

### 3.4 顺带收拢：一处**第三份副本**

`spreadsheet_query._run_query(op="match")` 与 `recon_engine.reconcile_by_key` **各有一份键对账实现**，而**两份 docstring 都写着「已收拢、同一份实现」——都不真**。已改为委托（外层 4 键 + 内层 6 键**逐字不变**），并加断言防它日后又被复制回来。
⇒ 判据：**「docstring 说是同一份」不算，必须回代码看 import。**
