# 「本期预报」页面 UI 视觉审查报告

> 审查日期：2026-09-22
> 审查对象：`hergent-cn-v2/src/pages/Forecast.vue`（scoped 样式块约 997 行，L10054–L11051）
> 规范权威：`src/styles/variables.css`（代码唯一权威）+ `docs/UI-SPEC.md`（规范说明）
> 方法：令牌符合性比对 + 硬编码/档外值排查 + 重复与"幽灵令牌"核查 + 模板引用交叉验证

---

## 0. 总体结论

**布局结构适配场景，问题集中在"组件级令牌合规"与"少数强调色不一致"。**

「本期预报」是密集数据工具页（工具栏 / 视图切换 / 汇总表+冻结列 / 固定选区统计条 / 多类模态），其**信息密度与视觉层次是合理的**，整体不缺"功能可用性"。影响"美观、简洁、高级感"的主要是以下四类细节：

1. **强调色/语义色不一致**——同一语义出现两副面孔（删除按钮、激活态、热标签），直接削弱"统一克制"的调性；
2. **档外圆角 / 刻度外字号**——系统性微偏离（24 处档外圆角、48 处刻度外字号），让同页控件出现"半档"跳动；
3. **硬编码颜色**——不仅违约，且**深色模式下不跟随主题**，会出现对比度倒挂或"亮卡片浮在暗界面"；
4. **重复/幽灵定义**——死 CSS 与未定义令牌，损害可维护性与一致性可信度。

> 所有问题均来自 scoped 样式块与全局件引用的逐行比对，**非凭印象**。行号指向 `Forecast.vue` 文件真实位置。

## 1. 问题清单与优化建议（按影响排序）

### A. 强调色 / 语义色不一致（最影响"统一高级感"）

#### A1. 本页把 `.btn-danger` 覆写成"实底红 + 白字"，与全局规范矛盾
- **证据**：L10556 `.btn-danger{background:var(--dan);border-color:var(--dan);color:#fff}` 覆盖全局；该按钮用于 L2175 `确认删除`。
- **规范冲突**：全局 `.btn-danger`（`variables.css` L483）与 `UI-SPEC §2.1` 明文规定危险按钮应是**浅红底 + 危险色字**（克制、不与主操作抢饱和）；本页却改成刺眼实底红。
- **影响**：本期预报的"确认删除"是实底红，而全站其他页面（商品档案等）的危险动作是浅红底——**同一"删除"语义两副面孔**，破坏统一感；且 `color:#fff` 为硬编码白字（应走 token）。
- **优化**：删除 L10556–L10558 的页内覆写，统一用全局 `.btn-danger`；若确需更强调，应在**全局层**新增"强危险"修饰符并全站生效，禁止单页覆写。

#### A2. "幽灵令牌" `--brand` / `--brand-soft` / `--fg` / `--fg-muted` / `--mono` 被引用但全仓未定义，实际落到 indigo 兜底
- **证据**：L10782 `var(--brand,#4f46e5)`、L10787 `var(--brand-soft,#eef2ff)`、L10785 `var(--fg)`、L10788 `var(--fg-muted,#94a3b8)`、L11016/L11017/L11018；全仓 grep **无定义**。
- **影响**：①「改动记录(undo)」列表 hover、以及「商品名候选面板(ns-item.on)」选中态用的是**靛蓝高亮**，而本页选区/聚焦/激活全是**品牌青**——同页出现两种强调色；②这些字面量在深色模式下不会跟随主题（indigo 虽在暗底可见，但"未定义令牌"本身是规范违约，且与设计系统割裂）。
- **优化**：替换为系统令牌——高亮底用 `var(--p-bg)`、强调字用 `var(--p-dark)/var(--p-deep)`、文字用 `var(--t1)/var(--t2)`；`--mono` 去掉 `var(--mono, …)` 包裹，直接写 `ui-monospace,SFMono-Regular,Menlo,monospace`（本页已 inline 写了，只差去掉变量壳）。

#### A3. `.tag.hot` 用饱和橙红渐变 `#ff7a45→#ff4d4f`，与全站扁平克制色板格格不入
- **证据**：L10698。
- **影响**：冲刺卡上的"热"标签像营销红点，破坏整体高级、克制的调性（全站标签/徽章一律扁平 token 底）。
- **优化**：改为扁平 token——如 `background:var(--sev-risk-bg);color:var(--sev-risk)` 或品牌青系；若要"热"的醒目感，用主色/危险色的浅底+深字，而非渐变实底。

#### A4. 深色提示气泡 `.tip` 用 `#111827` 深底白字，是孤立的"暗片"
- **证据**：L10440。
- **影响**：浅色主题里出现一块近黑气泡，与其它浅色浮层（ctx-menu / col-menu 都是白底）不一致；且 `#111827` 字面量不随主题。
- **优化**：与其它浮层同构——`background:var(--bg);border:1px solid var(--bd);box-shadow:var(--shadow-md);color:var(--t1)`；或引入一个"反色提示"令牌。

### B. 按钮尺寸 / 高度 / 间距 / 圆角 / 背景色（用户重点项）

#### B1. 按钮体系存在规范外的第四档 `.btn-xs`（高/内距/字号均偏离）
- **证据**：L10167 `.btn-xs{padding:3px 9px;font-size:12px;border-radius:var(--radius-sm)}`。
- **规范**：按钮只有 `.btn`(36/14px/500)、`.btn-sm`(32/13px/500)、`.btn-icon`(30×30) 三档（`UI-SPEC §2.1`）。
- **影响**：`.btn-xs` 比 `.btn-sm` 更矮更窄，且本页多处弹出菜单项/小操作混用，造成"小按钮"又有两种规格。
- **优化**：能并入 `.btn-sm` 的直接并入；若确需更紧凑的"文本胶囊"，在**全局层**加 `.btn-xs` 令牌化（而非页内私造），避免第二份漂移。

#### B2. `.btn-copy` 只设 `border-color` 未设 `border-width/style`，边框实际不显示
- **证据**：L10162 `.btn-copy{border-color:var(--bd);color:var(--t1)}`（继承自 `.btn` 的 `border:none`）。
- **影响**：意图是"带框次按钮"，但边框被 `.btn` 的 `border:none` 抵消——视觉上变成无框透明按钮，与同排 `.btn-ghost`（有 `--bd` 边框）不同构。
- **优化**：明确写成 `border:1px solid var(--bd)`（或让 `.btn-copy` 直接复用 `.btn-ghost` 类），与全局件同构。

#### B3. `.btn-del` 是页内私造图标按钮，与全局 `.btn-icon`(30×30) 不同构
- **证据**：L10691 `.btn-del{…font-size:14px;padding:4px 8px;…}`；用于 L1131/L2113 行内删除（×图标）。
- **影响**：全局已有 `.btn-icon`（30×30、`border-radius:8px`、hover 浅底），本页却另写一套更矮更小的删除按钮，规格不一致。
- **优化**：行内删除改用 `.btn-icon`（或全局层加 `.btn-icon-sm`），统一图标按钮尺寸/圆角/hover。

#### B4. 档外圆角 24 处（应为 `--radius-sm` 8px）
- **证据**：L10134(6px)、L10212(6px)、L10285(6px)、L10412(5px)、L10457(5px)、L10490(6px)、L10818/10828(6px)、L10837(6px)、L10938(6px) 等，共 **24 处** `5px/6px`。
- **规范**：圆角只有 8/12/16/22 四档（`UI-SPEC §1.5`）；6px、5px 属档外。
- **影响**：小控件圆角比规范略"方"，与全局件（`.chip`/`.fld` 用 8px）不一致；密集网格里尤其明显。
- **优化**：`6px → var(--radius-sm)`(8px)；`5px` 的极小输入/角标可统一升 8px，或（若担心密度）在全局层**新增 `--radius-xs:6px` 令牌**后统一引用，杜绝散写。

#### B5. 按钮间距：主工具栏 `.toolbar{padding:14px 16px}` 偏离规范全局 `.tb`(12px 16px)
- **证据**：L10063。
- **影响**：跨页工具栏纵向留白差 2px，一致性略损。
- **优化**：若信息密度确实需要 14px 可保留并注明；否则统一为 `12px 16px` 与全局 `.tb` 同。

### C. 文字字号 / 字重 / 行高 / 颜色对比度（用户重点项）

#### C1. 刻度外字号 48 处（含低于下限的 10px）
- **证据**：`10px`(L10111、L10221)、`10.5px`(L10612)、`11.5px`/`12.5px`(L10178、L10191、L10192、L10421、L10494、L10496、L10500、L10501、L10502、L10510、L10513、L10537、L10724、L10883、L10908、L11017、L11018 等)、`13.5px`(L10447、L10586、L10886、L10958)；共 **48 处**。
- **规范**：字阶只六档 11/12/13/14/16/20（`UI-SPEC §1.3`）；`10px` 已低于下限 `11px`。
- **影响**：① 10px 低于 WCAG/spec 下限；② 11.5/12.5/13.5 让同页文字出现"半档"跳动，破坏字阶纪律；③ 与全局件（`.btn-badge` 11px、`.tag` 12px）不同构。
- **优化**：`10px → var(--fs-xs)`(11px)；`11.5/12.5 → 12px(var(--fs-sm))` 或 `13px(var(--fs-base))`；`13.5 → 13px` 或 `14px`。密集表格优先 `12.5→12`（避免行高跳变）。

#### C2. `font-weight:700` 超出系统三档（400/500/600）
- **证据**：L10771(`.cell-input.invalid … font-weight:700`)、L10948(`.bi-num … font-weight:700`)。
- **影响**：错误态/指标数字用 700，与"强调值=600"纪律不符；PingFang 下 700 显黑，略"吼"。
- **优化**：改 `600`（`.bi-num` 已是强调值，600 足够；错误态靠 600+危险色已足够醒目）。

#### C3. `qty-cell{color:var(--t3)}` 把空数量格用最低对比度色（≈2.5:1）
- **证据**：L10206。
- **影响**：若格内出现任何字符即低于 AA 对比度（spec §5.6 红线：说明性文字 ≥4.5:1）；`.fc-num/.fc-code/.fc-text` 用 `--t2` 尚可。
- **优化**：确认空格仅显示"—"；若承载说明文字应升 `--t2`。

#### C4. 行高：多数文本未显式约束，依赖 `body{line-height:1.6}` 全局
- **影响**：密集型表格内 `font-size:12.5px` 配默认 1.6 行高（≈20px）在密集网格里略松，但整体可控。
- **优化**（可选）：表格单元格文字可局部收紧到 `line-height:1.5`，让行更紧凑、信息更聚焦；非阻断项。

### D. 整体配色 / 留白 / 视觉层次

#### D1. 顶部层级未用标准 `.page-hd`——自定义 `.toolbar` 同时承载"标题上下文+操作区"
- **证据**：模板仅 L10062 `:deep(.page-hd){display:none}`（嵌入配置面板时隐藏），主页面**无** `.page-hd`/`.page-sub`。
- **规范**：`UI-SPEC §3.2` 规定页头用 `.page-hd`（h2 20px/600 + `.page-sub`）。
- **影响**：本期预报顶部没有统一的"页标题+副标题"层级节点，标题感来自工具栏内的期次选择器；跨页"标题层级"一致性略损（虽功能上可接受，因工具栏本就承载期次上下文）。
- **优化**（可选）：在工具栏左端补一个轻量 `.page-hd` 形态（如"本期预报"h2 + 副标题），强化页级层级；或在规范中注明"数据工具页以工具栏为页头"的例外。

#### D2. 固定选区统计条 `.sel-stat` 用硬编码上投阴影（应为 `--shadow-*`）
- **证据**：L10240 `box-shadow:0 -2px 8px rgba(0,0,0,.07)`；同 L10294、L10412、L10486、L10440、L10696。
- **规范**：阴影只有三档 token（`UI-SPEC §1.6`）。
- **影响**：硬编码阴影在深色模式下强度不可控，且无法在 `variables.css` 一处调参。
- **优化**：浮层/卡片改 `var(--shadow-md/sm/lg)`；固定条"顶边微投影"若需保留，在全局层补 `--shadow-fixed`（轻量上投）令牌并全站统一引用。

#### D3. 留白整体合理，仅工具栏 padding 与卡片间距存在 2px 级微差
- 总体：卡片 18px 内距（`.card` 默认）、区块间距 14px（`margin-bottom:14px`）与规范一致；无需大改。
- 微差：见 B5（工具栏 14 vs 12）、D1（页头例外）。属低优先级。

### E. 深色模式断链（合规 + 正确性）

#### E1. 数十处字面量颜色在深色模式不跟随主题
- **证据**（代表性）：L10095–10097（save-state 三态 `#8a8f98/#1a7f45/#b26a00`）、L10440(`#111827`)、L10698(`#ff7a45/#ff4d4f`)、L10807(`#fff7ed/#fed7aa/#9a3412`)、L10808(`#b45309`)、L10963(`#185FA5`)、L11020(`#ef4444`)、L10836(`#2563eb`)。
- **影响**：① 深色模式下列如 `.draft-banner`(#fff7ed 浅奶油底+#9a3412 深字)会变成"亮卡片浮在暗界面"；`.link-btn`(#b45309)在暗底对比不足；② `var(--warn,#f59e0b)` 写错成**未定义令牌**（应为 `--war`），`var(--dan,#ef4444)` 虽真实但应直写 `var(--dan)` 去兜底。
- **优化**：全部换成 token（`.save-state` 三态改 `--t3/--ok-green*/--warn-amber*` 或新增语义令牌；`.st-dot` 用 `var(--dan)`；`.link-btn` 用 `var(--p)/var(--p-deep)`；`var(--warn,…)`→`var(--war)`；diff 高亮建议用 `var(--p)` 系或新增 `--accent-link`）。

### F. 重复 / 死 CSS（整洁度，间接影响"高级感=可信度"）

#### F1. `.draft-banner` 被定义两次（L10807 与 L10983），后者整体覆盖前者 → 死代码
- **影响**：规范 §2 明确反对"第二份拷贝=静默漂移"；两处都含字面量，易误改已失效那份。
- **优化**：删 L10807 那份，保留并修正 L10983（用 token、去 `var(--warn,…)` 幽灵）。

#### F2. `.col-menu-del:hover` 与 `.btn-del:hover` 各重复写两遍
- **证据**：L10187–10188、L10692–10693（后条覆盖前条，仅差 `var(--dan-bg, …)` 兜底）。
- **优化**：合并为一行，去掉 `,rgba(239,68,68,.1)` 兜底（已有真实 `var(--dan-bg)`）。

#### F3. `.view-seg button.on` 比全局 `.btn.on` 少一道"主色边框"，同语义不同构
- **证据**：L10135 `.view-seg button.on{background:var(--bg4);color:var(--p-dark);box-shadow:var(--shadow-sm)}` vs `variables.css` L234 `.btn.on{…border-color:var(--p);…}`。
- **影响**：视图切换胶囊的"已激活"态比工具栏按钮的"已展开"态少一道主色边——同一激活语义两种观感。
- **优化**：`.view-seg button.on` 补 `border-color:var(--p)` 与全局 `.btn.on` 完全对齐；或将 `.view-seg` 改为复用 `.btn`+`.on`（已是按钮语义）。

### G. 层级（z-index）偏离令牌（功能相关，降级确认）

#### G1. 本页浮层 z-index 自成 1000–1150 阶梯，与规范令牌（400/600/980/990/1010/1200）不重合
- **证据**：L10544 注释说明"本弹窗与遮罩 Teleport 到 body，须高于工具栏浮层 1120"；用到 `1100/1101/1120/1125/1130/1150`。
- **说明**：历史成因（先于令牌化），且本页有"表格浮层必须高于工具栏浮层 1120"的硬约束，属**功能性必要偏离**。
- **优化**（非阻断）：① 在 `UI-SPEC §1.7` 注明"页面内浮层天花板"例外；② 长期可在全局层增设 `--z-sheet:1120` 令牌，让工具栏/弹窗/全屏层共用，杜绝"1120 vs 990"这类需用注释解释的顺序坑。

## 2. 优先级整改建议（落地顺序）

| 优先级 | 项 | 类别 | 工作量 |
|---|---|---|---|
| **P0（统一感，高可见）** | A1 `.btn-danger` 覆写、A2 幽灵令牌→品牌青、A3 `.tag.hot` 渐变、A4 深色气泡 | 配色一致 | 小 |
| **P1（系统合规）** | B4 圆角(24处)、C1 字号刻度(48处)、E1 硬编码色→token、B3 `.btn-del` 同构 | 令牌合规 | 中 |
| **P2（整洁度）** | F1/F2 重复定义、F3 `.view-seg.on` 边框、B2 `.btn-copy` 边框 | 死 CSS | 小 |
| **P3（文档化偏离）** | G1 z-index、B5/D1 工具栏与页头层级 | 规范说明 | 小 |

> **P0 的"统一感"收益最大、风险最低**：改 `.btn-danger` 覆写、替换 indigo 幽灵令牌、去掉热标签渐变、统一浮层气泡，这几处改动能让页面在浅/深主题下立刻"像一套系统"，且不影响任何功能逻辑。

## 3. 验收方式

1. **类差集审计**：整改后确认无新增零定义类（尤其确认删掉的幽灵令牌引用已换真令牌）。
2. **深色模式切换**：确认 A2/A4/E1 涉及的字面量已无（用 token 后自动跟随 `:root.dark`），重点看 undo 列表 hover、name-suggestion 选中、draft-banner、link-btn 在暗底对比。
3. **像素比对**：`.btn-danger`、`.view-seg.on`、`.tag.hot` 在浅/深主题下与同语义全局件一致。
4. **字号/圆角抽样**：抽查密集表格与工具栏，确认 6px/5px 与 10/11.5/12.5/13.5px 已归并到令牌刻度。

## 4. 附：本页与规范核对速查（关键令牌对照）

| 维度 | 规范令牌 | 本页常见偏离 | 位置 |
|---|---|---|---|
| 危险按钮底 | 浅红底+危险字 (`--dan-bg`+`--dan`) | 实底红+白字 (`--dan`+`#fff`) | L10556 |
