# v207 交付说明：预报「合计(箱) 显示不了」

**日期**：2026-09-19 · **状态**：已上线 + 线上复验通过
**用户报障原话**：我刚提交了永辉东津店的报单，报单数量在 web 端"合计（小单位）"有显示，但在"合计（箱）"没有显示。

---

## 一、结论先说

**这不是「要不要四舍五入」的口径争议，是 2026-09-13 已拍板的口径被实现做反了。**

拍板的三条是：报单数量按**最小销售单位**录入 / **件数 = 数量 ÷ 规格（可为小数）** /
**取整只发生在「最终下单」**（理由：厂商不拆零发货）。

而代码是：`rowBoxes` **先 `Math.round` 抹零**、`rowFinalQty = 合计(箱) + 加单` **完全不取整**
—— **两处正好互换**。报 3 瓶 ÷ 24 瓶/箱 = 0.125 箱，被抹成 **0**。

## 二、根因（生产只读取证，逐字可复现）

期次 14 / 永辉东津店 / 单据 491 的真实 3 行：

| 商品 | 规格 / 单位 | 报单量 | 每箱小单位数 | 修复前 合计(箱) | 修复后 合计(箱) |
|---|---|---|---|---|---|
| 蒙牛小鲜语绿莎莎… | `185ml×24瓶` / 瓶 | 3 | 24 | **0** | **0.125** |
| 新希望(南山)活润… | `340G` / 瓶 | 3 | 340 | **0** | **0.009** |
| 简爱0%蔗糖原味 | `135g*24杯` / 杯 | 3 | 24 | **0** | **0.125** |
| **表尾合计** | | 9 | | **0** | **0.259** |

🔴 **连带后果（比箱数更贵，也已一并修好）**：
`下单金额 = 最终下单(箱) × 单价(厂价/箱)`。最终下单被抹成 0 ⇒ **金额整列归零**，
而「单价(厂价/箱)」那一列本身是有值的 ⇒ 用户视角是「金额栏凭空没了」。
