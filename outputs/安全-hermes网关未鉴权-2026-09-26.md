## 九、这次的方法论沉淀（已写进技能 `hergent-pre-launch-audit`）

1. **"内部服务只监听 127.0.0.1" ≠ "外网打不到"** —— 只要 nginx 有一条 `proxy_pass` 到它，就必须**手测外网零凭据**。
2. **反向代理里的 `proxy_set_header Authorization "Bearer …"` = 把密钥替全世界出示**，等价于无鉴权。
3. **`sites-enabled/` 里的任何 `.bak` / 副本都会被 `include *` 加载**；`conflicting server name` 警告就是"有多份 server 块"的信号，不是噪声。
4. **代码里 `os.environ.get(KEY, "<默认值>")` 是密钥泄漏的常见形态** —— 默认值应留空并**响亮地失败**。
5. **轮换密钥 grep 的是"值"，不是"变量名"**（本轮就因同名凭据两个变量名而漏了一处，差点让 skill 接口长期 502）。
6. 验证必须**从外网侧**打（服务器自测连的是 127.0.0.1，天然看不出"公网可达"这件事）。
