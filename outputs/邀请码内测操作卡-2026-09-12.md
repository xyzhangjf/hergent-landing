# 邀请码内测 · 操作卡

> 一句话：注册口子**只对拿到码的人开放**，你把码发给谁、谁就能注册；码什么时候停、停哪张，你都说了算。

## 一、当前状态（2026-09-12 已上线）

| 项 | 值 |

## 二、发一张码（30 秒）

1. 用 `boss` 或 `admin` 登录 → **设置** → **客户开通** → **邀请码**
2. 填「备注」写清给谁（如 `老李-襄阳-测试`）、「可用次数」一般填 `1`、「有效期」留空 = 不过期
3. 点生成 → 出来一串形如 `HG7K2M4P9X` 的码 → 点复制，微信发出去
4. 对方注册成功后，下方**注册流水**会自动多一行（公司名 / 手机 / 注册时间 / 来源 IP）

> 码里有几个字符天生不存在（`0 O 1 I L`），因为手抄容易错，已从字符集剔除。

## 三、对方怎么注册

打开 **hergent.cn** → 「立即注册」→ 填 公司名称 / 手机号 / 密码 / **邀请码** → 提交即开通。

- 没填码 / 填错：提交会被拦住并提示，**不会浪费名额**
- 码过期、被停用、次数用完：提示各不相同（分别是「已过期」「已停用」「已用尽」），一看就知道该找谁
- 注册后如果那家要用于真实经营，记得进 `设置` 把默认密码改掉

## 四、这一轮顺手堵掉的两个洞

这两个都是「注册一跑通就会变成真危害」的类型，所以和邀请码一起修了：

1. **全平台客户名单泄漏**：`/api/tenants` 原本未登录就能读到所有客户的公司名 + 手机号（前端根本没用这个接口）。现已收紧 —— 未登录 401、普通账号 403。
2. **谁都能开租户**：`POST /api/platform/onboard` 原本只要是 `boss` 就能开。而**每个注册用户自己就是 boss** → 等于把「开租户」发给客户。现改为仅平台管理员。

## 五、以后要接真短信

**不改一行代码**，只改服务器 `.env` 加两行然后重启：

```
REGISTER_MODE=sms
（+ 短信通道的 key/签名等配置）
```

原短信验证码分支是**原样保留**的，切过去就回到短信流程；想切回来改回 `invite` 即可。三档：`invite`（现在）/ `sms`（真短信）/ `open`（免验证，生产还须额外开 `ALLOW_SELF_REGISTER=1` 才生效）。

## 六、测试期注意

- 新注册的租户**不是空的** —— 系统会自动灌 15 条假客户 + 15 条假商品（演示数据）。如果你希望"上传第一份 Excel 才激活"，这条要单独改，先按现状用。
- 自测期间你直接用 `HG29PJ8289` 反复注册即可，它不限次；正式发给客户前，建议先用它跑一遍，确认无误后**把它停用**（列表里点停用），改发一次性码。
