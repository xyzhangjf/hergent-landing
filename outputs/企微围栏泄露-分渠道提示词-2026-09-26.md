# 企业微信里冒出 `cards {"show":[]}` —— 提示词层修不彻底，改为**分渠道提示词**（v281）

> 起因：老板发来企微截图 —— 副驾回复末尾多出一个代码块：
> ```
> cards
> {"show": []}
> ```
> 「cards 显示有是问题」

---

## 一、结论（先说最要紧的）

**昨天在提示词里"叫它别写"是不够的** —— 那是**软约束**。
改完之后**仍然复现了 3 次**，所以我这次改成**结构性修法**：

> **企业微信/飞书/钉钉/QQ 这些渠道的提示词里，把卡片与围栏协议整段删掉**
> （那些渠道**不渲染任何围栏**，留着只会变成代码块噪声）。

**实测对照**（同一道题、同一个模型，只有提示词不同）：

| | IM 版提示词（企微走这条） | Web 版提示词（对照） |
|---|---|---|
| 回复长度 | 581 字 | 1370 字 |
| **代码围栏个数** | **0** ✅ | 2（含 1 个经营卡围栏）✅ |
| 出现 `"show"` 字面 | 0 ✅ | 0 |
| 结论 | **彻底不再出围栏** | **网页卡片功能完好** |

---

## 二、取证：昨天那个修，到底还有没有漏

**① 昨天的修改还在**（三份 SOUL.md + 权威源，md5 全等 `b3036bcd`，「纯文字回复写」命中 0）。

**② 没有别处在教它**（全机 grep `show":[]` 只命中我们的新文案与旧备份）。

**③ 但会话库里查到了 4 次空意图，3 次发生在我改完之后**：

| 时间 | 说明 |
|---|---|
| 09-25 16:47:35 | 改前 |
| **09-25 22:49:38** | **改后** |
| **09-26 22:00:55** | **改后** |
| **09-26 22:10:25** | **改后** |

出现率 **4 / 125 条回复 ≈ 3.2%**。
⇒ **提示词里"叫它别写"这种软约束，模型会漏**。必须换硬办法。

**④ 那条渠道**（租户 Hermes）**只接 IM**：`gateway_status(1)` 显示 `channels: ['wecom']`，
且平台凭证只有 feishu / wecom / dingtalk / qq 四种 ⇒ **租户那份提示词里的卡片协议 100% 是死规则**。

**⑤ 企微适配器不消费任何围栏**（grep `cards|clarify|proposal|reminder` 零命中）
⇒ 删掉这些协议**不丢任何功能**，只是不再往老板脸上输出噪声。

**⑥ Hermes 没有"按平台"的提示词开关**：只有 `channel_overrides`（**按单个群 id**），
覆盖不全（新群不继承）；`system_prompt` 也只是 channel 级。⇒ 只能从**我们自己的提示词**下手。

---

## 三、做法：一份权威源，按渠道渲染两版

改造 `server/soul_sync.py`（昨日刚建的"单一权威源"机制）为**分渠道下发**：

| 目标 | 渲染规则 |
|---|---|
| `/root/.hermes/SOUL.md`（Web 副驾） | 权威源**原文**（软链指向权威源，结构上同源） |
| `/opt/hermes-tenants/*/SOUL.md` + `_seed`（IM） | 权威源**去掉 WEB-ONLY 区块** + 追加 `SOUL.im.md` |

- 权威源 `prompts/SOUL.md` 里，凡「仅网页端」的内容（**经营卡 JSON 结构** + `card`/`cards`/
  `clarify`/`proposal`/`reminder` **五种围栏协议**）都用一对注释标记夹住：
  `<!-- ▼▼▼ WEB-ONLY … -->` / `<!-- ▲▲▲ WEB-ONLY 结束 … -->`
- 新增 `prompts/SOUL.im.md`：**纯文本渠道规矩**（正向表述：要补信息就直接问、
  要提建议就用两句中文、要提醒就直接说、结构化结论文用中文要点/小表格）。
- 🔴 **单一作者**：IM 版由权威源**机械派生**，绝不手写第二份全文（手写必漂移）。

### 🔴 过程中修掉的两个"自己踩的坑"
1. **别把禁忌字面写进提示词**。第一版 `SOUL.im.md` 里我写了「不要写 `{"show":[]}`」和
   三个反引号 —— 这等于**把要禁的字符串送进上下文**（负向诱导）。现在
   **IM 版一个反引号都没有**，连 `cards`/`经营卡`/`卡片` 这些词都不出现。
2. **维护者注释也会漏进 IM**。我在权威源顶部加了一段"标记用法说明"（提到卡片结构与围栏名），
   它不在标记区内 ⇒ 会进入 IM 提示词，把禁忌词又带回去。已把它移到 `soul_sync.py` 的文档里
   —— **提示词文件只放提示词**。

### 顺带清理
权威源里还有一句 `正文不超过 400 字；超了说明该出经营卡，把明细移进卡里`（在标记区外）⇒
改成两渠道都成立的中性说法「超了就把明细收进结构化清单（表头/要点）」。
