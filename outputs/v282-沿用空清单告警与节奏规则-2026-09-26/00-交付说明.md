## 三、变更明细

### ① 「同节奏」——给 `蒙牛鲜奶` 建到货节奏规则

走**真实接口** `POST /api/rebate-rules`（非直连数据库）。逐字段照抄生产 `蒙牛低温`(id=10)：

| 字段 | 值 | 说明 |
|---|---|---|
| `order_first_date` | `2026-08-28` | 首次报单日 |
| `order_cadence_days` | `2` | 每 2 天一次 |
| `order_lead_days` | `4` | 提前 4 天下单 |
| `order_max_early_days` | `1` | 最多提前 1 天 |
| `arrival_mode` | `interval` | 按间隔 |
| `arrival_cadence_days` | `2` | 到货间隔 2 天 |
| `arrival_first_dom` | `1` | — |
| `arrival_count_override` | `15` | **期次覆盖 15**（决定「后续可报单数」分母）|
| `target_value` | **0** | 🔴 纯节奏规则，**不设返利目标** |
| `rebate_rate` | **0** | 🔴 不产生任何返利 |
| `auto_period_enabled` | **0** | 🔴 见下 |

**两个关键取舍（都是为了不弄坏已有功能）**：

1. **`target_value=0` 是安全的** —— 后端 `domain/rebate_calc.py` 里达成率写作
   `ach = basis/target if target and target > 0 else None` ⇒ 目标 0 时达成率为空、不除零、返利额 0。
   实测 `simulate` 返回 `"note": "无目标值，无法计算达成率"`，**不会污染返利/达成/KPI**。
2. **`auto_period_enabled` 必须为 0** —— 自动建表的排程器只认**第一条**开着的规则当「主导节奏」。
   若设 1，就会和 `蒙牛低温` 抢排程归属，**期次日期变得不确定**。实测设为 0 后，
   排程结果**一条都没变**（见下）。

**A/B 对照（5/5 通过）**：把这条规则加进排程集合前后，
**期次日期逐条完全一致**（去掉显示层字段后 JSON 全等）、主导品牌仍是 `蒙牛低温`、无漏报。

### ② 「要」——给「沿用上一期得到 0 个商品」加告警

**病根**：原返回值里 `skipped = 源商品数 − 实际复制数`，
但「源有 N 条、目标已有同商品被跳过」与「**源自己就是 0 条**」两种情况**算出来都是 0** ⇒
**根本分辨不出来**。这正是上一期「静默复制 0 行、逐期传染」的原因。

**改法（后端 4 个文件）**：

| 文件 | 改动 |
|---|---|
| `server/erp_db.py` | 沿用函数返回值**多带一个 `src_count`** ⇒ 从此能区分「源为空」与「全被跳过」|
| `server/routers/forecast.py` | 新增 `_carry_empty_warn()` 作为**唯一文案实现**；手工新建期次 / 手动填入 两处都回传 `carry_warn` ＋ 打 `[v282][carry-empty]` 日志 |

**三个防坑细节**：

- 通知**显式传** `event_key="forecast_carry_empty"`。不传的话，系统会把标题里的期次号归一化抹掉 ⇒

- 前端 `added=0` 时一律用 **warn 色**且文案**可操作**（告诉你点哪、或去导入 Excel），不再报「一切正常」。

## 五、顺带收获：给「只配节奏、不设目标」开了正门

要让 `蒙牛鲜奶` 有到货节奏，就必须建一条「规则」（节奏只能存在规则表里）。
但原校验要求「目标值必须大于 0」，等于**逼你编一个假目标**去污染返利和达成数据。

**改法**：新增唯一判定 `_row_rhythm_only()`，同时放行三件事：

1. 校验放行（无目标但有节奏 ⇒ 合法）
2. **不参与判重**（否则会和该品牌以后的真实目标冲突）
3. **不占月份锁** —— 🔴 这条最关键：年度规则若没有月度分解，覆盖月份算**整年**，
   一旦占锁就会**把这个品牌整年锁死**，你以后想建真实返利目标会被系统以「冲突」打回。

**并且证明了没有放松原有约束**：普通目标规则**照常判重**、**照常占 12 个月份锁**（单测内覆盖）。
生产实测：月份锁 **13 条 → 13 条**（新规则占 **0** 条）。
