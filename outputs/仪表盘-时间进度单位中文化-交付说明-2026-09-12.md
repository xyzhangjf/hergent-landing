## 二、变更

### 1. 主改动：单位由缩写改中文

| | 改前 | 改后 |
|---|---|---|
| 超前 | `超前 70pp` | **`超前 70 个百分点`** |
| 落后 | `落后 20pp` | **`落后 20 个百分点`** |
| 持平 | `与时间进度持平` | 不变（本就是中文） |

### 2. 顺带修掉一处「同屏两种写法」

改前 chip 与 hover title 是**各自算值**的：

```js
// chip：四舍五入到整数
vsTimeShort: Math.round(Math.abs(vsTime) * 100) + 'pp'          // → 63pp
// title：保留一位小数
vsTimePct  : (Math.abs(vsTime) * 100).toFixed(1) + ' 个百分点'   // → 63.5 个百分点
```

即**同一行鼠标悬停前后数字会变**（63 → 63.5）。现合并为单一来源 `vsTimePct`，chip 与 title 共用同一个字符串，**结构上不可能再分叉**。

整数不带小数点（`70 个百分点`），非整数保留一位（`63.5 个百分点`）。

### 3. 顺手清掉 3 处死代码（v154 判语 chip 化的遗留）

v154 把整行判语（`.rr-vs` / `.rr-warn`）删掉后，这三处已无人读取：

- `vsTimeShort` —— 被本次合并取代
- `toNextGapPct` —— 原「距下一档还差 X 个百分点」的展示字段，唯一消费者已删
- item 版 `curTierPct` —— 模板只读 `curTierText`（档位文案），该字段无引用（连同其局部变量 `toNextGap` 一并移除）
