# 报单配置界面优化方案（2026-09-23）

> 目标：提升「预报订货管理 → 报单配置」页的视觉清晰度与操作效率。
> 重点：整体布局与信息层级、表单字段分组、必填项标识、关键操作突出，且与现有系统视觉风格一致。
> 配套可视化：`报单配置页面布局`（三区骨架）、`新建配置弹窗`（分组 + 必填 + 校验）。

---

## 一、现状问题诊断

当前 `ReportMapping.vue` 把四类概念纵向平铺，存在三处结构性问题：

1. **三块「运行参数」外观不统一**：`报单自动化`（可折叠 + 头部状态芯片）、`报单提醒设置`（固定 `panel-hd` 卡片、必须展开才看到状态）、`模板参数`（另一种折叠头）。同属「报单这件事的运行参数」，视觉语言却三种，扫描时误以为是三个不同层级的东西。
2. **最关键动作被淹没**：页面最高频操作「新建配置」排在 3 块设置卡 + 两条提示条之后，且只是 `btn-sm` 小按钮，层级低于次要设置。
3. **必填标识不够明确 + 无内联校验**：弹窗里必填项仅 `<span class="req">*</span>` 一个小红星，可选字段（取价渠道 / 仓库）没有任何「选填」对照；保存校验只走 `toast`，错误不定位到字段（跨 Tab 时更找不到错在哪）。

---

## 二、优化后界面结构（信息架构）

把页面重排为 **三大区**，每区语义独立、视觉同构：

```
报单配置（页头）
├─ ① 运行参数（区）              ← 同构的可折叠卡片，头部即显示状态
│   ├─ 报单自动化        [自动/手动]  下次开表 09-24 20:00        [收起]
│   ├─ 报单提醒设置      [已开启]     截止前 3h 催报 · 按销售分组   [收起]
│   └─ 模板参数          [未设置]     业务员/部门/仓库列待填        [收起]
│
├─ ② 报单对象（区）              ← 「数据 + 操作」区
│   ├─ 配置体检条（有问题先暴露：N 门店未配 / 别名冲突 / 员工未分配）
│   ├─ 工具栏：[+ 新建配置](主色实底)  [Excel 批量导入](描边)
│   └─ 配置列表（表格：员工 / 类型 / 全称 / 简称(列头) / 单型 / 渠道 / 状态 / 操作）
│
└─ ③ 写入口（弹窗）              ← 新建 / 编辑共用
    分组① 归属：员工＊
    分组② 对象定义：对象类型 / 对象全称＊ / 报单简称(列头)＊ / 单型＊
    分组③ 价格与仓库 · 选填：取价渠道 / 源仓·目标仓
    [取消]  [保存](主色实底)
```

**改动原则**：① 区与 ② 区用 `sec-label`（现有全局区眉标，左竖条 + 13px 600）清晰切分；① 区内部三卡用**同一组件形态**（折叠头 + 状态芯片 + 一句话摘要 + 收起/展开），消除「三种外观」。

---

## 三、布局方案

1. **区眉标分层**：沿用全局 `.sec-label`（左竖条 `var(--p)` + 13px/600），把「运行参数」「报单对象」做成两个清晰分区，替代现在只有 1 个 `自动化与模板` 区眉标的不完整切分。
2. **运行参数三卡同构**：把 `ReminderConfig` 从「固定 `panel-hd` 卡片」改为与 `AutoPeriodBlock` 一致的**折叠头卡片**——头部始终显示 `[已开启/已关闭]` 状态芯片 + 一句话当前摘要（如「截止前 3 小时催报 · 按销售分组」），不必展开即知状态；展开才显示详细开关。
3. **数据区突出主操作**：「新建配置」用 `.btn-primary`（实底 `var(--p-dark)`）+ 放在配置体检条正下方、列表正上方，作为该区唯一主操作；`Excel 批量导入` 用 `.btn-ghost` 描边，主次分明。
4. **配置体检先行**：保留现有体检条（amber 左条），但明确它是「动手配之前先看哪里有坑」，位置固定在数据区顶部。
5. **弹窗字段分组**：用全局 `.sub-sec`（13px/600 次级小标题）把字段切成「归属 / 对象定义 / 价格与仓库」三组；「价格与仓库」标题后直接缀「· 选填」，与必填组形成对照。

## 四、关键交互改进点

| 改进 | 现状 | 优化后 |
|---|---|---|
| **必填标识** | 仅标签后小红星，可选字段无提示 | 必填字段标签后红色 `＊`；弹窗右上角统一图例「＊ 必填项」；选填组标题缀「· 选填」 |
| **内联校验** | 仅 `toast` 兜底，不定位字段 | 复用全局 `.input.err` + `.field-err`：保存时逐字段标红边框并下方显示「XX 为必填」，错误定位到字段 |
| **字段分组** | 单栏平铺 7 个字段 | 按业务语义分 3 组（归属 / 对象定义 / 价格与仓库），每组有子标题 |
| **关键操作** | 「新建配置」是 `btn-sm` 小按钮、埋在设置卡下方 | `.btn-primary` 实底、置于数据区顶部，作为唯一主操作 |
| **状态可见性** | 提醒设置须展开才知开启与否 | 三卡头部均显示状态芯片 + 一句话摘要，折叠态也可知当前状态 |
| **一致性** | 三块运行参数三种外观 | 统一为同一折叠卡组件形态 |

## 五、与现有视觉风格的一致性

- **不引入新视觉语言**：全部复用现有设计令牌（`variables.css`）——卡片 `.card`、区眉标 `.sec-label`、次级标题 `.sub-sec`、按钮 `.btn-primary/.btn-ghost`、输入 `.input`、错误态 `.input.err/.field-err`、状态色 `--p-dark / --suc / --war / --dan`。
- **统一卡片形态**：三块运行参数统一为 `AutoPeriodBlock` 已有的「折叠头 + 状态芯片」形态，不改其配色；状态芯片沿用现有 `ap-chip`（青色 `#E1F5EE` 底 + `#0F6E56` 字）、`tp-warn`（amber 底）语义。
- **字号/间距守令牌**：标题 15/13px、正文 13px、说明 12px、间距 4 的倍数，与全局一致；不新造尺寸。
