# UI 规范审查 ·【商品档案 → 编辑商品】

**审查日期**：2026-09-22
**审查对象**：`hergent-cn-v2/src/pages/ProductArchive.vue` 的编辑弹窗（模板 176–359 行，样式 1377–1529 行）
**规范基准**：`hergent-cn-v2/src/styles/variables.css`（本项目**唯一**的设计令牌与全局组件层）
**方法**：令牌逐项比对 + 模板类与样式定义的**差集审计** + 跨页横向对比（8 个页面的弹窗实现）

---

## 0. 审查基准说明（先说清"规范"是什么）

本项目**没有独立的 Design System 文档**，规范的**唯一可执行来源**是 `styles/variables.css`：它同时承担 ① 设计令牌（色/阴影/圆角/字号）与 ② 全局组件层（`.btn` `.input` `.card` `.tbl` `.page-hd` `.main-tabs` `.sec-hd` …）。

因此本次审查的判据是：**凡 `variables.css` 已定义的类与令牌，页面必须复用；凡页面自造而全局已有的，即为偏离；凡全局缺失而各页重复自造的，即为规范缺失。**

## 1. 结论摘要

| 严重度 | 条数 | 代表问题 |
|---|---|---|
| 🔴 高 | 6 | **17 个类用了但零样式定义**、关闭弹窗丢改动、无字段级校验呈现、无 dialog 语义、无键盘支持、提示文字对比度 2.5:1 |
| 🟡 中 | 9 | 阴影/控件高度/圆角偏离、禁用态无样式、无响应式断点、toast 无 aria-live、自造 Tab 与弹窗 |
| 🟢 低 | 4 | 圆角硬编码、保存按钮禁用无说明、z-index 硬编码、禁用输入用 disabled |

> **最需要立刻处理的一条**：v234/v237/v240 三期新增的编辑弹窗主体 UI（Tab 栏、包装单位三卡片、默认单位、移动端可见、价格矩阵）**共 17 个类名在全仓没有任何 CSS 定义**，元素退化为浏览器默认样式。这不是"样式不好看"，是**整块新功能没有视觉实现**。

### ✅ 已符合规范的维度

- **页面级骨架**：`.page` / `.page-hd.split` / `h2` / `.page-sub` 全部走全局层，未自造 ✅
- **主按钮层级**：`.btn` `.btn-primary` `.btn-ghost` `.btn-sm` 全部复用全局 ✅（`+ 新增` 主色、其余 ghost，层级正确）
- **卡片与表格**：`.card` `.table-wrap` `table.tbl` `.tbl .num` 复用全局 ✅
- **语义色**：状态徽标 `.pa-status.on/.off` 用 `rgba(var(--suc-rgb),.12)` 走令牌 ✅；危险态用 `var(--dan)` ✅
- **加载/进行中态**：价格矩阵按钮 `:disabled` + 文案切「保存中…」、修改记录「加载中…」 ✅
- **二次确认**：停用商品做**内联**二次确认（先点变「确认停用」+「取消」），无嵌套弹窗 ✅ 属良好实践
- **保存语义**：只提交改动过的字段（diff），并在底栏显示「N 个字段已改，未保存」 ✅

| # | 不符合项 | 所在区域或字段 | 规范预期值 vs 实际值 | 严重度 | 修改建议 |

## 3. 规范本身的缺失 / 过时 / 冲突（一并指出）

| # | 问题 | 说明 | 建议 |
|---|---|---|---|
| **S1** | 🔴 **无统一 Modal 组件与样式层** | 全站 8+ 页面各自实现弹窗，圆角/阴影/遮罩透明度/z-index 四要素全部不一致（实测：`ConnectCenter` 圆角 18px、`CronJobs` 遮罩 .45、z-index 六档） | 抽取 `<Modal>` 组件或至少把 `.modal-*` 上提到 `variables.css`（可参考已用令牌的 `rebate/TargetFormModal.vue` 作为基线） |
