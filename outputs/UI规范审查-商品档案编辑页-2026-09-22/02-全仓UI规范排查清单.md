## 二、分类明细

### B3 · 层级（z-index）散落 —— 🟡 建议（风险最高的一致性缺口）

规范（UI-SPEC §3.4）定义了：`--z-overlay:980 / --z-modal:990 / --z-toast:1100 / --z-drawer:1120 / --z-palette:1180`。
实测全仓 **16 处**覆盖 **40 / 950 / 960 / 980 / 1000 / 1121 / 1125 / 1130 / 9998 / 9999** 共 10 档，且含义重叠：

| 文件 | 当前值 | 规范期望 |
|---|---|---|
| `components/NotificationPanel.vue` | `z-index:40`（遮罩） | 应 ≥ `--z-overlay(980)`，否则遮不住页面内容 |
| `pages/CronJobs.vue` / `pages/LossAccounting.vue` 等 | `950 / 960 / 980` | 统一到 `--z-overlay` |
| `pages/Login.vue` / `components/rebate/TargetFormModal.vue` / `pages/Rebate.vue` / `pages/RoleManage.vue` | `1000` | 统一到 `--z-modal(990)` |
| `components/Shell.vue` `.md-overlay` | `1125` | 抽屉类应走 `--z-drawer(1120)` |
| `components/WeatherWidget.vue` `.wx-pop` | `1121` | 浮层应走 `--z-drawer` 或新档 |
| `components/CommandPalette.vue` | `1130` | 应走 `--z-palette(1180)` |
| `components/IdleTimeout.vue` | `9998` | 全局最高应走 `--z-toast(1100)` 之上的独立档（建议新增 `--z-critical:9990`） |
| `App.vue`（全局 toast） | `9999` | 同上 |

**风险**：`WeatherWidget` 浮层(1121) 与 `Shell` 弹窗遮罩(1125) 仅差 4，叠加时谁压谁取决于 DOM 顺序而非语义；`NotificationPanel` 遮罩(40) 根本压不住普通内容。**建议优先整改**，否则后续新增弹窗会持续踩层叠坑。

### C · 自建弹窗缺少无障碍语义（role/aria） —— 🟡 建议

规范（UI-SPEC §5.2）要求所有模态：`role="dialog"` + `aria-modal="true"` + `aria-labelledby` + Esc 关闭 + 初始焦点。
`ProductArchive.vue` 已在 v241 全量补齐。其余 **15 个**仍缺（多为只写了 `.xxx-overlay` 遮罩 + `.xxx-modal` 容器，无语义）：

`components/Shell.vue`、`components/rebate/TargetFormModal.vue`、`pages/AiHub.vue`、`pages/BrandArchive.vue`、`pages/ConnectCenter.vue`、`pages/CronJobs.vue`、`pages/CustomerArchive.vue`、`pages/EmployeeArchive.vue`、`pages/Forecast.vue`、`pages/Login.vue`、`pages/LossAccounting.vue`、`pages/PriceChannels.vue`、`pages/Rebate.vue`、`pages/ReportMapping.vue`、`pages/RoleManage.vue`

**影响**：屏幕阅读器无法识别对话框边界；键盘用户无 Esc 退出、打开时不聚焦。**不阻断功能，但属无障碍合规缺口**。

规范 §3.1 已有语义色令牌（`--suc`/`--warn`/`--dan`/`--info` 及浅底 `--*-bg`），但大量页面仍内联字面量。

### B1 · 圆角硬编码 —— 🟢 可选

多为小标签/圆点/气泡：`border-radius:3px`（10px 色块圆点）、`8px`（小标签，巧合等于 `--radius-sm`）、`6px`、以及偏离档位的 `9px/14px/18px`（气泡、胶囊）。
**处理**：`8px` 已是规范档，无需动；其余偏离值建议在 UI-SPEC 补充 `--radius-xs:6px` 与 `--radius-pill`，再逐页替换。纯视觉打磨，不紧急。

规范 §3.5 要求弹窗在 `≤640px` 降级单列、表布局允许横向滚动。
**🟡 建议（含自建弹窗的页面，窄屏会出两列挤压）**：

（这些在 C 段也缺 dialog 语义，应同批处理：补 `role=dialog` + 640px 单列降级，参照 ProductArchive v241 做法）

**🟢 可选（非弹窗组件，影响小）**：
`components/ResultCard.vue`、`components/WeatherWidget.vue`、`components/rebate/MonthlyAchvChart.vue`、`pages/AiOps.vue`、`pages/BidRadar.vue`、`pages/Settings.vue`

### A · 类差集（模板用了但样式未定义） —— ⚠️ 待人工复检，不计入上述等级

自动扫描报出 31 个文件有"未定义类"，**经抽样复核绝大多数为误报**：
- `pages/ProductArchive.vue` 的 `base/map/pack/price/stock` 来自动态绑定 `:class="{on: tab==='base'}"`（非静态类）；

**但扫描也提示了少量需人工确认的疑似项**（静态使用但全仓搜不到定义），例如：
`components/Shell.vue` 的 `tb-cp-txt`（模板 `<span class="tb-cp-txt">AI</span>` 的小徽章）、`pages/Login.vue` 的 `forgot-body/register`、`pages/Archive.vue` 的 `brands/customers/employees/products`（疑为路由视图包裹类）。
**这些不影响阻断判定（属小徽章/布局容器），建议后续逐文件人工确认是否真缺样式**，不在本次批量整改范围。

## 四、建议修复优先级

- **P1（先做的：正确性风险）**
  1. **层级令牌化（B3）**：在 `variables.css` 新增 `--z-critical:9990`，把 16 处散落 `z-index` 替换为 `--z-*` 令牌。优先级最高——层叠错乱会直接导致"弹窗被遮住/点不到"。
  2. **弹窗 dialog 语义（C）**：对 15 个自建弹窗批量补 `role="dialog"`+`aria-modal`+`aria-labelledby`+Esc+初始聚焦（可参照 ProductArchive v241 的写法做模板）。
- **P2（一致性：语义令牌）**
  3. **语义色/字号（B4/B5）**：在 UI-SPEC §4.4 已定义的 `.tag-suc/.tag-warn/.tag-dan/.tag-info` 基础上，替换 ConnectCenter/Forecast/AiOps 三重点的散落字面量；字号回归 `--fs-*`。
  4. **弹窗页响应式（D-🟡）**：6 个含弹窗页面在 `≤640px` 降级单列（复用 ProductArchive 的 `.pa-modal{max-width/min(92vw)}` 思路）。
- **P3（打磨）**
  5. 阴影/圆角令牌化（B2/B1）与新增 `--shadow-drawer/--shadow-pop/--radius-pill`。
  6. 非弹窗组件响应式（D-🟢）。
  7. 人工复检 A 段疑似项（`tb-cp-txt`/`forgot-body`/`brands` 等），确认是否有真缺样式的小容器。
