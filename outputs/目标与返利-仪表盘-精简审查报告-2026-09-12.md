# 「目标与返利 › 仪表盘」精简审查报告

日期：2026-09-12 ｜ 审查对象：`hergent-cn-v2/src/pages/Rebate.vue`（`mainTab='dashboard'`）+ `src/components/rebate/MonthlyAchvChart.vue`
审查方式：源码逐节点盘点 + 真机（1560×1200，演示租户 5 行数据）实测文案节点数与几何尺寸

---

## 一、结论摘要

**页面不算"信息过载"，问题集中在两处：同一信息被反复表达，和同一行里放了两套语法。**

| 实测指标 | 现状 | 建议目标 |
|---|---|---|
| 可见文本节点 | **103 个** | ~70 |
| 可见文案总字数 | **755 字** | ~520 |
| 其中「解释性说明」（图例 note / 口径说明 / 提示语） | **9 条** | 4 条 |
| 达成列表 5 行总高 | **811px** | ~570px |
| 单行结构 | **4 段**（标识 24px / 条形 16px / 指标 20px / 判语 38px） | 3 段（判语降级为 chip） |
| 单行高 | **144–148px** | ~104px |

**最高优先级 4 项**（详见第三节）：
1. 同一行出现**两个不同的达成率**（`110.0%` vs 条形内 `100%`）—— 不只是冗余，是自相矛盾
2. **「档位 0.0% → 100.0%，多赚 ¥-2,400」** —— 真缺陷：非阶梯规则本无档位概念，已达标行还算出负数
3. **预警行三重红色信号**（`预警`标签 + 红条 + 38px 红底横幅）
4. **「距目标 ¥1,350,000」与「还差 ¥1,350,000」** 同行重复

## 四、看着像冗余、但**不建议删**的（避免过度精简）

| 项 | 为什么留 |
|---|---|
| 「返利为按规则预估应返，非实际到账」 | **口径免责声明**。删掉后用户会拿它当到账金额对账 —— 这是产品风险，不是文案冗余。建议只是**挪位置**（挪到 KPI 的「本月预估返利」旁，与数字同处） |
| 图中 dp 虚线 + 图例「时间进度（虚线）」 | 是本页最重要的判读锚点，与时间进度着色是同一套语义的两个表达（一个定量、一个定性），不冲突 |
| 「另有 N 条非品牌维度目标未计入本图」 | **数据完整性披露**。不写就等于默默算错，必须留（但可与其它脚注合并成一条） |
| 预警行的「预计月底仅达成 25.8%」 | 这是**预测值**，与"达成率 10%"不同源、不同含义，是这一行唯一不可从别处推断的信息，必须留 |
| 异常区第 ③ 类「同品牌同月重复目标」 | 列表里看不到（两条数据看起来都正常），是异常区**唯一不可替代**的职责 |
| KPI `1 / 5`「已达标 / 生效目标」 | 分母（生效目标数）没有别处提供，保留 |

## 六、一句话总纲

> **这一页的问题不是"东西多"，而是"每件事说了两遍、每句话都带一段注解"。**
> 三个动作就能收干净：**同一信息只留一处最优位置**（G1/G2/D1/E2）、**判语从整行降级为标签**（G7）、**说明移到需要它的那一刻**（B1/E3/E4 → tooltip 或弹层）。
