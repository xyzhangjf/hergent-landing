## 二、变更（口径怎么变的）

**取值链（这是这次唯一的功能变化）**

1. **本期手工录入**（`r.casePrice`）—— 你在格子里填的数，随保存落本期记录，只在本期生效；
2. **沿用上一期**（`r.casePriceInherit`）—— 本期没填时，**自动带出该商品在本期之前最近一次录入过的价**，不用重填；
3. **都没有** ⇒ 按商品档案厂价自动算（`厂价 × 规格`）。

**关键取舍（我替你定的，若不合意请一句话改）**

- **沿用值只用来算，不落库**。本期没填就保持「没填」：库里该行的价仍是空。
  - 好处：保存不会把「没填」记成「填过」；清空后不会再被自己写回（否则你会陷入「删了它又跑回来」）。
  - 副作用：别人打开本期表看到的是同一个价（因为都从同一处取），但**数据库里没有一条「本期 88 元」的记录** —— 要追溯「本期到底按什么价算的」，看的是那一刻沿用来源那一期。
- **沿用只进灰字占位，不实填、不加粗**。一眼能区分「这是带过来的」和「这是我本期填的」；鼠标悬停会写明**是哪一期的价**（例：`沿用「08/30–09/15」录入的价 ¥88.00/箱`），并同时列出档案自动价，方便你两种价对得上。
- **沿用是逐商品的**：只有你**录过价**的商品才会被带出；没录过的仍是档案自动价（沙箱里专门做了对照行断言，防止「全表铺一个价」这种假绿）。
- **边界**：只向**更早的期次**取（严格 `< 本期`），本期自己的值优先；跨多期没填也能一直沿用（取「最近一次录入」而不是「紧邻上一期」）。
- 清空输入框 = 撤销「本期另行指定」⇒ 回落到沿用值（没有沿用来源时回落到档案自动价）。

## 四、对齐效果（证据）

**沙箱端到端（隔离租户 9997，先造一条「8/30–9/15 录过 88.00」的往期行；该商品档案自动价 45.00，两者差一倍 ⇒ 有判别力）**

| 判据 | 结果 |
|---|---|
| 沿用值只进灰字占位（`value` 空、无手工标记） | ✅ |
| 占位 = **88.00**（沿用值）而不是 45.00（档案价） | ✅ |
| 悬停说明来源（含「沿用」「88.00」「08/30–09/15」+ 档案自动价） | ✅ |
| **对照行**（没录过价的商品）仍是自己的档案自动价、无「沿用」字样 | ✅ 逐商品而非全表 |
| 金额真的吃沿用价：`下单金额 == 最终下单(箱) × 88`，且明显 ≠ × 45 | ✅ 实测 47 箱 → ¥4,136（按档案价会是 ¥2,115） |
| **未动单价**保存 → 载荷 `case_price = null` | ✅ 沿用值不落库 |
| 库层：本期 7 行的 `case_price` **全为 NULL** | ✅ 「没填」没被记成「填过」 |
| 填 99 → 保存 → 载荷 99；库层**只有该商品一行 = 99** | ✅ 本期手工价正常落库 |
| 重载回读 99；清空 → 保存 → 载荷 `null`、库层回 NULL | ✅ 可撤销 |
| 清空后占位回到 **88.00**（沿用值）而非 45.00 | ✅ 清空只撤销「本期另行指定」 |
| 全程 `batch-factory-price` 调用 **0 次**；商品档案厂价变化数 **0** | ✅ 不碰档案 |
| 三段合计 | **25/25** |

**生产真机主探针（tenant_1 期次 9，只读、全程不保存）**：**40/40** —— 单价链 `3840 → 手填 5760 → ¥28,800 → 清空回 ¥19,200`（tenant_1 的 `case_price` 全为 NULL ⇒ 沿用链不激活，**证明无沿用来源时行为与改动前逐字一致**）。

## 五、需确认事项

1. **沿用没有「作废」机制**：厂家调价后，只要该商品录过手工价，那些价会一直沿用下去（悬停里能看到「沿用价 vs 档案自动价」的差）。要不要加一条「档案厂价一变、沿用自动作废」的判据？（不加按钮，纯逻辑）
2. **沿用不落库** ⇒ 导出的 Excel 里「下单金额」会跟着沿用价算（同一取值链），但**没有哪张表能查「本期用的是哪个价」**。如果你要留痕，我可以把沿用值也落一份（代价：清空逻辑要另设标识，复杂度上一个台阶）。
3. 参照：v191 留下的两条（清单里那个 `unit` 非标准规格商品清单、别期是否要「从上一期带出」）现已被本次取代/满足。
