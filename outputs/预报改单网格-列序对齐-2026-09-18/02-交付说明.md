## 2. 变更（`hergent-cn-v2/src/pages/Forecast.vue`，单文件）

改单态编辑网格的列序由

> 报单单元 → **加单(箱)** → **金额（分销价×合计）** → 配方建议 → 上期量/Δ/趋势/去年同期/同比 → **合计（甩在最右）** → 操作

改为与「汇总表（只读）」逐列对齐：

> 报单单元 → **合计** → 件数(箱) → 配方建议 → 加单(箱) → **最终下单(箱)** → **单价(厂价/箱)** → **下单金额(厂价)** → 上期量/Δ/趋势/去年同期/同比 → 操作

四处同源落点（`<colgroup>` 由 `editColKeys` 驱动，缺一处即整表错位）：
1. `editColKeys` computed —— 汇总段重排
2. 编辑态 `thead` —— 新增 `件数(箱)/最终下单(箱)/单价(厂价/箱)` 三个 `calc-th`；`金额` → `下单金额(厂价)`
3. 编辑态 `tbody` —— 汇总单元格按新序重排；`amount` 单元格改走 `amountValue(r)`
4. 编辑态表尾 —— 补 `boxes/final/price` 三格

配套口径统一（**同屏口径同源**）：
- `editTotalAmount` 由「分销价 × 合计」改为 `amountValue` 累加（最终下单箱 × 单价(厂价/箱)）；失去引用的 `rowAmount` 已删除。
- 编辑态顶部汇总文案由「合计 X 件 · 金额 ¥Y」→「合计 X 件 · **下单金额(厂价)** ¥Y」（同屏有「分销价」列，裸「金额」会被读成分销价口径）。
- 两处推送文案（企微审批摘要、订货下单说明）的「金额 ¥」同步改为「下单金额(厂价) ¥」—— 数值口径变了，标签必须跟着自证。
- `COL_DEFAULTS` 补 `price: 104`（原走 90px 兜底，表头「单价(厂价/箱)」会折行）；两态同宽。
- 新增具名常量 `C_EXTRA_INPUT` 承载「加单」输入框的 `data-c` 哨兵值并写明**为什么它必须在选区索引空间之外**（calc 列不参与键盘导航/填充柄；原为硬编码表达式，改列序时极易误改）。

**未改动**：只读汇总表（`colOrderList`）列序本来就正确，本次未动；`分销价` 仍是主档可见列。
**命名纪律**：只读表同位置是「**系统建议**」(`r.ai`，后端固定口径)，编辑网格是「**配方建议**」(`r.suggest`，受「建议算法」面板控制、带「采纳」按钮)——两者是不同的量，本次保持各用其名，未合并。
