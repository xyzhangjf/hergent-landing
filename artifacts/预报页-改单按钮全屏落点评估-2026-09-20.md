# 预报主表「改单 / 编辑组」落点评估 —— 全屏场景（2026-09-20）

## 触发

用户两条诉求（第二条是澄清，解开了第一条的歧义）：

> ① 请调整表格工具栏的布局：将「改单」按钮及其点击后弹出的所有功能按钮统一移动到表格工具栏中，
>    使改单及改单后出现的功能按钮能够在一屏内完整展示，同时确保工具栏内所有内容仅占一行，不出现横向滚动条。
>
> ② 因为用户大概率会用**全屏功能**来查看和修改预报订单，所以要把这些按钮放在表格工具栏，
>    便于用户在全屏模式下直接操作，**不需要退出全屏模式才能进行操作**。

**解读**：② 是 ① 的因。全屏时主工具栏够不着，所以要搬按钮。

## 三、结论

1. **全屏态放得下**（只读 + 改单：全视口单行，最小余量 +191）。
2. **编辑态全屏在 1280/1366 差 139/53px**，1440 仅 +21（临界）。
3. **非全屏态放不下**：编辑态在 1280/1366/1440/1680 **全部折行**（1440 差 273px）。
   ⇒ 用户「仅占一行」的要求与「两态都搬」**数学上冲突**。
4. 顺带发现**既有缺陷**：只读态表格工具行在 **1280 现在就折行**（−21px），与本次改动无关。

## 四、方案

### 方案 A（推荐）：**全屏专属**

只在 `gridFullscreen` 为真时，把「改单」/ 编辑组渲染进 `.grid-ctl-row`；非全屏完全不动。

| | 评价 |
|---|---|
| 满足用户诉求 | ✅ 全屏下直接改单/保存，不必退出全屏 |
| 非全屏 | ✅ **零改动、零回归**（主工具栏原样） |
| ≥1440 全屏 | ✅ 单行 |
| 1280/1366 全屏 | ⚠️ 需收紧 ~140px（见下） |
| 无横向滚动 | ✅ |

**收紧 140px 的手段**（只在小屏 + 全屏档位启用，影响面极小）：

| 手法 | 收益 |
|---|---|
| 徽标「另有 N 个在售商品未显示」(180px) → 紧凑形态 | ~140px ✅ 单项即可覆盖 |
| `.tb-sep` 装饰分隔条隐藏 | ~17px |
| gap 8 → 6 | ~26px |

### 方案 B：两态都搬

| | 评价 |
|---|---|
| 满足「统一移动」字面 | ✅ |
| 非全屏折行 | ❌ **必然**（1440 差 273px）→ 违背「仅占一行」 |
| 额外代价 | 必须合并两个 toggle、图标化编辑组、缩短徽标 —— 改动大、且改变用户熟悉的非全屏布局 |

**不推荐。**

### 方案 C：全屏层内加一条「浮动按钮条」（不进 `.grid-ctl-row`）

不碰现有行、零折行风险，但多占一条垂直空间，且与用户「放在表格工具栏」的字面不符。
