# v372 交付：小程序「预报汇总总表」为空 —— 同一个接口，两端入参不同

**日期**：2026-10-03 23:42
**报告人**：老板（boss 账号）「我的 boss 账号有看到预报汇总总表的权限，今天测试了几个账号已成功报单，Web 端能看到报单，但小程序『预报汇总总表』里的数据是空的」
**结论**：**已修复并上线。小程序端零改动，不需要重新提审。**

---

## 一、一句话结论

不是权限问题，是**取数口径错位**：报单落库时的日期记的是**期次的起始日**，不是"今天"；
而小程序查汇总时默认按"今天"查 ⇒ 必然查不到。**改的是后端一处兜底（+32 行，纯新增）。**

---

## 二、先排除权限：不是"没权限"，是"取不到数"

| 检查项 | 结果 |
|---|---|
| boss 是否在后端 `SUMMARY_ROLES` | ✅ 在（含 admin/boss/supervisor/财务文员） |
| 小程序 `isApprover('boss')` | ✅ 为真 ⇒ **不进**「🔒 仅管理员/老板/督导可查看」提示 |
| 接口是否真被调用了 | ✅ 调了，只是返回 `rows=[]` ⇒ 界面显示「今天还没有预报提交」 |

⇒ **有权看到入口 ≠ 取得到数据。** 这两件事要分开查。

---

## 三、根因：报单日期记的是「期次起始日」，不是「今天」

报单落库时服务端强制推导（不信任客户端传的日期）：

```
order_date = 所选期次的 order_start
```

而 `order_start` 通常**早于**今天。于是 `forecast_submission_summary` 在四个参数
（`period_id` / `order_date` / `start` / `end`）**全空**时的兜底 `s.order_date = 今天`，
在真实业务下**几乎恒为空表**。

### 生产实测（tenant_1，今天 = 2026-10-03）

| 项 | 值 |
|---|---|
| 期次 #23「2026-10-03 报单期次」 | `order_start = 10-02`、`order_end = 10-03`、已关闭 |
| 本期报单的 `order_date` | **全部 = 2026-10-02**（21 单） |
| `order_date = 今天(10-03)` 的报单数 | **0** |
| 有量明细按日分布 | 10-02:16 / 09-28:3 / 09-26:18 / 09-22:10 —— **今天 0** |

### 为什么只有小程序中招：**同一接口、两端传参不同**

| 端 | 实际入参 | 命中分支 |
|---|---|---|
| **Web** `Forecast.vue`（6 处调用） | `summary('', p.order_start, p.order_end, p.id)` —— **全传** | 期次双口径 ⇒ 正常 |
| **小程序** `pages/summary/summary.js` | 只拼 `?date=`，**从不传 `period_id`**；默认 `date=''` | 四参全空 ⇒ **兜底"今天"** ⇒ 空 |

⇒ 只读接口实现会误判"两边应该一样"。**必须把两端的实际入参列出来对照。**

---

## 四、修法（后端一处，+32 −0 纯新增）

全空时取 `forecast_period_default()` 的期次，设好期次号后，**完全走既有的期次双口径分支**
（与 Web 端逐字同源），**不新写第二份"选期次 / 拼 SQL"的逻辑**。取不到时降级回原行为、不抛异常。

🔴 注释里钉死一条边界，**防止被抄到写路径**：
> 本兜底**只服务读路径**。`forecast_period_default()` 会选中**已关闭**的期次，写路径照抄
> 会把数据挂到用户看不见的期次 —— 正是 `import_router.py` v193（2026-09-18）的事故
> （154 个商品挂到已关闭的 9 期）。写路径要归属期次时只认 `forecast_period_current()`（仅 open）。

### ⚠️ 这个洞 2026-09-12 已经修过一次，但只修了一半

`forecast_period_default()` 的注释里**早就写着**：
> 原行为 current=None → 汇总表兜底成「今天~今天」→ **打开即空表，被误判成「小程序报上来的数据没同步」**

那次只把兜底修进了 Web 端期次下拉（`GET /api/forecast/periods` 的 `current` 字段），
**没修汇总取数函数自己的兜底** ⇒ 同一个洞在小程序侧复发。
⇒ **纪律：改完兜底必须 grep 全仓找同族兜底。**
