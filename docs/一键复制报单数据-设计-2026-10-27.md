# 一键复制报单数据 — 设计与判据（v703，2026-10-27）

## 1. 用户口径（原话，作为验收基准）

> 「只复制数字，列从『周运潘』开始、『备货』结束，行从商品第一行到最后一行，
> 如果用户按品牌进行筛选操作，那行从筛选后的商品第一行到最后一行。」

生产实测与之逐字吻合：

| 项 | 实测值（tenant_1，2026-10-27） |
|---|---|
| 报单对象列数 | **19**（`all_units`，排序 = `MIN(submission.id)` = 首次报单先后） |
| 首列 | 周运潘 |
| 末列 | 备货（经理自建列，未在「报单对象」登记） |
| 已隐藏列 | 易胜玲、永诺旗舰店、汴河、沃尔玛（`forecast_hidden_units`） |

## 2. 复制内容

- **范围**：`cross.units` 全段（报单对象列），**不含**表头、商品名等主档列、合计/金额等汇总列。
- **行**：`flatItems` 里 `kind === 'row'` 且分组未折叠的行 —— 即屏幕上从上到下；
  跟随搜索、品牌、到货周期、列筛选 / 唯一值筛选、表头排序、「仅显示有报单」。
- **空格**：留空（TSV 里两个连续 `\t`），**绝不写 0**。屏幕就是空白，写 0 会污染主管的均值/计数。
- **格式**：`\t` 分列、`\r\n` 分记录；值内若含制表/换行替换为空格（防一行变两行）。

## 3. 为什么值必须"纯净"

模板里同一列有两种取值用途：

| 函数 | 用途 | 形态 |
|---|---|---|
| `cellText()` | tooltip / aria / 屏幕文本 | `¥1,234.00 /箱`、`—`、`缺规格` |
| `cellRaw()` | **进表格文件**（复制、导出 xlsx） | `1234`、``、`` |

把后者的位置写成前者，粘进 Excel 就是**文本**，主管无法求和 —— 这是本轮最关键的一条。
`—` 是视觉占位、`缺规格` 是文案，两者在文件里一律为空串。

## 4. 顺序保证（结构性，不靠人肉核对）

唯一来源：

```
screenColumns()  = colOrderList      → 列序（屏幕从左到右）
screenRowItems() = flatItems         → 行序（屏幕从上到下）
screenRowCells() = cellRaw(每列)      → 取值（与模板逐列同一个函数）
```

表头（`screenHeaders()`）与数据行（`screenRowCells()`）由**同一个列数组**产出，
"第 N 列表头是谁、第 N 列数据是谁"是结构性成立的。

**不能读 DOM**：表体有虚拟滚动，屏幕上只真实渲染 20~26 行，抄 DOM 必漏行。

## 5. 与既有能力的关系

| 入口 | 用途 | 输出 |
|---|---|---|
| 行首「复制报单」→ 厂家编码 / 下单数量 | 贴到厂家系统下单 | 两段纯文本（各 N 行） |
| 「导出」→ 导出全部 / 选中行 / 差异 | 存档、发给别人 | `.xlsx` |
| **「导出」→ 复制整表数据（粘贴 Excel）** | **贴到主管的 Excel** | **TSV（只数字）** |

三者互不替代；新增项并入「导出」下拉，**不新增工具栏按钮**（该行宽度已紧，1536 视口曾折行）。

## 6. 顺带收口的三套旧口径（本轮一并修）

| 旧实现 | 问题 |
|---|---|
| `gridHeaders()` / `gridRowCells()` | 缺 合计(小单位)/合计(箱)/加单(箱)/最终下单(箱)/单价(进价/箱) 五列；客户空格写 `0`；只给「建议(件)」不给实际列名 |
| `filteredRowsForExport()` | 自己重写筛选：**漏品牌与到货周期**；明写「不受排序重排影响」⇒ 屏幕排好的序到文件里又变原始序 |

三者全部删除（不留同义空壳，留一个就一定有人再往里加分支），导出 xlsx 与打印改走 `screen*`。
打印副标题随之补报「品牌 / 到货周期 / 唯一值筛选」—— 同源之后不写就是谎报。

  294 行 × 19 列、字段数一致、无中文 / 无 `¥` 千分位、空格保留、行数 = 屏幕最后序号、

  导出表头 31 列与屏幕逐列同名同序；勾「仅显示有报单」后只复制 3 行；按品牌分组后仍 294 行且向量不变。

期望值由 SSH **只读** SQL 生成到 `/tmp`（客户名/销量是脱敏红线，不落 `outputs/`），测完删除。

## 8. 已知边界（如实记录）

1. **不含商品名** ⇒ 粘贴位置必须与页面行序对齐。回执固定报「N 行 × M 列 · 首列→末列 · 首末商品名」，
   这是用户粘完唯一能自查错位的锚点。
2. 分组**折叠**分支未做线上自动化：该期按品牌只有 1 个组（折叠即全表隐藏），且虚拟滚动下
   点击目标会被重建替换 ⇒ 断言不可靠。判据与模板是同一个表达式 `openGroups[it.gkey] !== false`。
3. 顺带发现、**非本轮引入**且未改：导出下拉展开时同行「到货周期」按钮层叠更高，形成遮挡带。
