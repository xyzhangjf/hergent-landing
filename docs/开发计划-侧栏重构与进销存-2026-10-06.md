1. **判定基准必须是「生产生效集」，不是 `assets/` 并集** —— 从 `index.html` 入口递归解析

3. **Vue scoped CSS 会插 `[data-v-xxxxxxxx]`** ⇒ 精确串 `.foo{…}` 对 scoped 规则恒 0 命中，须用正则。
   另：`background` / `clearTimeout` 这类通用词命中**没有判别力**（任何 CSS/JS 都有）。
