## 二、潜在 Bug

### 高
- **import_zhoupu.py:428**（舟谱导入账号默认口令）
  - 问题：`pw = core._hpw('hergent2026')` 为所有被导入员工设置相同硬编码口令。
  - 影响：知道源码或猜到口令者可登录任意被导入员工账号；若账号绑定老板/财务角色风险更大；口令不会自动失效。
  - 修复：不写死口令；导入时置 `password_changed=0` 强制首登改密，或生成随机口令仅一次性展示；至少改为启动环境变量/配置项。

### 中
- **Forecast.vue:7621**（`saveSnap` 的 JSON.parse 无保护）
  - 问题：`const list = JSON.parse(localStorage.getItem(SNAP_KEY()) || '[]')` 无 try/catch，而同文件 `loadSnaps()`（7618）对同源做了兜底，两处不一致。
  - 影响：localStorage 快照 JSON 损坏/截断时抛出未捕获异常，保存快照崩溃且成功 toast 不执行，用户误以为保存成功。
  - 修复：与 `loadSnaps` 一致，包 try/catch 失败时回退 `[]`。
- **ReportMapping.vue:334**（导入失败列表空值守卫缺失）
  - 问题：`v-if="importResult.failures.length"`，成功导入（无 failures 字段）时 `importResult.failures` 为 `undefined`，`.length` 抛 `TypeError`，结果弹层白屏。
  - 影响：0 失败的成功导入弹层崩溃，用户看不到成功反馈。
  - 修复：`v-if="importResult.failures && importResult.failures.length"`，并对 `imported`/`failed` 加 `|| 0` 兜底。
- **ReportMapping.vue:72/80/84/88/472**（health 子数组直接 `.length`）
  - 问题：`health.alias_conflicts.length` 等子数组无 `?.` 或 `|| []` 守卫，任一字段缺即抛 `Cannot read properties of undefined`；`health` 由多接口聚合，任一字段缺失即触发。
  - 影响：配置体检区或整页渲染崩溃。
  - 修复：加载时归一化 `health = r || {alias_conflicts:[], unmapped_objects:[], unassigned_employees:[], ...}`，模板统一用可选链。
- **einvoice_engine.py:243-251, 297-302**（发票号取号非原子）
  - 问题：序号由 `SELECT COUNT(*)+1 WHERE invoice_no LIKE ?` 得出，读与写之间非原子，`invoice_no` 有 UNIQUE 约束；红冲（351）同逻辑；INSERT 无 try/except。
  - 影响：并发开票时第二个 INSERT 抛 `sqlite3.IntegrityError` → 500。
  - 修复：用自增/原子序号或随机后缀（`secrets.token_hex`，参考 `db/connection.py:_gen_no`）；或把取号+插入放进事务并在 `IntegrityError` 后重试。
- **einvoice_engine.py:322-333**（事务内做外部网络调用）
  - 问题：`with get_db_tx() as db:` 内调用 `_call_tax_api`（最长阻塞 30s），租户库 `busy_timeout=5000ms`。
  - 影响：事务/连接被持 30s，其间该租户其它请求排队甚至超时失败。
  - 修复：先把 API 调用移到 `with` 块外，调用成功后再以独立短事务更新状态。
- **import_zhoupu.py:76-86, 141-146**（破坏性整表清空无租户守卫）
  - 问题：`conn.execute("DELETE FROM products")` 及 inventory/sale_orders 等整表清空，脚本无任何 `set_tenant_context(None)` 守卫。
  - 影响：若被放在带 `X-Tenant-Id` 的上下文执行，`get_db()` 落到某 `tenant_N.db`，误删真实业务数据且不可恢复。
  - 修复：开头显式 `set_tenant_context(None)` 或断言 master 上下文；破坏性全量重导加 `--force` 标志。
- **tenant_audit.py:113-126**（异常路径连接泄漏）
  - 问题：`c = sqlite3.connect(f)` 后、`c.close()` 前抛异常时，`except` 只记错误不关闭连接。
  - 影响：扫描大量租户库时连接句柄累积泄漏。

- **platform.py:385-386**（新建账号 role 未归一化）

  - 问题：`localStorage.setItem('hermes_v2_key', key.value.trim())` 明文存储 Bearer Key。
  - 影响：任意 XSS（即便同源其它组件漏洞）可读密钥并以用户身份调用 Hermes 服务。
  - 修复：改内存变量/会话内保存；若必须持久化，加短有效期+可吊销并在安全说明中记录。
- **CopilotDrawer.vue:90**（`v-html` 渲染 AI 内容）
  - 问题：`<div v-html="renderMd(m.content)">` 依赖 `renderMd` 永远先 `esc()` 转义；该 XSS 不变量押在单个函数上。
  - 影响：一旦 `renderMd` 改动放行原始 HTML，即产生存储型 XSS。
  - 修复：渲染前用 DOMPurify 再过滤一次，仅放行 `b/i/code/ul/ol/li/table` 等标签与禁 `on*` 属性。
- **metrics.py:42-89**（`/metrics` 无鉴权 + 全局聚合）
  - 问题：`/metrics`、`/health/ready` 端点无鉴权；计数器为进程级全局，不区分租户。
  - 影响：未授权可读跨租户聚合请求量/路径/库大小/会话数，运维信息外泄。
