## 三、本轮新增问题

### 低-新1 · BidRadar 内联手写 `<svg>` 图标，未复用本仓 `<Icon>` 组件（UI 规范一致性偏差）

- **路径与行号**：`hergent-cn-v2/src/pages/BidRadar.vue:5`（搜索按钮的纸飞机图标）、`hergent-cn-v2/src/pages/BidRadar.vue:66`（「取消默认地区」X 关闭图标）。
- **真实代码行**：
  - 第 5 行：`<svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M3 11l19-9-9 19-2-8-8-2z"/></svg>`
  - 第 66 行：`<svg width="11" height="11" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.6" stroke-linecap="round"><path d="M18 6L6 18M6 6l12 12"/></svg>`
- **问题描述**：两处均为手写的 Lucide 风格线性图标。但本仓既有约定是统一用 `components/Icon.vue` 组件（`<Icon name="..."/>`）——Forecast.vue（`<Icon name="alert-triangle"/>`、`<Icon name="close"/>`）、ReportMapping.vue（`<Icon name="close"/>` 经 `import Icon from '../components/Icon.vue'`）、PayrollWorkflow.vue 等同款用法。BidRadar 既未 `import Icon`，也未走 `<Icon>`，等于绕开了本仓图标单一出口。该组件**未全局注册**（各页自行局部 import），故此处不是"省了 import"，而是漏了统一入口。
- **可能造成的影响**：视觉上仍是线性 `currentColor`，短期不影响功能；但违背 site-wide UI 规范（图标合规审计以 `<Icon>` 为单一判定点），后续若 `Icon.vue` 统一调整（如换库、加 `aria`、改 `stroke-width`）此处不会跟随，形成一致性漂移。
- **最小改动修复建议**：在 `<script setup>` 顶部加 `import Icon from '../components/Icon.vue'`，并将第 5 行替换为 `<Icon name="send" />`、第 66 行替换为 `<Icon name="close" />`（与 Forecast.vue 关闭按钮同款），删掉两处内联 `<svg>`。
