### 低-新1 · `pages.js` 父级 `/archive` 注释漏列 `suppliers` 子路由（注释漂移，无功能影响）

- **文件 / 行号**：`hergent-cn-v2/src/constants/pages.js:245`
- **真实代码行**：
  ```js
  //   档案管理：`/archive/employees|customers|brands|products|warehouses|prices` 六个子路由自动继承本行。
  ```

- **问题描述**：该注释称「六个子路由」，但实际子路由已于 v387 增至 **七个**——`/archive/suppliers`（见同文件 `:280` `{ title: '供应商档案', module: 'data', roles: BIZ_ROLES }`）。注释未同步补 `suppliers`。
- **可能造成的影响**：**当前无运行时故障**（功能三处已对齐，见下）。但本项目反复踩过「入口可见性三处（页签表 / pages.js / router）必须同批同步，缺一即假入口或假封锁」的坑（v332 / v341 / v387）。注释作为「唯一真源」若漏列一项，未来维护者照注释做同步时可能漏掉 `suppliers`，埋下回归隐患。
- **三处一致性已核实（本轮无 bug）**：
  - `Archive.vue:82` `TABS` 含 `{ key:'suppliers', path:'/archive/suppliers' }`；
  - `pages.js:280` 有 `/archive/suppliers` 精确登记行；
  - `router/index.js:109` 有 `{ path: 'suppliers', component: Archive }`。
- **最小改动建议**：把 `:245` 注释的「六个」改为「七个」并补 `suppliers`，或改为「各子路由见下方逐条登记行」。仅改一行注释，零逻辑改动。
