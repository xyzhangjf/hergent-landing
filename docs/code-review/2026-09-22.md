### 【高】Forecast.vue:8437-8441 — 异常自愈闭环：乐观更新 + 静默吞错，写失败无回滚无提示

```js
async function setHeal(id, status, note) {
  const it = healIssues.value.find(x => x.id === id)
  if (it) { it.status = status; if (note != null) it.note = note }   // 8438-8439 先改本地
  try { await forecastApi.interventionsPost({ id, status, note: note || '' }) } catch (e) {}  // 8440 静默
}
```
- **影响**：第 8438-8439 行先改本地状态，第 8440 行把服务端写入的失败**完全吞掉**。网络异常 / 401 / 校验失败时，界面已显示新状态而服务端仍为旧值，刷新后"改了一半"，且用户**收不到任何失败反馈**——正是该项目已反复踩过的「提交了但看不出成没成」失败模式。
- **最小修复**：失败时回滚本地值并提示，例如
  `catch (e) { if (it) { it.status = prev; it.note = prevNote } toast('保存失败：' + (e.message || e), 'err') }` （需在改动前存 `const prev = it.status, prevNote = it.note`）。

### 【中】server/domain/forecast_engine.py:545-550 — 效期解析失败 `continue`，整行库存静默不计入临期统计

