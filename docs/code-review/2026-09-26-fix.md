- **修改内容**（`hergent-cn-v2/src/pages/Forecast.vue:7773-7774`）：

## 🟡 L4 · `os.popen` 拼接 shell 命令

- **原问题**：`server/server.py:4941` `os.popen('ps -o rss= -p ' + str(os.getpid()))`。附带发现**潜在真 Bug**：原代码 `round(....read().strip())` 对**字符串**调用 `round()` 会抛 `TypeError` ⇒ 该 psutil 缺失兜底路径**从来就没成功过**。
- **修改内容**（`hergent-erp/server/server.py`）：
  1. 第 5 行 import 追加 `subprocess`。
  2. 第 4941 行改为
     ```python
     try: mem_mb = round(int(subprocess.check_output(['ps', '-o', 'rss=', '-p', str(os.getpid())], text=True).strip()) / 1024)
     ```
- **修复后预期效果**：不再经 shell 解释（无拼接注入面）；`int(...)` 显式转换使兜底路径**真正可用**（psutil 未安装时内存读数不再是 0/异常）。
- **验证方式**：`ast.parse` 通过；`grep -n os.popen server.py` → 无命中；本机 `python3 -c "import subprocess,os;print(subprocess.check_output(['ps','-o','rss=','-p',str(os.getpid())],text=True).strip())"` 输出正整数。
