# 全站表头冻结审计清单（v720 基线）

> 扫描日期：2026-11-02｜基线构建号 **v720**（生产 `https://hergent.cn/`）
> 范围：`hergent-cn-v2/src` 全量 87 个含表格的 `.vue`，共 **161 个 `<table>`**
> 方法：静态解析（逐文件维护 DOM 祖先栈）+ 生产真机采集（59 个页面族，1440×900）+ 行注入实验

---

## 一、一句话结论

**表头冻结在全站是「三套机制并行、各管一段」，不是统一能力。** 161 个表格里 **43 个** 走共享类 `freeze-list`、**3 个** 走进销存专用的 `.psi-tbl`、另有一批各页自写 sticky（约 12 处，质量参差）；**剩下 101 个既不在共享机制里、也没写 sticky**。

更要紧的是：**写了 `position:sticky` 不等于冻结生效**，它还有一个硬前提 —— 表必须待在一个**有限高、自己会纵向滚动**的容器里。全站 `.table-wrap` 的全局定义只有 `overflow-x:auto`、**没有限高**，所以凡是没有额外限高的表格，sticky 都退化成「跟着页面一起滚走」。本轮抓到两类：

- **假冻结 1 例**（商品目标：写了 sticky，但容器不限高 + 外层 `overflow:hidden` 双重吃掉）—— 静态判定，页面当前无数据无法实测；
- **连 sticky 都没写 1 例**（定时任务：`.tbl-wrap` 这个类在 CSS 里根本不存在，等于裸 div）—— 已实测表头滚走。

| 指标 | 数值 |
|---|---|
| 静态扫到的 `<table>` | **161**（208 个 `.vue` 里 87 个含表格） |
| 真机跑过的页面族 | **59**（1440×900） |

| 结论 | 数量 | 含义 |
|---|---|---|
| ✅ 钉住（滚 400px 表头不动） | **12** | 冻结确实生效 |
| 🔴 滚走（滚 400px 表头跟着走） | **4** | 应冻未冻，已确证 |
| — 不适用（表未超视口 / 容器不滚也装得下） | **19** | 冻不冻看不见差别 |

> 「4 个滚走」是**当前有数据**的部分。建单/退货 9 个明细表因为默认只有 15 行、没超视口，真机直接跑测不出来，所以用**行注入实验**（`--grow`）把它们逼到 45 行再测 —— 结果全部滚走，计入清单 B-P0。

## 三、冻结要生效，必须同时满足两个条件

| 条件 | 说明 | 不合格的表现 |
|---|---|---|
| ① 表头有 `position:sticky` | 钉住的声明 | 表头随内容滚走 |
| ② 表在一个「有限高 + `overflow-y:auto`」的容器里 | 钉住的**舞台**；sticky 只在它的滚动祖先内吸附 | 容器高度等于内容高度 ⇒ 容器永不滚动 ⇒ sticky 无吸附空间 ⇒ 等于没写 |

两种典型失效：

- **写在 `overflow:hidden` 祖先里** —— 该祖先会成为 sticky 的「最近滚动容器」，但它不滚 ⇒ sticky 静默失效。`ProductTarget` 的 `.pt-card{overflow:hidden}` 就是这一例；`InvPurchaseDetail.vue:542` 里已有一行注释记过这个坑（当时把合计行移出 `.ipd-plain` 才修好）。
- **容器没限高** —— 见上表第 ② 条。全局 `.table-wrap` 正处于这个状态。

## 十、复现方式

三个探针已入库到 `.workbuddy/tools/`，与既有的 `v716-contrast-audit.mjs` / `v720-scale-audit.mjs` 同一套 `cdp-lite`：

```bash
cd /Users/zhangjunfeng/Documents/laozhangai-product

HG_TOKEN=<boss token> node .workbuddy/tools/v720-table-freeze-scan.mjs --live

# ③ 真机：往明细表注入 30 行，看表头是否滚走（阳性对照用）
HG_TOKEN=<boss token> node .workbuddy/tools/v720-table-freeze-scan.mjs --grow
```

两次真机运行会把原始读数写到 `/tmp/tbl-live.json`（59 页 × 35 个渲染表格）；这是临时产物，重跑即再生，不入库。

**纪律提醒**（本轮踩过的）：
- 判「表头是否钉住」不能只看 `getComputedStyle(th).position === 'sticky'` —— 商品目标、定时任务都是这么被误判成「已冻结」的。必须**内滚一段再测表头位置**。
- 找滚动容器不能只看 `overflow-y`，`overflow:hidden` 同样会成为 sticky 的锚点（`ProductTarget` 就是被 `.pt-card{overflow:hidden}` 吃掉的）。
- 页面无数据时表格用 `v-if="rows.length"` 整块不渲染 ⇒ 真机扫出来是 0 个表。**空数据页只能按结构判定**，本清单已逐条标注证据等级。
