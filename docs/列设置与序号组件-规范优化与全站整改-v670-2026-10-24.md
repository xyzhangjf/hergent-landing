## 二、规范说明（v670 补齐的五个维度）

> 完整条文见 §2.6.1，这里只列"新增/改写了什么"，方便对照。

### 2.1 适用范围与判定标准（新增判定树）

两个问题各自独立回答：

| 判据 | 是 | 否 |
|---|---|---|
| 这张表会不会被用户说成「**第几行那个**」？ | 必须有序号列 | 不要 |
| 这张表的**列集合会不会变**（可加主档列/可隐藏/可拖序）？ | 必须有齿轮 | 不要 |

🔴 绑定关系：**齿轮的宿主就是序号列表头** ⇒ 要齿轮必须同时有序号列，反之不然。

### 2.2 视觉层级（新增，`--z-*` 阶梯）

| 档 | 值 | 谁 |
|---|---|---|
| 序号列冻结 | 6（表体）/ 9（表头） | 粘性列 |
| 全屏层 | `--z-page-fs` **1000** | `.grid-area.is-fs` |
| **列菜单遮罩** | `--z-page-overlay` **1100** | `.col-menu-overlay` |
| **列菜单本体** | `--z-page-menu` **1101** | `.col-menu` |
| 页面模态 | 1125 / 1130 | Modal |
| 快捷键浮层 | 1250 | `.kbd-pop` |

判据：**遮罩与本体成对**取 1100/1101。低了被全屏层盖（面板不在全屏层内部）；高了浮到确认框上；只抬本体不抬遮罩 ⇒ 全屏下"点空白关闭"失效。

### 2.3 间距与对齐（新增，全部收敛为一张表）

| 项 | 值 |
|---|---|
| 序号列宽 | **46px**（唯一值） |
| 序号格内距 | 表头 `8px 4px`、表体 `6px 4px`（紧凑档 5/3px） |
| 数字形态 | 必须包 `.seq-num`：`tabular-nums` + `min-width:18px` 居中 |
| 齿轮按钮 | **30×30**、`--radius-sm`、`color:--t2`、透明底 |
| 齿轮图标 | `<Icon name="settings" :size="15"/>`（**必须显式写 15**，默认是 16） |
| 面板 | `width:240px`、头部 `10px 12px`、清单行 `6px 8px`、间距 `gap:6px`、贴边 `pad:8px` |
| 对齐 | 齿轮居中于序号列（`margin-inline:auto`，因为 `space-between` 对单子元素等价 `flex-start`） |

### 2.4 交互状态（新增一张表 + 一条硬判据）

默认 / hover / 禁用 / 打开中四态逐元素定义。核心硬判据：

> 🔴 **列清单复选框必须 `@change`，⛔ 禁 `@click.prevent`**。
> Chrome 的 pre-click activation 会**先**翻转 `checked`、**再**派发 click；`preventDefault()` 让浏览器在派发**结束后**把翻转**还原** —— 而 Vue 的 patch 只写翻转前的值 ⇒ 勾选态与列显隐**永久相反**，只有重开面板才对齐。
> 🔴 验收必须发**真实鼠标事件**：`el.click()` 没有 pre-click activation，会把这类缺陷全部漏掉。

### 2.5 响应式（新增，定位/限高/收起）

面板 `position:fixed`，`top/left/maxHeight` 由 `useColMenu` 按齿轮 rect **现算**：
默认下方 `gap:6px` 左缘对齐 → 下方放不下上翻 → 右侧越界改右对齐 → 仍越界贴边；
**限高必须与移位配对**（v401 真机：清单 543px，上下都只剩 ~520px，光移位照样盖住齿轮）；
任何 `scroll`（捕获阶段）/ `resize` 直接收起。

### 2.6 同时修正的四类「文档 - 实现」漂移

1. 齿轮/面板 CSS 全部换成 v432 实现版，旧版标注**作废**；
2. `.seq-th` 选择器写法改正为 `th.seq-th`（v402 靠 `(0,2,2)` 稳压页面 scoped 的 `(0,2,1)`）；
3. 「齿轮只在 `/forecast`」改为现状（28 处 / 22 页）+ 写明「已作废」；
4. 补数据契约：`useColSettings` 的 `page` 键**必须**在后端 `COL_PREF_PAGES` 登记（否则 400、配置永远存不上，且只在 console 留痕）。

## 三、全站排查：方法

不用一次性 grep（本机 `grep "A\|B"` 会静默失效、`| head` 会截掉决定性命中）。新增**可复跑工具**：

```bash
python3 tests/spec/seq-colcfg-audit.py          # 人读表格
python3 tests/spec/seq-colcfg-audit.py --json   # 机器读
```

它扫 8 类事实：齿轮实例 / emoji 齿轮 / 序号三件套 / 表类归属（非 `tbl` 必须带 `seq-host`）/
序号取值与跨页补偿 / 私有序号样式 / 列菜单实现方式 / 复选框写法。

两个**工具自身**的坑（第一版踩过，已修）：

- **扫注释会误报**：`<!-- -->` 与 `/* */` 里出现 `col-cfg` / `.seq-th` 全是噪声 ⇒ 先剥注释（等长空白替换，保行号）。
- **扫全文会淹没真问题**：一个页面常有多张表（阶梯表/说明表/弹窗表）⇒ 只取「确实含序号格的那张表」向上回溯最近的 `<table`。第一版据此报了 17 条噪声、真正漏 `seq-host` 的反被淹掉。
