## 一、扫描方法（覆盖四盲区）

| 盲区 | 覆盖方式 | 结果 |
|---|---|---|
| 组件 `.vue` 零引用 | 按 stem 全库正则（标识符 + `.vue` 路径双匹配） | 命中候选 |
| 短 stem（<5 字符）误判 | 单独扫 App/Icon 等 | 均活着 |
| `.js`/`.ts` 模块零引用 | 按模块名全库匹配 import | 0 个 |
| `import.meta.glob` 批量注册 | 全库 grep | 0 处 |

**判定标准**：一个文件「零引用」= 无任何其他文件 `import` 它（静态 import、动态 `import()`、路由懒加载、`app.component` 全局注册、`import.meta.glob` 批量注册都算引用）。
