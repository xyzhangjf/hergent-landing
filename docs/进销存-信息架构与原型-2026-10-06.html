模块清单（用途 + 优先级）

优先级模块用途（一句话）低温奶/你的业务要点
P0 · 第一版 基础档案 所有单据的「字典」：商品 / 供应商 / 客户 / 仓库 商品含条码、三档单位与换算、品牌；供应商=蒙牛厂家；客户=门店/分销商/永辉等
P0 · 第一版 采购进货 采购单 → 入库，记进货价、数量、批次、效期 到货即入库；批次号 + 到期日必须在入库那一刻就登记（否则效期就算不准）
P0 · 第一版 销售出货 销售单 → 出库，记售价、数量；含车销 / 访销 / 自提 三种出货场景：车销（沿街配送）、访销（门店下单）、自提（分销/永辉/美廉）
P0 · 第一版 库存查询 按商品 / 仓库 / 批次 / 效期查实时库存 「现在还剩多少、最早哪天到期」—— 这是替代舟谱后每天都要看的那一眼
P1 · 第二版 效期与批次 临期预警、批次追溯、先进先出 低温奶保质期短，临期 7 天内必须能一眼拉出来 —— 这是你的核心痛点
P1 · 第二版 盘点 定期盘点、盘盈盘亏、调整库存 库存账实要对得上；盘点差异要能留痕
P1 · 第二版 调拨 双仓 / 门店之间调货 东津、吾悦两门店之间的货要能互相调
P1 · 第二版 往来账 应收（客户）/ 应付（供应商）+ 收付款 谁欠我多少钱、我欠厂家多少钱、回款进度 —— 钱的闭环
P2 · 第三版 进销存报表 毛利 / 周转 / 滞销 / 效期分布 经营分析，也是将来「卖点」—— 经销商最缺的就是看得懂的经营账
P2 · 第三版 赠品管理 厂家赠品政策、赠品进出库 蒙牛赠品政策常见，赠品成本要能单独算
P2 · 第三版 与既有能力打通 报单 → 采购建议；返利；货损 复用你已做好的预报订货、返利、货损核算，形成闭环
注：P0 四块是「替代舟谱」的最小闭环 —— 没这四块，你没法把业务从舟谱迁过来；P1 补齐低温奶的效期与钱的闭环；P2 才是对外卖的增值点。
