# v736 · 品牌色统一（小程序 ↔ Web）

2026-11-03 · 用户反馈：「我怎么感觉小程序和 Web 端的品牌色不一样呢？」

---

## 一、结论

**用户感觉成立，而且不是"审美差异"——小程序用的正是 Web 端 v717 就已经修掉的旧值。**

修完后两边是**同一个值**：`#0E7490`。
小程序 62 处样式 + 5 处原生配置 + 2 张图标 PNG；Web 2 个法务页。

按用户选择执行 **方案 ②**：统一文字与按钮 + 收法务页，**logo 的渐变底色不动**（品牌资产，改动要重出 6 个尺寸并重新提审）。

---

## 二、实测：到底哪里不一样

| 语义位置 | Web（v735） | 小程序（改前 v393） |
|---|---|---|
| 主按钮 / 选中底 | `#0E7490` 白字 **5.36** ✓ | `#06B6D4` 白字 **2.43** ✗ |
| 可点文字 / 链接 | `#0A5A6D` **7.79** ✓ | `#06B6D4` **2.43** ✗（压页底 2.23） |
| 卡片副标题 | 用 `--t2` 灰 | `#0891B2` 压 `#ECFEFF` **3.54** ✗ |
| 原生导航栏 | —（玻璃质感白底） | `#06B6D4` + 白字 **2.43** ✗ |
| tabBar 选中 | —（侧栏，非 tab） | 文字 `#06B6D4` + 图标 PNG 也是 `#06B6D4` |
| 品牌青 `--p` | `#06B6D4` **只做装饰** | **被当成主色** |

**根因不是"选错了颜色"，是同一个"品牌青"在项目里长出了三个值：**

```
#06B6D4 (189°)   亮青      白字 2.43  ✗
#0891B2 (192°)   中间档    压浅青底 3.54  ✗
#0E7490 (193°)   深青      白字 5.36  ✓   ← Web --p-solid 同值
```

同一屏出现两档青，人眼就能分辨 —— 这就是"感觉不一样"的直接来源。
而 `#0891B2` 那档还是 11px 小字压浅青底，**3.54:1 连 AA 都不到**：所谓"不一样"里，有一半其实是"看不清"。

## 三、改了什么

### 3.1 小程序：建令牌 + 62 处收口

**新增 `app.wxss`**（本仓首次引入 CSS 变量）：

```css
page{ --brand:#0e7490; }
```

`page{}` + `var()` 是微信官方暗色适配文档采用的做法，基础库 3.4.3 完全支持。

**62 处 `#06B6D4` / `#0891B2` / `#0E7490` → `var(--brand)`**，分布：

| 文件 | 处数 | 典型 |
|---|---|---|
| `pages/fill/fill.wxss` | 32 | `.submit-btn` `.dock-btn-main` `.msg-bar` 全家 |
| `pages/mine/mine.wxss` | 7 | `.avatar` `.entry-ic` `.rec-copy` |
| `pages/login/login.wxss` | 6 | `.btn` `.remember-box.on` `.lk` |
| `pages/summary/summary.wxss` | 5 | `.copy-btn` `.date-btn` `.ai-num` |
| `pages/no-permission/no-permission.wxss` | 5 | `.btn-primary` `.btn-ghost` `.idx` |
| `pages/messages/messages.wxss` | 4 | `.seg.on` `.hact` |
| 其余 4 个文件 | 3 | password / forgot / legal |

**装饰也一起收了**：`.msg-accent`（6rpx 竖条）、`.prod-row-flash`（闪烁描边）原本是亮青 ——
如果只改主色、留这两处亮青，它们就成了"全屏唯一一个亮青"，反而更像遗留 bug。**统一走 `--brand`。**

### 3.2 吃不到 CSS 变量的 5 处（必须同批手改）

CSS 变量在 `app.json` / `wx.showModal` 参数 / 组件属性里都取不到：

| 位置 | 键 |
|---|---|
| `app.json` | `navigationBarBackgroundColor`、`tabBar.selectedColor` |
| `app.js` | 版本更新弹窗 `confirmColor` |
| `pages/fill/fill.js` | 「覆盖当前已填内容？」`confirmColor` |
| `pages/privacy-settings/privacy-settings.wxml` | `<switch color>` |

### 3.3 两张图标 PNG（最容易被漏的一处）

`assets/tab-fill-active.png` / `tab-mine-active.png` 是**纯单色位图**，`#06B6D4` 直接烘在像素里。

> 只改 `app.json` 的 `selectedColor`，会出现**图标亮青、文字深青**并排 —— 比改之前更不一致。

两个文件都只有 1 种 RGB（原文件 52/31 种变体是 ±2 的压缩噪声），
处理方式：**保持 alpha 通道逐像素不变、只换 RGB**，改后每个文件只剩一种颜色 `#0E7490`，
可见像素数 1418 / 1320，与改前完全一致（形状零改动）。

### 3.4 Web：两个法务页

`public/legal/terms.html`、`privacy.html` 自己维护了一套品牌色 `--p:#0d9488`（青绿，色相差 18°）——
纯遗漏，不是设计选择。改为 `#0e7490`，顺手把链接对比度从 3.5 提到 **5.36**。

已部署线上（`/opt/hergent-cn-v2/legal/`，md5 逐字节一致，线上回读 `--p:#0e7490`），
并把 `dist/legal/` 一起同步 —— 否则下次谁部署闭包，会把线上这两个文件刷回旧色。

## 四、改后对比度（全部按实际底色算）

| 组合 | 对比度 | 判定 |
|---|---|---|
| `#0E7490` 压白卡片 | **5.36** | ✓ AA |
| `#0E7490` 压页面底 `#F5F5F7` | **4.92** | ✓ AA |
| `#0E7490` 压浅青底 `#ECFEFF` | **5.15** | ✓ AA（原 3.54 ✗） |
| `#0E7490` 压灰底 `#F2F2F7` | **4.80** | ✓ AA |
| 白字压 `#0E7490`（按钮/导航栏） | **5.36** | ✓ AA（原 2.43 ✗） |

> 口径说明：这一档按用户选的"一个深青走到底"，只做到 AA ≥4.5，没追 AAA 7。
> 理由是小屏上 `#0A5A6D`（7.79）接近墨黑，会让"能点的字"和正文黑字混在一起、丢掉可点暗示。
> 这是**取舍**，不是疏漏 —— 如果哪天要提 AAA，只需改 `app.wxss` 一行。

## 五、护栏：`check-miniprogram-brand.mjs`

位置 `.workbuddy/tools/check-miniprogram-brand.mjs`，六条：

1. 除 `app.wxss` 声明行外，任何 wxss/js/wxml 出现品牌色字面量 → 报错（注释自动跳过）
2. `app.wxss` 必须声明 `--brand` 且**精确等于** `#0e7490`；不许出现 `--brand-xxx` 第二档
3. `--brand` 在 4 种实际底色上、以及白字压它，全部 ≥4.5（改浅了当场挂）
4. 5 个原生载体逐项核对值
5. **两张图标 PNG 逐像素解码校验**（自带最小 PNG 解码器，支持 8bit RGBA/RGB 非隔行）
6. `var(--brand)` 使用量下限 50 处（低于它说明有人绕过令牌 —— 只定义不用的令牌是空白支票）

**六个坏状态全部拦住、还原后 exit=0：**

| 注入的坏状态 | 结果 |
|---|---|
| wxss 写回 `color:#06b6d4` | ✅ exit=1 命中 |
| `--brand` 改成 `#0891b2` | ✅ exit=1 命中 |
| `tabBar.selectedColor` 改回亮青 | ✅ exit=1 命中 |
| 偷偷加一档 `--brand-deco` | ✅ exit=1 命中 |
| 图标 PNG 改回亮青 | ✅ exit=1 命中 |
