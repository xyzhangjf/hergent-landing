## ④ 结论与建议

**结论：A 无需升级，维持生产 v0.19.0。**

理由：
1. 官方最新 v0.21.1 相对已评估的 v0.21.0 无 hergent 需要的新能力或修复——新能力 90% 桌面/多机器人/云端向，hergent 近期 AI 优化已 90% 走自有 hermes_core.py 直连 DeepSeek，与 Hermes 版本解耦。
2. 升级仍会**破坏契约 ③**：cron bridge 脚本全仓零命中未回归，升级即每日简报（8:05）等全部定时任务失效，须先把 cron_tasks.py 的 subprocess 桥接重写为对 `/api/cron/jobs` 的 HTTP 调用——这是代码改动 + staging 验证工程，不是版本替换。
3. v0.21.0/v0.21.1 延续 gateway 新运行时（端口 8642、API_SERVER_KEY、进程模型），部署形态与 v0.19.0 单进程 `hermes serve` 不同，nginx→18765 反代需重核；生产机无外网（pip 依赖安装阻塞）问题依旧。
4. 收益/风险失衡不变：为边际收益（≈0）冒线上副驾/每日简报/Excel 对账中断风险，不值得。
