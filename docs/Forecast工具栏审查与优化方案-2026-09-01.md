## 二、现状问题

### 2.1 功能重叠 / 可合并项

| 问题 | 具体 | 性质 |
|---|---|---|
| **同类能力被拆散** | 「移动端录单」在协同闭环组，「小程序端审批」在更多工具组 —— 同属小程序、同图标 `smartphone`，却在两个不同的组 | **真重叠**，应合并 |
| 历史对比三件套散落 | 「对比期 + 清除对比」「载入趋势」「去年同期」都属历史对比，被埋在 14 项的「更多工具」里，找不到彼此 | 应聚合 |
| 同名不同作用域 | 「更多工具·清除对比」（期次对比）与「快照对比·清除对比」文案完全一样，作用对象不同 | 歧义 |
| 低频常驻 | 「重置列宽」常驻工具栏，但它属于列设置范畴；而列菜单（col-menu）里**没有**它 → 占了高频区、入口却唯一 | 位置错 |
| 语义相邻难分辨 | 「体检」= 提交前检查（healthIssues）；「数据健康分」= 档案完整度评分。两者同组且都带"健康" | 命名需区分 |
| 期次操作二选一 | 「关闭期次」「删除期次」互斥显示，只会出现一个，却各占一个按钮位 | 可合并为「⋯」 |

> 说明：「智能建议 / 运行预测 / 一键凑单达返利 / 建议配方」四者**功能确实不同**（分别是：生成并审核建议、时序预测、凑单、算法参数配置），不是重复项，但命名区分度低，属文案问题（见 2.3）。

### 2.2 布局紧凑度与空间浪费

1. **期次下拉过宽 —— 最大浪费点（约 350–400px）**
   - 模板第 16 行 option 文本 = `{{ 期次名 }}（{{ 下单起 }} ~ {{ 下单止 }}）`
   - `.sel-period{width:auto;max-width:100%}` → select 会撑到**最长选项**的宽度
   - 而下方 SOP 条（307–315 行）已完整显示当前期次的下单区间与到货日 → **下拉里的日期是重复信息**

2. **期次下拉高 40px，同排按钮 32px —— 视觉错位**
   - `<select class="input sel-period">` 继承了 `.input{height:40px}`，`.sel-period` 未覆写 height
   - 同排 `.btn-sm{height:32px}`、`.tb-search{height:32px}`、`.tb-toggle{height:32px}`

3. **工具栏溢出靠横向滚动，右侧按钮被裁切**
   - `.toolbar{...flex-wrap:wrap;...overflow-x:auto}` —— 同时设了 wrap 和 overflow-x，行为冲突；子项都带 `flex:0 0 auto`，实际结果是**横向滚动**，右侧「智能建议 / 表格设置」容易看不见（仅有 6px 细滚动条提示）

4. **分隔线占位约 55px**：5 条 `.tb-sep`（1px + margin 0 5px = 11px/条）

5. **状态行独占一整行，右侧大片空白**
   - `.tb-status-row{flex:0 0 100%;margin-top:10px}` 里只有「已确认/草稿」「已隐藏 N 个零报单」两个徽章 → 工具栏实际占 2 行高

6. **死 CSS 3 处**（模板区已确认无引用，`<style>` 从 5625 行起）
   - `.tbl-toolbar`（5788–5789）、`.edit-ops`（5882）、`.enh-panels`（6091）

7. **缩放控件重复写两遍**：359–367 行（只读态）与 497–505 行（编辑态）完全相同的 `zoom-group`

## 三、优化后布局

### 3.1 主工具栏（结构不变，只做 3 处改动）

**只读态**
```
[ 期次名 ▾ ] [＋ 新建期次] [关闭期次]        [🔍 搜索商品名…] [仅显示有报单] │ [导入 Excel] [✎ 编辑] │ [✨ AI 智能建议] [⚙ 显示设置 ▾]
                                                                              状态行：● 已确认 · 张三     已隐藏 12 个零报单
```
**编辑态**
```
[ 期次名 ▾ ] [＋ 新建期次] [关闭期次]        [🔍 搜索商品名…] [仅显示有报单] │ [导入 Excel] [取消] [回退] [校验 3] [保存] │ [✨ AI 智能建议] [🧰 工具箱 ▾]
```

| 改动 | 原因 | 省出空间 |
|---|---|---|
| ① 期次下拉 option 只保留期次名，加 `max-width:220px` | 日期在下方 SOP 条已显示，属重复信息 | **≈ −180px** |
| ② 期次下拉补 `height:32px;line-height:32px` | 与同排 32px 控件对齐，消除 8px 错位 | 0（纯视觉） |
| ③ 「重置列宽」移入列菜单（col-menu）底部 | 极低频，且它与列设置同类；移走后编辑态也仍可达 | **≈ −100px** |
| ④ 分隔线由 5 条减到 3 条（去掉「重置列宽」前后多余的一条） | 归并后语义簇变少 | **≈ −11px** |
| ⑤ 「高级」→「工具箱」、「智能建议」→「AI 智能建议」+ sparkle 图标 | 消除语义冲突、补图标一致性 | 0 |
| ⑥ 「导入」→「导入 Excel」、「回退上次保存」→「回退」 | 明确对象、缩短标签 | ≈ −20px |
| ⑦ `.toolbar` 去掉 `overflow-x:auto`，改为 `flex-wrap:wrap` 并把状态行推到第二行 | 溢出时优雅换行而非裁切右侧按钮 | 0 |

**合计省出 ≈ 310px**，在常见笔记本宽度下可避免横向滚动，右侧「AI 智能建议 / 工具箱」始终可见。
