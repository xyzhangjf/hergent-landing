**差 0.00，一分不差。** 期初数据本身是完整、正确、平衡的。

## 二、根因（三处，都在 `import_zhoupu.py: import_coa_openings()`）

```python
for item in data:                      # ① 无条件遍历，没有幂等
    ...
    direction = item.get('余额方向', '').strip()
    debit  = amount if direction == '借方' else 0
    credit = amount if direction == '贷方' else 0
    INSERT INTO journal_entries ...    # ② 父科目汇总行也照写
                                       # ③ 全程不校验借贷是否相等
```

舟谱导出的「科目期初余额.xlsx」是**科目明细表**，父科目也有汇总行。脚本把它当分录逐行写入 ⇒ 父 + 子双倍。而且每跑一次就全量插一遍，老板点了 4 次 ⇒ ×4。

**只修数据不修代码，下次再点一次又会重复。**

## 三、改了什么

### A. 数据（`tenant_1.db`，删 168 行）

- 每个库的 opening 凭证只保留 `created_at` 最早的一轮
- 删掉「存在直接子科目」的父科目行（12 个）
- **不补任何调整分录**——期初本身是平的，补反而造假

### B. 报表口径（`db/queries/finance.py: get_balance_sheet_gl()`）

权益并入「尚未结转到本年利润」的当期损益（6 开头科目净额）。

原因：资产负债表恒等式是 资产 = 负债 + 所有者权益。损益类在期末结转前仍挂在账上，不并入就**永远差一个"当期利润"**。tenant_1 实测未结转 **98,325.00**（`revenue_recognition` 90,000 + `sale` 8,325），**正好等于清理后的报表差额**——这不是账不平，是没结转。

结转后损益类归零、`4103 本年利润` 有余额，不会重复计。

返回体新增 `unclosed_profit` 字段便于诊断。

### C. 防复发（`import_zhoupu.py: import_coa_openings()`）

三重保护：

1. **幂等**——已有 opening 分录就拒绝，并提示先 `DELETE ... WHERE ref_type='opening'`
2. **跳父科目**——先解析全部行，按编码前缀（长度 +2）识别父科目并跳过，打印跳过了哪些
3. **平衡校验**——写完借贷不等就把本次插入的行**全部删净**并报错，绝不留半截账

## 六、踩坑（三条，都值得记住）

### ① 🔴 幂等判据第二次栽在同一个坑（这次是反方向）

`NEW = OLD + 追加内容` ⇒ **OLD 是 NEW 的前缀**，改完之后 `n_old` 依然 ≥ 1。

我沿用了 v707 的判据 `if n_new >= 1 and n_old == 0: 跳过`，结果 `n_old == 1` 不走跳过分支，**又替换了一遍**——`total_equity += unclosed_profit` 出现 2 次，权益被多加 98,325，而且**语法合法、静默劣化**。

v707 那次是「旧串是新串的前缀」（`import round_money` vs `import round_money, money_balanced`），这次是「旧串被新串包含」。**同一个坑的两个方向。**

正确判据：**先判新串是否已在位**（`n_new >= 1` 就跳过），再判旧串唯一。

补丁脚本现已加硬断言：`fin.count("total_equity += unclosed_profit") == 1`。

### ② `tenant_*.db` 白名单会抓到历史快照

生产上还有 `tenant_1.pre-v617-20261019-1148.db`、`tenant_1.pre-v618-20261019-1215.db` 两个归档。用 `startswith("tenant_")` 会把它们当活动库处理——**改它等于篡改历史证据**。已收紧为 `^tenant_\d+\.db$`。

### ③ 自检脚本扫全文会误报

`import_coa()`（科目表导入，第 349 行）里也有 `for item in data: try: code_text = ...` 的同构结构。用全文 grep 判"期初导入是否已改"，会命中这个**本来就该这样**的函数，报假 FAIL。改为**只截取 `import_coa_openings` 函数体**判断。
